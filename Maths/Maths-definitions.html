M1 · Systems of linear equations · 15 items

System of linear equations

A set of \(m\) equations \(a_{i1}x_1 + \dots + a_{in}x_n = b_i\) in \(n\) unknowns, written compactly as \(Ax = b\) with coefficient matrix \(A \in \mathbb{R}^{m \times n}\), unknown vector \(x \in \mathbb{R}^n\) and right-hand side \(b \in \mathbb{R}^m\). A solution is any \(x\) satisfying all \(m\) equations at once.

1.1.1, 1.2.5 · slides 5–8, 29–30

Consistent and inconsistent systems

A system is consistent if it has at least one solution and inconsistent if it has none. A consistent system has either exactly one solution or infinitely many; it is consistent exactly when \(\operatorname{rk}(A) = \operatorname{rk}([A \mid b])\).

1.1.2, 1.4.2 · slides 9–12, 46–49

Matrix and matrix product

An \(m \times n\) matrix \(A \in \mathbb{R}^{m \times n}\) is a rectangular array of real numbers \(a_{ij}\) with \(m\) rows and \(n\) columns. For \(A \in \mathbb{R}^{m \times n}\) and \(B \in \mathbb{R}^{n \times k}\) the product \(C = AB \in \mathbb{R}^{m \times k}\) has entries \(c_{ij} = \sum_{l=1}^{n}a_{il}b_{lj}\); it is associative and distributive but not commutative.

1.2.1, 1.2.2 · slides 19–24

Identity matrix and transpose

The identity \(I_n\) is the \(n \times n\) matrix with ones on the diagonal and zeros elsewhere, so \(I_mA = AI_n = A\). The transpose \(A^\top \in \mathbb{R}^{n \times m}\) has entries \((A^\top)_{ij} = a_{ji}\), and \((AB)^\top = B^\top A^\top\).

1.2.2, 1.2.4 · slides 22–24, 28

Inverse matrix; invertible and singular

A square matrix \(A\) is invertible (regular, non-singular) if some \(A^{-1}\) satisfies \(AA^{-1} = A^{-1}A = I_n\); otherwise it is singular. \(A\) is invertible exactly when \(\det A \ne 0\), and \((AB)^{-1} = B^{-1}A^{-1}\).

1.2.3, 1.2.4 · slides 25–27

Augmented matrix

The matrix \([A \mid b] \in \mathbb{R}^{m \times (n+1)}\) formed by appending the right-hand side \(b\) as an extra column of \(A\). Row operations on it transform the whole system \(Ax = b\) at once.

1.4.2 · slides 46–47

Elementary row operations

The three operations used in elimination: swapping two rows, multiplying a row by a scalar \(\lambda \ne 0\), and adding a multiple of one row to another. Each is invertible, so it leaves the solution set of the system unchanged.

1.4.1 · slides 39–45

Row-echelon form and pivots

A matrix is in row-echelon form (REF) if all zero rows are at the bottom and the first non-zero entry of each non-zero row, its pivot, lies strictly to the right of the pivot of the row above (a staircase). The columns containing pivots are the pivot columns.

1.4.3 · slides 46–50

Basic and free variables

In a row-echelon form, the variables belonging to pivot columns are basic (pivot) variables and the others are free variables. The free variables can take any value, and the basic variables are then determined by back-substitution.

1.1.3, 1.4.3 · slides 12–13, 50

Reduced row-echelon form

A row-echelon form in which every pivot equals 1 and is the only non-zero entry in its column (RREF). Every matrix has a unique RREF, from which a basis of the null space can be read off directly.

1.4.5 · slides 55–58

Particular solution and homogeneous system

A particular solution \(x_p\) is any single vector with \(Ax_p = b\). The homogeneous system is \(Ax = 0\), which always has the trivial solution \(x = 0\).

1.3.1, 1.3.2, 1.4.4 · slides 31–36, 50–54

General solution

The set of all solutions of \(Ax = b\), written \(x = x_p + \sum_k\lambda_kn_k\) with \(\lambda_k \in \mathbb{R}\), where \(x_p\) is a particular solution and \(n_1, \dots, n_{n-r}\) is a basis of \(\operatorname{null}(A)\). The set is unique; its description (choice of \(x_p\) and basis) is not.

1.3.3 · slides 37–38, 50

Gaussian elimination and back-substitution

Gaussian elimination is the algorithm that applies elementary row operations to \([A \mid b]\) to reach row-echelon form. Back-substitution then solves the triangular system from the last pivot row upwards, one basic variable at a time.

1.4.2, 1.4.4 · slides 39–54

Gauss–Jordan elimination

Elimination continued past row-echelon form, clearing entries above the pivots as well, until the reduced row-echelon form is reached. Applied to \([A \mid I_n]\) it yields \([I_n \mid A^{-1}]\) when \(A\) is invertible; the deck calls the whole process Gaussian elimination.

1.5.1, 1.5.2 · slides 59–63

Over-determined system and least squares

A system with more equations than unknowns (\(m > n\)), which is typically inconsistent. Its least-squares solution minimises \(\lVert Ax - b \rVert^2\) and satisfies the normal equations \(A^\top Ax = A^\top b\); linear regression is this approximate solution.

1.1.2 · slide 9
M2 · Vector spaces · 12 items

Group and Abelian group

A group is a set \(G\) with an operation \(\otimes : G \times G \to G\) that is closed, associative, has a neutral element \(e\) (\(x \otimes e = e \otimes x = x\)) and gives every \(x\) an inverse \(y\) with \(x \otimes y = y \otimes x = e\); it is Abelian if also \(x \otimes y = y \otimes x\). Example: \((\mathbb{Z}, +)\); non-examples: \((\mathbb{N}_0, +)\) and \((\mathbb{Z}, \cdot)\).

2.1.1, 2.1.2 · slides 67–69

Vector space

A set \(V\) with vector addition and scalar multiplication, \(V = (V, +, \cdot)\), such that \((V, +)\) is an Abelian group and, for all \(\lambda, \psi \in \mathbb{R}\) and \(x, y \in V\), \(\lambda(x + y) = \lambda x + \lambda y\), \((\lambda + \psi)x = \lambda x + \psi x\), \(\lambda(\psi x) = (\lambda\psi)x\) and \(1 \cdot x = x\). Examples: \(\mathbb{R}^n\), \(\mathbb{R}^{m \times n}\), polynomials of bounded degree.

2.2.1, 2.2.2 · slides 70–73

Vector subspace

A subset \(U \subseteq V\) that is itself a vector space under the operations of \(V\). Equivalently \(U \ne \emptyset\) and \(U\) is closed under addition and scalar multiplication, which forces \(0 \in U\).

2.3.1, 2.3.2 · slides 74–76

Null space (kernel)

The set \(\operatorname{null}(A) = \{x \in \mathbb{R}^n : Ax = 0\}\) of all solutions of the homogeneous system. It is always a subspace of \(\mathbb{R}^n\), of dimension \(n - \operatorname{rk}(A)\) (the nullity).

2.3.3, 1.3.2 · slides 34–36, 77

Linear combination

A vector of the form \(v = \sum_{j=1}^{k}\lambda_jx_j\) with scalars \(\lambda_j \in \mathbb{R}\) and vectors \(x_1, \dots, x_k \in V\). It is trivial if every \(\lambda_j = 0\) and non-trivial otherwise.

2.4.1 · slides 78–80

Linear independence and dependence

Vectors \(x_1, \dots, x_k\) are linearly independent if \(\sum_j\lambda_jx_j = 0\) forces \(\lambda_1 = \dots = \lambda_k = 0\), and linearly dependent if some non-trivial combination equals 0. Dependence is equivalent to one vector being a linear combination of the others.

2.4.2, 2.4.3, 2.4.4, 2.4.5 · slides 81–96

Span and generating set

The span of \(A = \{x_1, \dots, x_k\}\) is the set of all linear combinations of its vectors, \(\operatorname{span}[A] = \{\sum_j\lambda_jx_j : \lambda_j \in \mathbb{R}\}\). \(A\) is a generating set of \(V\) if \(\operatorname{span}[A] = V\).

2.5.1 · slides 97–98

Basis

A linearly independent generating set of \(V\); equivalently a minimal generating set, or a maximal linearly independent set. Every vector of \(V\) is then a unique linear combination of the basis vectors.

2.5.2, 2.5.3, 2.5.5 · slides 99–104

Canonical basis and coordinates

The canonical (standard) basis of \(\mathbb{R}^n\) is \(e_1, \dots, e_n\), where \(e_i\) has a 1 in position \(i\) and 0 elsewhere. The coordinates of \(x\) in a basis \(b_1, \dots, b_n\) are the unique scalars \(c_i\) with \(x = \sum_ic_ib_i\).

2.5.2, 2.5.3 · slides 99–102

Dimension

The number of vectors in any basis of \(V\), written \(\dim V\); all bases of \(V\) have the same size. For a subspace \(U \subseteq V\), \(\dim U \le \dim V\), with equality only if \(U = V\).

2.5.4 · slides 102–103

Rank

The rank \(\operatorname{rk}(A)\) of \(A \in \mathbb{R}^{m \times n}\) is the number of linearly independent columns, which equals the number of linearly independent rows and the number of pivots in a row-echelon form. It is the dimension of the column space, and \(\operatorname{rk}(A) + \dim\operatorname{null}(A) = n\).

2.5.6 · slides 105–106

Full rank

\(A \in \mathbb{R}^{m \times n}\) has full rank if \(\operatorname{rk}(A) = \min(m, n)\), and full column rank if \(\operatorname{rk}(A) = n\); otherwise it is rank deficient. A square matrix is invertible exactly when it has full rank.

2.5.6 · slides 105–106
M3 · Analytic geometry · 14 items

Norm

A function \(\lVert \cdot \rVert : V \to \mathbb{R}\) that is absolutely homogeneous (\(\lVert \lambda x \rVert = \lvert \lambda \rvert\lVert x \rVert\)), satisfies the triangle inequality (\(\lVert x + y \rVert \le \lVert x \rVert + \lVert y \rVert\)) and is positive definite (\(\lVert x \rVert \ge 0\), with equality only for \(x = 0\)). It assigns a length to every vector.

3.1.1 · slide 111

Manhattan and Euclidean norms

The Manhattan (\(\ell_1\)) norm is \(\lVert x \rVert_1 = \sum_i\lvert x_i \rvert\) and the Euclidean (\(\ell_2\)) norm is \(\lVert x \rVert_2 = \sqrt{\sum_ix_i^2} = \sqrt{x^\top x}\). The Euclidean norm is induced by the dot product; the Manhattan norm is induced by no inner product.

3.1.2 · slide 111

Inner product and dot product

An inner product is a map \(\langle \cdot, \cdot \rangle : V \times V \to \mathbb{R}\) that is bilinear (linear in each argument), symmetric (\(\langle x, y \rangle = \langle y, x \rangle\)) and positive definite (\(\langle x, x \rangle > 0\) for \(x \ne 0\)). The dot product \(x^\top y = \sum_{i=1}^{n}x_iy_i\) is the standard inner product on \(\mathbb{R}^n\).

3.2.1 · slides 112–113

Symmetric positive definite matrix

A matrix \(A = A^\top \in \mathbb{R}^{n \times n}\) with \(x^\top Ax > 0\) for every \(x \ne 0\) (SPD, written \(A \succ 0\)); it is positive semidefinite (\(A \succeq 0\)) if only \(x^\top Ax \ge 0\) holds. \(\langle x, y \rangle = \hat{x}^\top A\hat{y}\) is an inner product exactly when \(A\) is SPD.

3.2.2, 3.2.3 · slides 113–115

Induced norm

The norm \(\lVert x \rVert = \sqrt{\langle x, x \rangle}\) defined by an inner product. Every induced norm satisfies the parallelogram law, which is how one shows that a norm such as \(\lVert \cdot \rVert_1\) is not induced.

3.3.1 · slide 116

Cauchy–Schwarz inequality

For any inner product and induced norm, \(\lvert \langle x, y \rangle \rvert \le \lVert x \rVert\lVert y \rVert\), with equality exactly when \(x\) and \(y\) are parallel.

3.3.2 · slides 117–118

Metric (distance)

A function \(d : V \times V \to \mathbb{R}\) that is positive definite (\(d(x, y) \ge 0\), zero only when \(x = y\)), symmetric and satisfies the triangle inequality \(d(x, z) \le d(x, y) + d(y, z)\). In an inner product space the distance is \(d(x, y) = \lVert x - y \rVert = \sqrt{\langle x - y, x - y \rangle}\).

3.3.3 · slides 118–119

Angle between vectors

For non-zero \(x, y\) the angle \(\omega \in [0, \pi]\) is defined by \(\cos\omega = \frac{\langle x, y \rangle}{\lVert x \rVert\lVert y \rVert}\), which lies in \([-1, 1]\) by Cauchy–Schwarz. With the dot product this is cosine similarity.

3.4.1 · slides 120–122

Orthogonal and orthonormal vectors

\(x\) and \(y\) are orthogonal, \(x \perp y\), if \(\langle x, y \rangle = 0\); the zero vector is orthogonal to every vector. They are orthonormal if, in addition, \(\lVert x \rVert = \lVert y \rVert = 1\); orthogonality depends on the chosen inner product.

3.4.2, 3.6.1 · slides 123–125, 129–130

Orthogonal matrix

A square matrix \(A \in \mathbb{R}^{n \times n}\) whose columns are orthonormal, so \(A^\top A = AA^\top = I\) and \(A^{-1} = A^\top\); it preserves lengths and angles and has \(\det A = \pm 1\). Example: the 2-D rotation \(R(\theta) = \begin{bmatrix} \cos\theta & -\sin\theta \\ \sin\theta & \cos\theta \end{bmatrix}\), which turns vectors anticlockwise by \(\theta\) and has \(R(\theta)^{-1} = R(-\theta)\).

3.5.1, 3.5.2 · slides 126–128

Orthonormal and orthogonal basis

A basis \(b_1, \dots, b_n\) is orthonormal if \(\langle b_i, b_j \rangle = \delta_{ij}\), where the Kronecker delta \(\delta_{ij}\) is 1 for \(i = j\) and 0 otherwise. It is orthogonal if only \(\langle b_i, b_j \rangle = 0\) for \(i \ne j\) is required.

3.6.1 · slides 129–130

Gram–Schmidt orthogonalisation

A procedure that turns a basis \(v_1, \dots, v_n\) into an orthogonal basis spanning the same space, by subtracting from each \(v_k\) its projections onto the previously built vectors; dividing by the norms makes it orthonormal. The deck carries it out by forward elimination on \([A^\top A \mid A^\top]\), where the columns of \(A\) are the \(v_k\).

3.6.2, 3.6.4 · slides 131–132, 136

Elementary matrix

The identity matrix with one extra non-zero entry below the diagonal; left-multiplying by it performs one "add a multiple of row \(j\) to row \(i\)" step of elimination. Its inverse is the same matrix with that entry negated.

3.6.3 · slides 133–134

Triangular matrices and LU decomposition

A matrix is lower (upper) triangular if every entry above (below) the diagonal is zero. The LU decomposition writes \(A = LU\) with \(L\) unit lower triangular (holding the elimination multipliers) and \(U\) upper triangular (the echelon form).

3.6.3 · slides 134–135
M4 · Eigenvalues & eigenvectors · 14 items

Determinant

A scalar \(\det A\) assigned to a square matrix, defined recursively by cofactor expansion along any row or column, with \(\det\begin{bmatrix} a & b \\ c & d \end{bmatrix} = ad - bc\). It is non-zero exactly when \(A\) is invertible, and \(\lvert \det A \rvert\) is the factor by which \(A\) scales volumes.

4.1.1, 4.1.2, 4.1.3 · slides 141–149

Minor and cofactor

The minor \(M_{jk}\) is the determinant of the \((n-1) \times (n-1)\) matrix obtained by deleting row \(j\) and column \(k\) of \(A\). The cofactor is \(C_{jk} = (-1)^{j+k}M_{jk}\), so \(\det A = \sum_ka_{jk}C_{jk}\) for any row \(j\).

4.1.1 · slides 142–145

Trace

The sum of the diagonal entries of a square matrix, \(\operatorname{tr}(A) = \sum_ia_{ii}\). It is linear, \(\operatorname{tr}(I_n) = n\), and \(\operatorname{tr}(AB) = \operatorname{tr}(BA)\).

4.2.1 · slides 150–151

Characteristic polynomial

\(p_A(\lambda) = \det(A - \lambda I) = c_0 + c_1\lambda + \dots + c_{n-1}\lambda^{n-1} + (-1)^n\lambda^n\), a polynomial of degree \(n\) with \(c_0 = \det A\) and \(c_{n-1} = (-1)^{n-1}\operatorname{tr}A\). Its roots are the eigenvalues of \(A\).

4.2.2 · slides 152–153

Eigenvalue and eigenvector

A scalar \(\lambda\) (possibly complex) is an eigenvalue of \(A \in \mathbb{R}^{n \times n}\), with eigenvector \(x \ne 0\), if \(Ax = \lambda x\). Equivalently \(\det(A - \lambda I) = 0\), or \(\operatorname{rk}(A - \lambda I) < n\).

4.3.1, 4.3.2 · slides 154–157

Eigenspace and spectrum

The eigenspace of \(\lambda\) is \(E_\lambda = \operatorname{null}(A - \lambda I)\), the set of all its eigenvectors together with 0; it is a subspace. The spectrum of \(A\) is the set of all its eigenvalues.

4.3.4 · slide 158

Algebraic and geometric multiplicity

The algebraic multiplicity of \(\lambda\) is the number of times it occurs as a root of \(p_A\); the geometric multiplicity is \(\dim E_\lambda\). Always \(1 \le\) geometric \(\le\) algebraic.

4.3.3, 4.4.1 · slides 157–160

Defective matrix

A square matrix with an eigenvalue whose geometric multiplicity is smaller than its algebraic multiplicity, so it has fewer than \(n\) independent eigenvectors and cannot be diagonalised. Example: \(\begin{bmatrix} 0 & 1 \\ 0 & 0 \end{bmatrix}\).

4.3.3 · slide 157

Symmetric matrix

A square matrix equal to its transpose, \(A = A^\top\), that is \(a_{ij} = a_{ji}\). Covariance matrices, Hessians with continuous second partials, \(A^\top A\) and kernel matrices are symmetric.

4.4.1 · slide 160

Conjugate transpose and Hermitian matrix

The conjugate transpose of a complex vector or matrix is \(x^H = \bar{x}^\top\), so \(\lVert x \rVert^2 = x^Hx\). A matrix is Hermitian if \(A^H = A\); real symmetric matrices are the real case, and Hermitian matrices have real eigenvalues.

4.4.2 · slides 161–163

Spectral theorem

If \(A \in \mathbb{R}^{n \times n}\) is symmetric, then all its eigenvalues are real and there is an orthonormal basis of \(\mathbb{R}^n\) of eigenvectors of \(A\), so \(A = Q\Lambda Q^\top\) with \(Q\) orthogonal and \(\Lambda\) diagonal. The diagonal of \(\Lambda\) holds the eigenvalues, which may be 0.

4.4.1, 4.4.3, 4.4.4 · slides 160, 164–167

Rayleigh quotient

For symmetric \(A\) and \(x \ne 0\), \(R(x) = \frac{x^\top Ax}{x^\top x}\). It always lies between \(\lambda_{\min}\) and \(\lambda_{\max}\), attaining them at the corresponding eigenvectors, which is why PCA's top direction is the top eigenvector.

4.4.4, 4.3.5 · slides 159, 167

Cholesky decomposition

The factorisation \(A = LL^\top\) of a symmetric positive definite matrix, where \(L\) is lower triangular with strictly positive diagonal entries (off-diagonal entries may be negative). It exists and is unique exactly when \(A\) is SPD; \(L\) is the Cholesky factor.

4.6.1 · slide 169

Multivariate Gaussian sampling

A sample from \(N(\mu, \Sigma)\) is generated as \(x = \mu + Lz\), where \(\Sigma = LL^\top\) is the Cholesky factorisation and \(z \sim N(0, I)\) is a standard-normal vector. It works because \(\operatorname{Cov}(Lz) = LL^\top = \Sigma\).

4.6.2 · slide 170
M5 · Singular value decomposition · 11 items

Diagonal matrix

A square matrix \(D = \operatorname{diag}(d_1, \dots, d_n)\) whose off-diagonal entries are all zero. Its determinant is \(\prod_id_i\), its powers are \(\operatorname{diag}(d_i^k)\), and its inverse (when every \(d_i \ne 0\)) is \(\operatorname{diag}(1/d_i)\).

5.1.1 · slide 175

Diagonalisable matrix

A square matrix \(A\) is diagonalisable if there is an invertible \(P\) such that \(D = P^{-1}AP\) is diagonal; \(A\) and \(D\) are then similar matrices. This holds exactly when \(A\) has \(n\) linearly independent eigenvectors, which form the columns of \(P\).

5.1.2 · slides 176–177

Eigendecomposition

The factorisation \(A = PDP^{-1}\) of a diagonalisable matrix, with eigenvectors as the columns of \(P\) and the matching eigenvalues on the diagonal of \(D\). For symmetric \(A\), \(P\) can be chosen orthogonal, giving \(A = PDP^\top\).

5.2.1, 5.2.2, 5.2.3 · slides 178–182

Singular value decomposition (SVD)

For any \(A \in \mathbb{R}^{m \times n}\) of rank \(r\), the factorisation \(A = U\Sigma V^\top\) with \(U \in \mathbb{R}^{m \times m}\) and \(V \in \mathbb{R}^{n \times n}\) orthogonal and \(\Sigma \in \mathbb{R}^{m \times n}\) zero except for \(\Sigma_{ii} = \sigma_i\), \(\sigma_1 \ge \dots \ge \sigma_r > 0\). It exists for every real matrix.

5.3.1, 5.3.2 · slides 183–186

Singular values

The non-negative numbers \(\sigma_i\) on the diagonal of \(\Sigma\), sorted in decreasing order; the non-zero ones are \(\sigma_i = \sqrt{\lambda_i(A^\top A)}\), and their number is \(\operatorname{rk}(A)\). They can repeat, and for symmetric \(A\) they equal \(\lvert\lambda_i(A)\rvert\).

5.3.1, 5.3.3 · slides 183–187

Left and right singular vectors

The columns \(u_i\) of \(U\) are the left singular vectors (eigenvectors of \(AA^\top\)) and the columns \(v_i\) of \(V\) the right singular vectors (eigenvectors of \(A^\top A\)). They are linked by \(Av_i = \sigma_iu_i\), so \(u_i = Av_i/\sigma_i\) for \(i \le r\).

5.3.3, 5.3.4 · slides 186–188

Outer product and rank-1 matrix

The outer product of \(u \in \mathbb{R}^m\) and \(v \in \mathbb{R}^n\) is the \(m \times n\) matrix \(uv^\top\) with entries \(u_iv_j\); every non-zero outer product has rank 1. The SVD writes \(A = \sum_{i=1}^{r}\sigma_iu_iv_i^\top\) as a sum of \(r\) such matrices.

5.6.1 · slides 197–198

Rank-k approximation (truncated SVD)

\(\hat{A}(k) = \sum_{i=1}^{k}\sigma_iu_iv_i^\top\) for \(k < r\): the SVD with all but the \(k\) largest singular values set to zero. It has rank \(k\) and needs \(k(m + n + 1)\) stored numbers instead of \(mn\).

5.6.2 · slides 199–200

Eckart–Young theorem

The truncated SVD \(\hat{A}(k)\) is the closest rank-\(k\) matrix to \(A\) in both the spectral and the Frobenius norm, with \(\lVert A - \hat{A}(k) \rVert_2 = \sigma_{k+1}\). It is the theorem behind SVD compression and PCA.

5.6.2, 10.5.2 · slides 199–200, 406–407

Spectral norm

The matrix norm \(\lVert A \rVert_2 = \max_{x \ne 0}\frac{\lVert Ax \rVert_2}{\lVert x \rVert_2}\), the largest factor by which \(A\) stretches a vector. It equals the largest singular value \(\sigma_1\), attained at \(x = v_1\).

5.6.3 · slides 200–201

Frobenius norm

\(\lVert A \rVert_F = \sqrt{\sum_{i,j}a_{ij}^2} = \sqrt{\operatorname{tr}(A^\top A)} = \sqrt{\sum_i\sigma_i^2}\), the Euclidean norm of the matrix viewed as one long vector.

5.6.2, 5.4.1 · slides 193, 199–200
M6 · Differentiation, backpropagation & automatic differentiation · 15 items

Derivative

The derivative of \(f : \mathbb{R} \to \mathbb{R}\) at \(x\) is \(f'(x) = \frac{df}{dx} = \lim_{h \to 0}\frac{f(x + h) - f(x)}{h}\), the two-sided limit of the difference quotient, when it exists. It is the slope of the tangent, the local rate of change of \(f\).

6.1.1, 6.1.2 · slides 205–208

Taylor polynomial, Taylor series and Maclaurin series

The Taylor polynomial of degree \(n\) of \(f\) at \(x_0\) is \(T_n(x) = \sum_{k=0}^{n}\frac{f^{(k)}(x_0)}{k!}(x - x_0)^k\), the polynomial matching \(f\) and its first \(n\) derivatives at \(x_0\); the Taylor series \(T_\infty\) is the same sum to infinity. A Maclaurin series is a Taylor series about \(x_0 = 0\), for example \(e^x = \sum_kx^k/k!\).

6.1.3 · slides 209–213

Chain rule

The derivative of a composition is the product of the derivatives: \((g \circ f)'(x) = g'(f(x))f'(x)\). In several variables it becomes a product of gradients and Jacobians, \(\frac{df}{dt} = \frac{\partial f}{\partial x}\frac{\partial x}{\partial t}\), summing over every path from input to output.

6.1.4, 6.2.4 · slides 214–215, 221–224

Partial derivative

For \(f : \mathbb{R}^n \to \mathbb{R}\), \(\frac{\partial f}{\partial x_i} = \lim_{h \to 0}\frac{f(x_1, \dots, x_i + h, \dots, x_n) - f(x)}{h}\): the derivative with respect to \(x_i\) with all other variables held constant.

6.2.1, 6.2.2 · slides 216–219

Gradient

The vector of all partial derivatives of a scalar function \(f : \mathbb{R}^n \to \mathbb{R}\). Gradient layout: the deck writes it as the row vector \(\nabla_xf = \frac{df}{dx} = \big[\frac{\partial f}{\partial x_1} \; \cdots \; \frac{\partial f}{\partial x_n}\big] \in \mathbb{R}^{1 \times n}\); many texts use its transpose, a column vector, and the gradient-descent step then drops the transpose.

6.2.1 · slides 216–218

Jacobian

For \(f : \mathbb{R}^n \to \mathbb{R}^m\), the \(m \times n\) matrix \(J = \frac{df}{dx}\) with entries \(J_{ij} = \frac{\partial f_i}{\partial x_j}\); row \(i\) is the gradient of \(f_i\). For a linear map, \(\frac{d(Ax)}{dx} = A\).

6.3.1, 6.3.2 · slides 225–228

Matrix calculus

Differentiation of scalar, vector or matrix expressions with respect to vectors or matrices, using identities such as \(\frac{\partial x^\top a}{\partial x} = a^\top\) and \(\frac{\partial x^\top Bx}{\partial x} = x^\top(B + B^\top)\) (row layout). A derivative with respect to a matrix \(X\) has the shape of \(X\).

6.4.1 · slide 235

Expression swell

The rapid growth in size of a closed-form symbolic derivative, caused by the same sub-expressions being copied many times by the chain rule. Computing shared intermediate values once (backpropagation, AD) avoids it.

6.5.1 · slides 236–237

Backpropagation

An algorithm that computes the gradient of a loss with respect to all parameters of a layered model \(f_i = \sigma_i(A_{i-1}f_{i-1} + b_{i-1})\) by applying the chain rule from the output layer backwards. The product of Jacobians already computed for layer \(i + 1\) is reused for layer \(i\).

6.5.2 · slides 238–241

Computation graph

A directed acyclic graph whose nodes are the intermediate variables \(x_i = g_i(x_{\text{Pa}(x_i)})\) of a calculation, each an elementary function of its parent nodes \(\text{Pa}(x_i)\). The inputs are the source nodes and the output \(x_D = f\) is the final node.

6.6.1 · slides 242–245

Automatic differentiation

A technique that computes exact derivatives of a program by applying the chain rule to the local derivatives of the elementary operations in its computation graph. It is neither symbolic differentiation (no expression swell) nor numerical differentiation (no truncation error).

6.6.1, 6.6.2, 6.6.3 · slides 242–247

Forward and reverse mode

Forward mode propagates derivatives from the inputs to the output, needing one pass per input; reverse mode propagates \(\partial f/\partial x_i\) from the output back to the inputs, \(\frac{\partial f}{\partial x_i} = \sum_{j}\frac{\partial f}{\partial x_j}\frac{\partial g_j}{\partial x_i}\) over the children \(x_j\) of \(x_i\). Reverse mode gives the whole gradient of a scalar \(f\) in one backward pass; backpropagation is reverse mode.

6.6.2, 6.6.3 · slides 245–247

Sigmoid function

\(\sigma(z) = \frac{1}{1 + e^{-z}}\), an S-shaped activation mapping \(\mathbb{R}\) to \((0, 1)\), with derivative \(\sigma'(z) = \sigma(z)(1 - \sigma(z)) \le \tfrac{1}{4}\). Applied to a vector it acts element-wise.

6.7.1 · slides 248–250

Hadamard product

The element-wise product \(a \odot b\) of two vectors or matrices of the same shape, \((a \odot b)_i = a_ib_i\). Multiplying by a diagonal Jacobian \(\operatorname{diag}(d)\) is the same as taking a Hadamard product with \(d\).

6.7.1, 6.7.2 · slides 251–256

Error signal δ

The gradient of the loss with respect to a layer quantity, written as a column vector in the deck's sigmoid-layer slides: \(\delta^{(a)} = \partial\text{Loss}/\partial a\) and \(\delta^{(Z)} = \partial\text{Loss}/\partial Z = \delta^{(a)} \odot a \odot (1 - a)\). It gives \(\partial\text{Loss}/\partial A = \delta^{(Z)}x^\top\), \(\partial\text{Loss}/\partial b = \delta^{(Z)}\) and \(\partial\text{Loss}/\partial x = A^\top\delta^{(Z)}\).

6.7.2 · slides 253–256
M7 · Taylor & Maclaurin series · 12 items

Taylor's theorem (Lagrange remainder)

If \(f^{(n-1)}\) is continuous on \([a, b]\) and \(f^{(n)}\) exists on \((a, b)\), then \(f(b) = \sum_{k=0}^{n-1}\frac{f^{(k)}(a)}{k!}(b - a)^k + \frac{f^{(n)}(c)}{n!}(b - a)^n\) for some \(c \in (a, b)\). The last term is the Lagrange form of the remainder.

7.1.1 · slides 260–262

Remainder (truncation error)

The difference \(R_n(x) = f(x) - T_n(x)\) between a function and its Taylor polynomial, equal to \(\frac{f^{(n+1)}(c)}{(n+1)!}(x - x_0)^{n+1}\) for some \(c\) between \(x_0\) and \(x\). Bounding \(\lvert f^{(n+1)} \rvert \le M\) gives \(\lvert R_n \rvert \le M\lvert x - x_0 \rvert^{n+1}/(n+1)!\).

7.1.5 · slide 268

Mean-value theorem

If \(f\) is continuous on \([a, b]\) and differentiable on \((a, b)\), there is a \(c \in (a, b)\) with \(f'(c) = \frac{f(b) - f(a)}{b - a}\). It is Taylor's theorem with \(n = 1\).

7.1.2 · slides 263–264

Rolle's theorem

If \(f\) is continuous on \([a, b]\), differentiable on \((a, b)\) and \(f(a) = f(b)\), then \(f'(c) = 0\) for some \(c \in (a, b)\).

7.1.3 · slides 264–265

Proposition P

The deck's lemma obtained by applying Rolle's theorem \(n\) times: if \(F(a) = F'(a) = \dots = F^{(n-1)}(a) = 0\) and \(F(b) = 0\), with the usual continuity and differentiability, then \(F^{(n)}(c) = 0\) for some \(c \in (a, b)\). Applied to \(F = f - P\) it proves Taylor's theorem.

7.1.3, 7.1.4 · slides 265–267

Critical (stationary) point

A point \(x^*\) where the gradient vanishes, \(\nabla f(x^*) = 0\) (in two variables \(f_x = f_y = 0\)). It may be a local minimum, a local maximum or a saddle point.

7.2.2, 8.1.3 · slides 271, 284–286

Local minimum, local maximum and saddle point

\(x^*\) is a local minimum (maximum) if \(f(x^*) \le f(x)\) (\(\ge\)) for all \(x\) in some neighbourhood of \(x^*\), and a global minimum if this holds for all \(x\). A saddle point is a critical point that is neither: \(f\) increases in some directions and decreases in others.

7.2.4, 9.2.1 · slides 273, 321–322

Quadratic form

A function \(Q(\delta) = \delta^\top H\delta = \sum_{i,j}H_{ij}\delta_i\delta_j\) for a symmetric matrix \(H\); in two variables \(Q = h^2f_{xx} + 2hkf_{xy} + k^2f_{yy}\). Its sign over all directions \(\delta\) classifies a critical point.

7.2.2, 7.2.3 · slides 271–272

Second-derivative test

At a critical point of \(f(x, y)\) with \(D = f_{xx}f_{yy} - f_{xy}^2\): \(D > 0\), \(f_{xx} > 0\) gives a local minimum; \(D > 0\), \(f_{xx} < 0\) a local maximum; \(D < 0\) a saddle; \(D = 0\) is inconclusive. In one variable, \(f'' > 0\) is a minimum, \(f'' < 0\) a maximum and \(f'' = 0\) inconclusive.

7.2.4, 8.1.3 · slides 273, 285

Hessian matrix

The \(n \times n\) matrix of second partial derivatives, \(H = \nabla^2f\) with \(H_{ij} = \frac{\partial^2f}{\partial x_i\partial x_j}\); in two variables \(H = \begin{bmatrix} f_{xx} & f_{xy} \\ f_{xy} & f_{yy} \end{bmatrix}\). It is symmetric when the second partials are continuous.

7.3.1 · slides 274–275

Sylvester's criterion and leading principal minors

The \(k\)-th leading principal minor \(\Delta_k\) is the determinant of the top-left \(k \times k\) block of a square matrix. Sylvester's criterion: a symmetric matrix is positive definite exactly when all \(\Delta_k > 0\), and negative definite exactly when \((-1)^k\Delta_k > 0\) (alternating signs starting negative).

7.3.2 · slide 275

Positive definite, negative definite and indefinite

A symmetric \(H\) is positive definite if \(\delta^\top H\delta > 0\) for all \(\delta \ne 0\) (all eigenvalues positive), negative definite if \(\delta^\top H\delta < 0\) (all eigenvalues negative), and indefinite if the form takes both signs (eigenvalues of both signs). A PD Hessian at a critical point means a strict local minimum, ND a strict maximum, indefinite a saddle.

7.3.3 · slide 276
M8 · Gradient descent · 16 items

Objective (loss) function

The scalar function \(f(x)\) or \(L(\theta)\) to be minimised (or maximised) over the decision variables or model parameters. Example: the least-squares loss \(L(a, b) = \sum_i(y_i - ax_i - b)^2\) for a line fit.

8.1.1, 8.1.2 · slides 280–283

Unconstrained and constrained optimisation

Unconstrained optimisation minimises \(f(x)\) over all \(x \in \mathbb{R}^d\); constrained optimisation restricts \(x\) to a feasible set given by constraints such as \(g_i(x) \le 0\) and \(h_j(x) = 0\).

8.1.1 · slides 280–281

Gradient descent

The iterative method \(x_{i+1} = x_i - \gamma_i(\nabla f(x_i))^\top\), which steps along the negative gradient, the direction of steepest local descent. Gradient layout: the transpose appears because the deck's gradient is a row vector; with a column gradient the step is \(x_i - \gamma_i\nabla f(x_i)\).

8.2.1, 8.2.2 · slides 287–288

Step size (learning rate)

The positive scalar \(\gamma\) (or \(\alpha\)) that multiplies the descent direction in each update. Too small converges slowly, too large overshoots or diverges; the halving heuristic undoes a step that increases \(f\) and halves \(\gamma\).

8.2.3 · slides 288–289

Condition number

For a symmetric positive definite Hessian or matrix, \(\kappa = \lambda_{\max}/\lambda_{\min}\), the ratio of the largest to the smallest curvature. A large \(\kappa\) (ill-conditioning) makes gradient descent zig-zag and converge slowly.

8.2.2, 9.2.4, 9.2.5 · slides 288, 326–333

Line search and exact line search

Line search chooses the step at each iteration by minimising the objective along the current direction, \(\alpha_t = \arg\min_\alpha J(w_t + \alpha g_t)\). It is exact when this one-dimensional problem is solved exactly (for a quadratic, from \(h'(\gamma) = 0\) in closed form), and then the new gradient is orthogonal to the search direction; otherwise it is inexact.

8.2.4, 8.5.1 · slides 290, 296–298

Unimodal function and bracketing

A function of one variable is unimodal on an interval if it has a single minimum there, decreasing before it and increasing after. Bracketing finds an interval \([0, \alpha_{\max}]\) containing the minimiser, by evaluating at geometrically increasing \(\alpha\) until the value rises.

8.5.2 · slide 299

Binary search (line search)

An interval-halving method for a unimodal \(H(\alpha)\) that compares \(H\) at the midpoint \(\tfrac{a+b}{2}\) and at \(\tfrac{a+b}{2} + \varepsilon\) to learn the sign of the slope, then keeps the half that contains the minimiser.

8.5.3 · slides 300–301

Golden-section search

An interval-elimination method for a unimodal function that evaluates two interior points \(m_1 < m_2\), discards the part beyond the worse one, and places the points at the golden-ratio fraction \(\tau = (\sqrt{5} - 1)/2 \approx 0.618\) of the interval so that one evaluation can be reused. The deck shows the elimination step without the golden ratio.

8.5.4 · slides 302–303

Armijo rule (backtracking line search)

An inexact line search that tries \(\alpha = 1, \tfrac{1}{2}, \tfrac{1}{4}, \dots\) and accepts the first step satisfying the sufficient-decrease condition \(f(w - \alpha g) \le f(w) - c\,\alpha\,g^\top g\), with \(g\) the column gradient and \(c \in (0, 1)\) small.

8.5.5 · slide 304

Newton's method

The second-order iteration \(x_{k+1} = x_k - H(x_k)^{-1}\nabla f(x_k)\) (column gradient), which jumps to the minimiser of the local quadratic Taylor model. Pure Newton takes the full step; damped Newton shortens it with a backtracking (Armijo) search.

7.3.1, 8.5.5 · slides 274–276, 304

Finite-difference gradient check

A test of a computed gradient against the numerical estimate \(\frac{\partial J}{\partial w_i} \approx \frac{J(w + \Delta e_i) - J(w)}{\Delta}\) for small \(\Delta\), done for a few sampled coordinates \(i\). The central difference \(\frac{J(w + \Delta e_i) - J(w - \Delta e_i)}{2\Delta}\) is more accurate.

8.3.1 · slide 291

Learning-rate schedule (decay) and epoch

A schedule reduces the learning rate over training: exponential decay \(\alpha_t = \alpha_0e^{-kt}\), inverse decay \(\alpha_t = \alpha_0/(1 + kt)\), or step decay (multiply by a fixed factor every few epochs), with decay rate \(k > 0\). An epoch is one full pass over the training set, and the deck counts \(t\) in epochs.

8.4.1, 8.4.2 · slides 292–294

Bold driver

An adaptive learning-rate heuristic: after each step that decreases the loss, increase the rate by about 5%; after a step that increases it, undo the step and decrease the rate by about 50%.

8.4.3 · slide 295

Batch, mini-batch and stochastic gradient descent

Batch gradient descent uses the exact gradient of \(L(\theta) = \sum_{n=1}^{N}L_n(\theta)\) over all \(N\) examples at each step, at cost \(O(N)\). Mini-batch gradient descent estimates it from a random subset \(S\), for example \(J(S) = \sum_{i \in S}(w^\top X_i - y_i)^2\), and stochastic gradient descent (SGD) is the case \(\lvert S \rvert = 1\).

8.6.1, 8.6.2 · slides 305–307

Unbiased gradient estimate

A random estimate \(\hat{g}\) of the gradient whose expectation equals the true gradient, \(E[\hat{g}] = \nabla L\). A uniformly sampled mini-batch gradient scaled by \(N/\lvert S \rvert\) is unbiased for the summed loss, and its variance falls as \(\lvert S \rvert\) grows.

8.6.3 · slide 308
M9 · Optimization · 18 items

Overfitting

Fitting the training data so closely (for example reaching zero training error with more parameters than examples) that the model captures noise instead of the true relationship and performs poorly on new data.

9.1.2 · slides 316–318

Feature scaling

Transforming each input feature to a comparable range before training: mean-centring \(x_j - \mu_j\), standardisation (z-score) \((x_j - \mu_j)/\sigma_j\), or min–max scaling \((x_j - \min_j)/(\max_j - \min_j)\). It reduces differential curvature so gradient descent converges faster.

9.1.3, 9.2.5 · slides 319–320, 332–333

Flat regions, cliffs and valleys

Difficult loss landscapes: a flat region (plateau) has gradient close to zero, so progress stalls; a cliff is a region where the gradient changes abruptly, so a fixed step overshoots; a valley is steep across and gentle along, so gradient descent bounces between its walls.

9.2.3 · slides 324–325, 337–340

Differential curvature (ill-conditioning)

The situation in which the second derivatives (curvatures) of the loss differ greatly between directions, as in \(x^2 + 4y^2\) compared with \(x^2 + y^2\). It produces elongated contours and zig-zagging gradient-descent paths, and is measured by the condition number of the Hessian.

9.2.4, 9.2.5 · slides 326–333

Contour line

A level set \(\{x : F(x) = c\}\) of the objective. The gradient at any point is orthogonal to the contour through it, since moving along the contour gives \(\nabla F\,\delta x = 0\).

9.2.4 · slides 329–331

Momentum

A gradient-descent variant that adds a fraction of the previous step, \(x_{i+1} = x_i - \gamma(\nabla f(x_i))^\top + \beta(x_i - x_{i-1})\) with momentum parameter \(\beta \in [0, 1]\). It accelerates movement along consistent directions and damps oscillations.

9.3.1 · slides 341–347

AdaGrad

An adaptive method that keeps, for each parameter, the running sum \(A_i \leftarrow A_i + (\partial J/\partial w_i)^2\) of squared partial derivatives and updates \(w_i \leftarrow w_i - \frac{\alpha}{\sqrt{A_i}}\frac{\partial J}{\partial w_i}\). Its effective learning rates only decrease.

9.3.2 · slides 348–349

RMSProp

An adaptive method like AdaGrad but with an exponentially decaying average \(A_i \leftarrow \rho A_i + (1 - \rho)(\partial J/\partial w_i)^2\), \(\rho \in (0, 1)\), so that old gradients are forgotten and the step does not shrink to zero.

9.3.3 · slide 350

Adam

An adaptive method combining momentum and RMSProp: it keeps exponential averages \(F_i\) of the gradient (decay \(\rho_f\)) and \(A_i\) of its square (decay \(\rho\)) and updates \(w_i \leftarrow w_i - \alpha_tF_i/\sqrt{A_i}\) with bias-corrected rate \(\alpha_t = \alpha\sqrt{1 - \rho^t}/(1 - \rho_f^t)\). Defaults: \(\rho_f = 0.9\), \(\rho = 0.999\).

9.3.4 · slides 351–353

Indicator function

In the deck, \(\mathbf{1}(z) = 0\) if \(z \le 0\) and \(\infty\) if \(z > 0\), so that \(J(x) = f(x) + \sum_i\mathbf{1}(g_i(x))\) equals \(f\) on the feasible set and \(\infty\) outside it.

9.4.1 · slides 354–355

Lagrangian and Lagrange multipliers

For \(\min f(x)\) s.t. \(g_i(x) \le 0\), the Lagrangian is \(\mathfrak{L}(x, \lambda) = f(x) + \sum_i\lambda_ig_i(x) = f(x) + \lambda^\top g(x)\), where the Lagrange multipliers satisfy \(\lambda_i \ge 0\). Multipliers of equality constraints \(h_j(x) = 0\) are unrestricted in sign.

9.4.2, 9.4.4 · slides 356–360

Primal problem, dual function and dual problem

The primal problem is the original constrained minimisation, with optimal value \(p^*\). The dual function \(D(\lambda) = \min_x\mathfrak{L}(x, \lambda)\) is concave in \(\lambda\) even when the primal is not convex, and the dual problem is \(\max_{\lambda \ge 0}D(\lambda)\), with optimal value \(d^*\).

9.4.3, 9.5.4 · slides 357–359, 368

Minimax inequality and weak duality

The minimax inequality states \(\max_y\min_x\varphi(x, y) \le \min_x\max_y\varphi(x, y)\) for any function \(\varphi\). Applied to the Lagrangian it gives weak duality, \(d^* \le p^*\); the non-negative difference \(p^* - d^*\) is the duality gap.

9.4.3 · slides 358–359

Convex set

A set \(C\) such that \(\theta x + (1 - \theta)y \in C\) for all \(x, y \in C\) and \(\theta \in [0, 1]\): it contains the line segment between any two of its points.

9.5.1 · slides 361–362

Convex and concave functions

\(f\) is convex if \(f(\theta x + (1 - \theta)y) \le \theta f(x) + (1 - \theta)f(y)\) for all \(x, y\) and \(\theta \in [0, 1]\) (every chord lies above the graph); for differentiable \(f\) this is \(f(y) \ge f(x) + \nabla f(x)(y - x)\). \(f\) is concave if \(-f\) is convex.

9.5.1 · slides 361–363

Convex optimisation problem

Minimising a convex objective \(f\) subject to convex inequality constraints \(g_i(x) \le 0\) and affine equality constraints \(h_j(x) = 0\). Every local minimum of such a problem is global.

9.5.1 · slide 361

Linear program

An optimisation problem with a linear objective and linear constraints, \(\min_xc^\top x\) s.t. \(Ax \le b\). Its dual is \(\max_\lambda -\lambda^\top b\) s.t. \(c + A^\top\lambda = 0\), \(\lambda \ge 0\).

9.5.2 · slides 364–365

Quadratic program

An optimisation problem with a quadratic objective and linear constraints, \(\min_x\tfrac{1}{2}x^\top Qx + c^\top x\) s.t. \(Ax \le b\), with \(Q\) symmetric. For \(Q\) positive definite its dual is \(\max_{\lambda \ge 0} -\tfrac{1}{2}(c + A^\top\lambda)^\top Q^{-1}(c + A^\top\lambda) - \lambda^\top b\).

9.5.3 · slides 366–367
M10 · Principal component analysis · 12 items

Dimensionality reduction

Representing data \(x_n \in \mathbb{R}^D\) by lower-dimensional vectors \(z_n \in \mathbb{R}^M\), \(M < D\), while keeping as much of the relevant structure as possible. It exploits redundancy: high-dimensional data are often overcomplete.

10.1.1 · slides 372–373

Principal component analysis (PCA)

A linear dimensionality-reduction method (Pearson 1900, Hotelling 1933) that projects centred data onto the \(M\)-dimensional subspace of maximum variance, equivalently of minimum average reconstruction error. That subspace is spanned by the eigenvectors of the data covariance matrix with the \(M\) largest eigenvalues.

10.1.1, 10.2.2, 10.3.1 · slides 373, 379–393

Data covariance matrix

For centred data, \(S = \frac{1}{N}\sum_{n=1}^{N}x_nx_n^\top \in \mathbb{R}^{D \times D}\), symmetric positive semidefinite. PCA data layout: with the points as the columns of \(X \in \mathbb{R}^{D \times N}\) (the deck) \(S = \frac{1}{N}XX^\top\); with the points as rows (the question bank's Module 10) \(S = \frac{1}{N}X^\top X\). Some texts use \(\frac{1}{N-1}\), which rescales the eigenvalues only.

10.1.3 · slides 374–377

Centring and standardisation

Centring subtracts the mean, \(x_n \leftarrow x_n - \mu\) with \(\mu = \frac{1}{N}\sum_nx_n\); standardisation also divides each feature \(d\) by its standard deviation \(\sigma_d\). PCA requires centring; standardisation is used when features have different units or scales.

10.1.3, 10.7.1 · slides 376–377, 415–420

Principal components and principal subspace

The principal components (principal directions) \(b_1, \dots, b_M\) are orthonormal eigenvectors of \(S\) ordered by decreasing eigenvalue \(\lambda_1 \ge \lambda_2 \ge \dots\); the variance of the data along \(b_m\) is \(\lambda_m\). Their span is the principal subspace.

10.2.2, 10.2.5 · slides 379–392

Code and reconstruction

With \(B = [b_1, \dots, b_M] \in \mathbb{R}^{D \times M}\) orthonormal, the code (low-dimensional representation) of a centred point is \(z = B^\top x \in \mathbb{R}^M\) and its reconstruction is \(\tilde{x} = Bz = BB^\top x \in \mathbb{R}^D\).

10.1.2 · slides 374–375

Projection matrix

A matrix \(P\) with \(P^2 = P\); it is an orthogonal projection if also \(P = P^\top\). For orthonormal \(B\), \(BB^\top\) projects onto the span of the columns of \(B\), and \(I - BB^\top\) onto its orthogonal complement.

10.1.2, 10.2.4 · slides 375, 388–390

Deflation

Removing from the data the part already explained by the first \(m - 1\) components, \(\hat{X} = X - B_{m-1}X\) with \(B_{m-1} = \sum_{i<m}b_ib_i^\top\) (points as columns), so that the top direction of the remaining data is the \(m\)-th principal component.

10.2.4, 10.2.5 · slides 388–392

Explained variance and reconstruction error

The variance explained by \(M\) components is \(\sum_{m=1}^{M}\lambda_m\), and the explained-variance ratio divides it by the total variance \(\sum_{d=1}^{D}\lambda_d = \operatorname{tr}S\). The average squared reconstruction error \(\frac{1}{N}\sum_n\lVert x_n - \tilde{x}_n \rVert^2\) equals the sum of the discarded eigenvalues \(\sum_{d>M}\lambda_d\).

10.3.1, 10.4.1 · slides 393, 398, 423

Power iteration

The iterative method \(x_{k+1} = \frac{Sx_k}{\lVert Sx_k \rVert}\), which converges to the eigenvector of the largest eigenvalue when \(\lvert\lambda_1\rvert > \lvert\lambda_2\rvert\) and the starting vector has a non-zero component along it.

10.6.2 · slides 410–411

Abel–Ruffini theorem

There is no general formula in radicals for the roots of polynomials of degree 5 or higher. Hence eigenvalues of large matrices cannot be found from the characteristic polynomial in closed form and must be computed iteratively.

10.6.1 · slides 408–409

Gram matrix

The matrix of all pairwise inner products of a set of vectors, \(G_{ij} = x_i^\top x_j\); for data stored as the columns of \(X \in \mathbb{R}^{D \times N}\) it is the \(N \times N\) matrix \(X^\top X\). PCA with \(N \ll D\) eigendecomposes \(\frac{1}{N}X^\top X\) instead of \(S\), and a kernel matrix is a Gram matrix in feature space.

10.6.3, 11.6.1 · slides 412–414, 520–522
M11 · Mathematics of support vector machines · 21 items

Binary classification and linear separability

Binary classification assigns each input \(x \in \mathbb{R}^D\) to one of two classes, labelled \(y \in \{-1, +1\}\) in the SVM lectures. A labelled data set is linearly separable if some hyperplane has all points of one class strictly on one side and the other class on the other, \(y_n(w^\top x_n + b) > 0\) for every \(n\).

11.2.1 · slides 440–445

Feature map

A function \(\varphi : \mathbb{R}^D \to \mathcal{H}\) that sends each input to a (usually higher-dimensional) feature space, in which data that are not linearly separable may become separable. Example: \(\varphi(x) = (1, x_1^2, \sqrt{2}x_1x_2, x_2^2, \sqrt{2}x_1, \sqrt{2}x_2)\).

11.2.1, 11.6.3 · slides 446, 528–533

Hyperplane and linear classifier

A hyperplane is a set \(\{x : w^\top x + b = 0\}\) with normal vector \(w \ne 0\) (orthogonal to the plane) and bias \(b\). The linear classifier it defines predicts \(\hat{y} = \operatorname{sign}(w^\top x + b)\).

11.2.2 · slides 442–451

Signed distance to a hyperplane

The signed distance of \(x_a\) from the hyperplane \(w^\top x + b = 0\) is \(r = \frac{w^\top x_a + b}{\lVert w \rVert}\), positive on the side \(w\) points to; for a correctly classified point \(y_a(w^\top x_a + b)/\lVert w \rVert\) is its (positive) distance.

11.2.3 · slides 452–455

Margin

The width of the empty band around the decision boundary, bounded by the hyperplanes \(w^\top x + b = \pm 1\) through the closest points. Margin convention: this site uses margin \(= 2/\lVert w \rVert\) (full width, as slides 487, 511 and 549) and half-margin \(= 1/\lVert w \rVert\) (the distance from the boundary to the closest point, which slide 452 calls the margin).

11.2.3, 11.2.4 · slides 452, 487, 511, 549

Canonical hyperplane

The scaling of \((w, b)\), always possible because positive rescaling does not move the plane, for which the closest training points satisfy \(y_n(w^\top x_n + b) = 1\) and all points satisfy \(y_n(w^\top x_n + b) \ge 1\).

11.2.4 · slides 456–461

Hard-margin SVM

The maximum-margin classifier for linearly separable data, found from the primal quadratic program \(\min_{w, b}\tfrac{1}{2}\lVert w \rVert^2\) subject to \(y_n(w^\top x_n + b) \ge 1\) for all \(n\). It is equivalent to maximising the margin (MML Theorem 12.1).

11.2.4 · slides 456–461

SVM dual problem

\(\max_\alpha\sum_i\alpha_i - \tfrac{1}{2}\sum_i\sum_j\alpha_i\alpha_jy_iy_jx_i^\top x_j\) subject to \(\sum_i\alpha_iy_i = 0\) and \(\alpha_i \ge 0\) (hard margin) or \(0 \le \alpha_i \le C\) (soft margin), with one multiplier \(\alpha_i\) per training point. The primal solution is recovered as \(w = \sum_i\alpha_iy_ix_i\).

11.3.1, 11.5.3 · slides 462–471, 506–508

Support vectors

The training points with \(\alpha_i > 0\) in the dual solution; in the hard-margin case they lie exactly on \(y_i(w^\top x_i + b) = 1\). Only they determine \(w\) and \(b\).

11.3.2, 11.4.1, 11.4.2 · slides 471–487, 512–515

Strong duality and Slater's condition

Strong duality is \(p^* = d^*\) (zero duality gap), so the dual can be solved in place of the primal. Slater's condition guarantees it for a convex problem (convex \(f\) and \(g_i\), affine \(h_j\)): some strictly feasible \(\bar{x}\) has \(g_i(\bar{x}) < 0\) for all \(i\) and \(h_j(\bar{x}) = 0\) for all \(j\).

11.1.2 · slides 434–436

Karush–Kuhn–Tucker (KKT) conditions

For \(\min f\) s.t. \(g_i \le 0\), \(h_j = 0\): primal feasibility (\(g_i(x^*) \le 0\), \(h_j(x^*) = 0\)), dual feasibility (\(\lambda_i^* \ge 0\)), complementary slackness (\(\lambda_i^*g_i(x^*) = 0\)) and stationarity (\(\nabla f(x^*) + \sum_i\lambda_i^*\nabla g_i(x^*) + \sum_j\nu_j^*\nabla h_j(x^*) = 0\)). Under strong duality they are necessary for optimality, and for convex problems also sufficient.

11.1.3 · slides 437–439, 463

Complementary slackness

The KKT condition \(\lambda_ig_i(x^*) = 0\) for each inequality constraint: either the constraint is active (\(g_i = 0\)) or its multiplier is zero. In the SVM, \(\alpha_i[y_i(w^\top x_i + b) - 1] = 0\), so only points on the margin can have \(\alpha_i > 0\).

11.1.3, 11.3.2 · slides 437–439, 471–480

Soft-margin SVM and slack variables

The SVM for data that are not separable: \(\min\tfrac{1}{2}\lVert w \rVert^2 + C\sum_n\xi_n\) s.t. \(y_n(w^\top x_n + b) \ge 1 - \xi_n\), \(\xi_n \ge 0\). The slack \(\xi_n\) measures the margin violation of point \(n\): \(0 < \xi_n \le 1\) inside the margin but correct, \(\xi_n > 1\) misclassified.

11.5.1 · slides 457–458, 488–495

Regularisation parameter C

The positive constant \(C\) that weights the total slack against the margin term in the soft-margin objective. Large \(C\) penalises violations heavily and approaches the hard margin; small \(C\) allows a wider margin with more violations.

11.5.1, 11.6.5 · slides 488–495, 540–549

Hinge loss and 0–1 loss

The hinge loss of a prediction \(f(x) = w^\top x + b\) is \(\max(0, 1 - yf(x))\): zero when \(yf(x) \ge 1\), between 0 and 1 for a correct point inside the margin, above 1 for a misclassified point. The 0–1 loss is 0 for a correct and 1 for a wrong classification; slide 488 confuses the two.

11.5.2 · slides 488–505

Subgradient

For a convex function that is not differentiable at a point (such as the hinge loss at \(yf(x) = 1\)), any vector \(g\) with \(f(y) \ge f(x) + g^\top(y - x)\) for all \(y\). Subgradient descent uses it in place of the gradient.

11.5.2 · slides 491–496

Box constraint

The constraint \(0 \le \alpha_i \le C\) on the soft-margin dual variables, which follows from \(\mu_i = C - \alpha_i \ge 0\), where \(\mu_i\) is the multiplier of \(\xi_i \ge 0\).

11.5.3 · slides 506–508

Kernel function and kernel trick

A kernel is a function \(K(x, x') = \varphi(x)^\top\varphi(x')\) that computes an inner product in a feature space. The kernel trick replaces every inner product \(x_i^\top x_j\) in the SVM dual and decision function by \(K(x_i, x_j)\), so the feature map never has to be computed.

11.6.1 · slides 520–522

Kernel matrix and Mercer's condition

The kernel (Gram) matrix of points \(x_1, \dots, x_N\) is \(K_{ij} = K(x_i, x_j)\). Mercer's condition: a symmetric function \(K\) is a valid kernel exactly when its kernel matrix is positive semidefinite for every finite set of points.

11.6.1, 11.6.2 · slides 520–527

Linear, polynomial, Gaussian and sigmoid kernels

Linear \(K = x^\top x'\); polynomial \(K = (1 + x^\top x')^p\); Gaussian (RBF) \(K = \exp(-\gamma\lVert x - x' \rVert^2)\) with \(\gamma > 0\); sigmoid \(K = \tanh(\beta_0x^\top x' + \beta_1)\). The first three are valid kernels; the sigmoid is not positive semidefinite for all parameters.

11.6.2, 11.6.3 · slides 523–533

XOR problem

The four points \((\pm 1, \pm 1)\) labelled by the sign of \(-x_1x_2\), the standard example of data that are not linearly separable. With the kernel \((1 + x^\top x')^2\) the SVM separates them with the boundary \(x_1x_2 = 0\).
