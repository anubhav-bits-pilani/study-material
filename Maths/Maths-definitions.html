Lecture 1 — Linear Algebra: Systems & Matrices · source: Lecture 1.pdf

Vector

Any object that can be added to another object of the same kind and multiplied by a scalar to yield another object of that kind — e.g. tuples in \(\mathbb{R}^n\), geometric arrows, or polynomials.

Lecture 1 · p2

Closure

The property that applying an operation (addition or scaling) to members of a set always yields another member of the same set.

Lecture 1 · p3

Linear system solution count

A system of linear equations has exactly zero, one, or infinitely many solutions — no other possibility exists.

Lecture 1 · p8

Matrix

An \((m,n)\) array of \(mn\) real numbers \(a_{ij}\) arranged in \(m\) rows and \(n\) columns; \(\mathbb{R}^{m\times n}\) denotes all such real matrices. Row and column vectors are the \(1\times n\) and \(m\times 1\) cases.

Lecture 1 · p18

Matrix inverse

For a square matrix \(A\), the matrix \(A^{-1}\) satisfying \(AA^{-1}=A^{-1}A=I\); it exists if and only if \(\det(A)\neq0\).

Lecture 1 · p22-24

Transpose

The matrix \(A^{T}\) obtained by writing the rows of \(A\) as columns, i.e. \((A^{T})_{ij}=a_{ji}\).

Lecture 1 · p25

Particular solution

Any single vector \(x_p\) that satisfies the system \(Ax=b\).

Lecture 1 · p32

General solution

The complete solution set of \(Ax=b\), expressed as a particular solution plus every solution of the homogeneous system \(Ax=0\).

Lecture 1 · p37

Gaussian elimination

The procedure of applying solution-preserving elementary row operations to reduce a matrix to (reduced) row-echelon form so that solutions can be read off.

Lecture 1 · p38-40

Elementary row operations

The three operations that preserve a system's solution set: swapping two rows, multiplying a row by a non-zero constant, and adding a multiple of one row to another.

Lecture 1 · p40

Augmented matrix

The coefficient matrix with the right-hand-side vector appended as an extra column, \([A\,|\,b]\), on which row operations are performed.

Lecture 1 · p42

Row-echelon form

A matrix in which all-zero rows are at the bottom and each row's leading non-zero entry (pivot) lies strictly to the right of the pivot in the row above, forming a staircase.

Lecture 1 · p50

Pivot, basic & free variables

A pivot is the first non-zero entry of a non-zero row. Variables at pivot columns are basic (pivot) variables; variables at non-pivot columns are free variables.

Lecture 1 · p50

Reduced row-echelon form (RREF)

A row-echelon form in which every pivot equals 1 and is the only non-zero entry in its column, so pivot columns look like canonical basis vectors.

Lecture 1 · p53
Lecture 2 — Vector Spaces & Linear Independence · source: Lecture_2.pdf

Group

A set \(G\) with an operation \(\otimes\) that is closed, associative, has an identity element, and gives every element an inverse.

Lecture 2 · p4

Abelian group

A group whose operation is also commutative: \(x\otimes y=y\otimes x\) for all \(x,y\).

Lecture 2 · p4

Vector space

A set \(V=(V,+,\cdot)\) where \((V,+)\) is an Abelian group and scalar multiplication satisfies distributivity, associativity of scaling, and the identity \(1\cdot x=x\).

Lecture 2 · p6-7

Vector subspace

A non-empty subset \(U\subseteq V\) that is itself a vector space under the inherited operations, i.e. closed under addition and scalar multiplication.

Lecture 2 · p10

Null space

The set of all solutions to the homogeneous system \(Ax=0\); it is a vector subspace.

Lecture 2 · p13

Linear combination

A weighted sum \(\sum_i\lambda_i x_i\) of vectors \(x_i\) with scalar coefficients \(\lambda_i\).

Lecture 2 · p14

Linear (in)dependence

Vectors are linearly dependent if some non-trivial combination equals the zero vector; they are linearly independent if only the all-zero coefficients give the zero vector.

Lecture 2 · p16

Span / generating set

The span of a set is the collection of all its linear combinations; the set is a generating set of \(V\) when its span equals \(V\).

Lecture 2 · p33-34

Basis

A minimal generating set of a vector space — equivalently a maximal linearly independent set — in which every vector has a unique representation.

Lecture 2 · p35-36

Dimension

The number of vectors in any basis of a finite-dimensional vector space, denoted \(\dim(V)\).

Lecture 2 · p39
Lecture 3 — Norms, Inner Products & Orthogonality · source: Lecture_3.pdf

Norm

A function \(\lVert\cdot\rVert:V\to\mathbb{R}\) assigning a length to each vector, satisfying absolute homogeneity, the triangle inequality, and positive definiteness.

Lecture 3 · p4

Inner product

A symmetric, positive-definite bilinear map \(\langle\cdot,\cdot\rangle:V\times V\to\mathbb{R}\); the dot product is the standard example.

Lecture 3 · p5-6

Bilinear mapping

A two-argument mapping that is linear in each argument separately.

Lecture 3 · p5

Inner product space

A vector space equipped with an inner product, written \((V,\langle\cdot,\cdot\rangle)\).

Lecture 3 · p6

Symmetric positive-definite matrix

A symmetric matrix \(A\) with \(x^{T}Ax>0\) for all \(x\neq0\); it has full rank and strictly positive diagonal entries, and defines a valid inner product.

Lecture 3 · p7-8

Metric

A distance function \(d(x,y)=\lVert x-y\rVert\) that is positive-definite, symmetric, and satisfies the triangle inequality; with the dot product it is the Euclidean distance.

Lecture 3 · p11-12

Orthogonal vectors

Two vectors whose inner product is zero (\(x\perp y\)); the zero vector is orthogonal to every vector.

Lecture 3 · p16

Orthogonal (orthonormal) matrix

A square matrix whose columns are orthonormal, so \(A^{T}A=AA^{T}=I\) and \(A^{T}=A^{-1}\); it preserves lengths and angles.

Lecture 3 · p17

Orthonormal basis

A basis whose vectors are mutually orthogonal and each of unit length; if only mutually orthogonal, it is an orthogonal basis.

Lecture 3 · p22-23

Gram–Schmidt process

A procedure that converts a given basis into an orthogonal (then orthonormal) basis, here realised via Gaussian elimination on \([A^{T}A\,|\,A^{T}]\).

Lecture 3 · p24-25

Elementary matrix

An identity matrix with a single below-diagonal entry made non-zero; pre-multiplying by it performs one row operation.

Lecture 3 · p26

LU decomposition

The factorisation \(A=LU\) of a matrix into a lower-triangular \(L\) and an upper-triangular \(U\), arising from Gaussian elimination.

Lecture 3 · p28-29
Lecture 4 — Determinant, Trace, Eigenvalues & Cholesky · source: Lecture_4.pdf

Determinant

A scalar associated with a square matrix, computed by cofactor expansion; it is non-zero exactly when the matrix has full rank / is invertible.

Lecture 4 · p4

Minor & cofactor

The minor \(M_{jk}\) is the determinant of the submatrix obtained by deleting row \(j\) and column \(k\); the cofactor is \(C_{jk}=(-1)^{j+k}M_{jk}\).

Lecture 4 · p5

Trace

The sum of the diagonal entries of a square matrix, \(\text{tr}(A)=\sum_i a_{ii}\).

Lecture 4 · p13

Characteristic polynomial

The degree-\(n\) polynomial \(p_A(\lambda)=\det(A-\lambda I)\), whose roots are the eigenvalues of \(A\).

Lecture 4 · p14

Eigenvalue & eigenvector

A scalar \(\lambda\) and non-zero vector \(x\) with \(Ax=\lambda x\); \(A\) scales \(x\) without changing its direction.

Lecture 4 · p17

Eigenspace

The subspace \(E_\lambda\) of all eigenvectors for a given eigenvalue \(\lambda\) (plus the zero vector); it equals the null space of \(A-\lambda I\).

Lecture 4 · p20-21

Spectrum

The set of all eigenvalues of a matrix.

Lecture 4 · p20

Algebraic & geometric multiplicity

Algebraic multiplicity is how many times \(\lambda\) appears as a root of the characteristic polynomial; geometric multiplicity is \(\dim(E_\lambda)\). For symmetric matrices they are equal.

Lecture 4 · p24

Spectral theorem

Every symmetric real matrix has an orthonormal basis of eigenvectors with all-real eigenvalues, giving the factorisation \(A=Q\Lambda Q^{T}\).

Lecture 4 · p23-24, p30

Hermitian matrix

A complex matrix equal to its conjugate transpose, \(A^{H}=A\); the complex generalisation of a symmetric matrix.

Lecture 4 · p26

Cholesky decomposition

The unique factorisation \(A=LL^{T}\) of a symmetric positive-definite matrix into a lower-triangular \(L\) with positive diagonal entries.

Lecture 4 · p32
Lecture 5 — Diagonalization & SVD · source: Lecture_5.pdf

Diagonal matrix

A matrix whose off-diagonal entries are all zero.

Lecture 5 · p4

Diagonalizable matrix

A matrix \(A\) for which an invertible \(P\) exists with \(P^{-1}AP\) diagonal; equivalently \(A\) has a full set of independent eigenvectors.

Lecture 5 · p5

Eigenvalue decomposition

The factorisation \(A=PDP^{-1}\) where \(P\)'s columns are eigenvectors and \(D\) is the diagonal matrix of eigenvalues.

Lecture 5 · p7

Singular value decomposition (SVD)

The factorisation \(A=U\Sigma V^{T}\) valid for any \(m\times n\) matrix, with orthogonal \(U,V\) and rectangular \(\Sigma\) holding the singular values.

Lecture 5 · p12

Singular values

The non-negative diagonal entries \(\sigma_i\) of \(\Sigma\), ordered decreasingly; they are the square roots of the non-zero eigenvalues of \(A^{T}A\).

Lecture 5 · p12-13

Left / right singular vectors

The right-singular vectors (columns of \(V\)) are eigenvectors of \(A^{T}A\); the left-singular vectors (columns of \(U\)) are eigenvectors of \(AA^{T}\).

Lecture 5 · p15-16

Rank-k approximation

The matrix \(\hat{A}(k)=\sum_{i=1}^{k}\sigma_i u_i v_i^{T}\) obtained by truncating the SVD sum at \(k\lt r\) terms; the best rank-\(k\) approximation of \(A\).

Lecture 5 · p28

Spectral norm

The matrix norm \(\lVert A\rVert_2=\max_{x\neq0}\lVert Ax\rVert_2/\lVert x\rVert_2\), equal to the largest singular value of \(A\).

Lecture 5 · p29-30
Lecture 6 — Differentiation, Gradients & Jacobian · source: Lecture_6.pdf

Derivative

The limit \(\frac{df}{dx}=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}\); it gives the direction of steepest ascent of a univariate function.

Lecture 6 · p4

Taylor polynomial

A degree-\(n\) polynomial built from a function's derivatives at \(x_0\) that approximates the function near \(x_0\).

Lecture 6 · p7

Taylor series / Maclaurin series

The infinite Taylor expansion of a smooth function; the Maclaurin series is the special case with \(x_0=0\).

Lecture 6 · p8

Partial derivative

The derivative of a multivariate function with respect to one variable while holding the others constant.

Lecture 6 · p15

Gradient

The row vector of all partial derivatives of \(f:\mathbb{R}^n\to\mathbb{R}\); it points in the direction of steepest ascent.

Lecture 6 · p16

Jacobian

The \(m\times n\) matrix of all first partial derivatives \(\partial f_i/\partial x_j\) of a vector-valued function \(f:\mathbb{R}^n\to\mathbb{R}^m\).

Lecture 6 · p25

Hessian

The symmetric matrix of all second partial derivatives of a scalar function; it describes local curvature and classifies critical points.

Lecture 6 · p14 (prereq)

Critical (stationary) point

A point where the gradient vanishes, \(\nabla f=0\); classified as a minimum, maximum, or saddle by the definiteness of the Hessian.

Lecture 6 · p3 (prereq)
Lecture 7 — Backpropagation & Automatic Differentiation · source: Lecture-7.pdf

Backpropagation

An efficient algorithm that computes the gradient of a network's loss with respect to all parameters by applying the chain rule backward through layers and reusing intermediate results.

Lecture 7 · p5-6

Automatic differentiation

A technique that decomposes a function into elementary operations on a computation graph and mechanically propagates derivatives; reverse mode is backpropagation.

Lecture 7 · p15

Computation graph

A directed graph whose nodes are input, intermediate, and output variables \(x_i=g_i(x_{\text{Pa}(x_i)})\), with edges to their parent nodes.

Lecture 7 · p15

Sigmoid function

The activation \(\sigma(z)=1/(1+e^{-z})\) with derivative \(\sigma'(z)=\sigma(z)(1-\sigma(z))\), applied element-wise in a layer.

Lecture 7 · p17

Error signal (delta)

The backpropagated gradient of the loss with respect to a layer's activation or pre-activation, e.g. \(\delta(a)=\partial L/\partial a\), \(\delta(Z)=\partial L/\partial Z\).

Lecture 7 · p16-18

Hadamard product

The element-wise product \(\odot\) of two equal-sized vectors or matrices, multiplying corresponding entries.
