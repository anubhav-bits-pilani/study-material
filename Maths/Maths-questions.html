Q1. Compute the product \(AB\) where \(A=\begin{bmatrix}1&2\\3&4\end{bmatrix}\), \(B=\begin{bmatrix}2&0\\1&5\end{bmatrix}\). [2 Marks]

Each entry \(c_{ij}=\sum_l a_{il}b_{lj}\).
\(c_{11}=1\cdot2+2\cdot1=4\), \(c_{12}=1\cdot0+2\cdot5=10\),
\(c_{21}=3\cdot2+4\cdot1=10\), \(c_{22}=3\cdot0+4\cdot5=20\).
$$AB=\begin{bmatrix}4&10\\10&20\end{bmatrix}$$

Q5. Solve the system by Gaussian elimination: $$\begin{aligned}x_1+2x_2+x_3&=2\\ 2x_1+x_2-x_3&=1\\ x_1-x_2+2x_3&=3\end{aligned}$$ [3 Marks]

Augmented \([A\mid b]=\left[\begin{array}{ccc|c}1&2&1&2\\2&1&-1&1\\1&-1&2&3\end{array}\right]\).
\(R_2\leftarrow R_2-2R_1:\ (0,-3,-3\mid-3)\); \(R_3\leftarrow R_3-R_1:\ (0,-3,1\mid1)\).
\(R_3\leftarrow R_3-R_2:\ (0,0,4\mid4)\Rightarrow x_3=1\).
From \(R_2\): \(-3x_2-3(1)=-3\Rightarrow x_2=0\).
From \(R_1\): \(x_1+0+1=2\Rightarrow x_1=1\).
$$x=(1,\,0,\,1)^T$$

Q9. Find matrices \(A,B\) such that \(A^{-1},B^{-1}\) and \((A+B)^{-1}\) all exist but \((A+B)^{-1}\neq A^{-1}+B^{-1}\). [1 Mark]

Take \(A=B=I\) (2×2). Then \(A^{-1}=B^{-1}=I\) and \(A+B=2I\) is invertible with \((A+B)^{-1}=\tfrac12 I\).
But \(A^{-1}+B^{-1}=I+I=2I\neq\tfrac12 I\).
Hence \((A+B)^{-1}\neq A^{-1}+B^{-1}\) in general — the inverse is not additive.

Q2. State \(\dim(\text{span}\{(0,1)^T\})\) and explain why it differs from the number of components. [1 Mark]

The span is a single line \(\{(0,t)^T:t\in\mathbb{R}\}\); one vector forms a basis, so the dimension is \(\mathbf{1}\).
The vectors have 2 components, but dimension counts basis vectors (degrees of freedom), not component count.

Q3. Is \((\mathbb{N}_0,+)\) (non-negative integers under addition) a group? Justify using the group axioms. [1 Mark]

Closed, associative, has identity \(0\). But it is not a group: elements lack additive inverses (e.g. \(3\) has no \(x\in\mathbb{N}_0\) with \(3+x=0\)). \((\mathbb{Z},+)\) fixes this and is Abelian.
tests: group / Abelian axioms · Easy

Q4. Determine whether \(x_1=(1,2,1)^T\), \(x_2=(2,1,0)^T\), \(x_3=(1,-4,-3)^T\) are linearly independent. [3 Marks]

Put them as columns and row-reduce \(\begin{bmatrix}1&2&1\\2&1&-4\\1&0&-3\end{bmatrix}\).
\(R_2\leftarrow R_2-2R_1:(0,-3,-6)\); \(R_3\leftarrow R_3-R_1:(0,-2,-4)\).
\(R_3\leftarrow R_3-\tfrac23 R_2:(0,0,0)\). Only 2 pivots for 3 vectors.
A non-trivial dependence exists (\(x_3=... \), a zero row appears) ⇒ linearly dependent. Indeed \(x_1-2x_2+? \): solving gives \(x_3=3x_1-2x_2\). Check: \(3(1,2,1)-2(2,1,0)=(-1,4,3)=-x_3\). ✓

Q5. The vectors \((1,2,3)^T,(2,4,6)^T,(1,0,1)^T\) span a subspace \(U\subseteq\mathbb{R}^3\). Find a basis and \(\dim(U)\). [2 Marks]

Second vector \(=2\times\) first, so it is redundant. Keep \((1,2,3)^T\) and \((1,0,1)^T\); these are not multiples of each other, hence independent.
Basis \(\{(1,2,3)^T,(1,0,1)^T\}\), \(\dim(U)=\mathbf{2}\).

Q6. Let \(V=\mathbb{R}^2\). Determine whether \(W=\{(x,2)\mid x\in\mathbb{R}\}\) is a subspace of \(V\). [1 Mark]

A subspace must contain \(0=(0,0)^T\). But \((0,0)\notin W\) (second coordinate is fixed at 2). Also not closed under addition: \((x,2)+(x',2)=(x+x',4)\notin W\).
Therefore \(W\) is not a subspace.
tests: subspace test · Medium

Q7. Prove that the null space \(N(A)=\{x\in\mathbb{R}^n:Ax=0\}\) is a subspace of \(\mathbb{R}^n\). [3 Marks]

Use the subspace test.
(i) Non-empty: \(A\,0=0\), so \(0\in N(A)\).
(ii) Closed under addition: if \(x,y\in N(A)\) then \(A(x+y)=Ax+Ay=0+0=0\), so \(x+y\in N(A)\).
(iii) Closed under scaling: for \(\lambda\in\mathbb{R}\), \(A(\lambda x)=\lambda Ax=\lambda\,0=0\), so \(\lambda x\in N(A)\).
All three hold, so \(N(A)\) is a subspace. \(\blacksquare\)
tests: prove subspace (null space) · Hard
Hard

Q8. Let \(V=\mathbb{R}^2\) with inner operation \(x\oplus y=(x_1+y_1+1,\ x_2+y_2+1)^T\) and outer operation \(k\cdot(x_1,x_2)^T=(kx_1,kx_2)^T\). Prove or disprove that \((V,\oplus,\cdot)\) is a vector space over \(\mathbb{R}\). [2 Marks]

Check the distributive axiom \((k+l)\cdot x=(k\cdot x)\oplus(l\cdot x)\).
LHS \(=((k+l)x_1,(k+l)x_2)^T\).
RHS \(=(kx_1,kx_2)^T\oplus(lx_1,lx_2)^T=(kx_1+lx_1+1,\ kx_2+lx_2+1)^T=((k+l)x_1+1,(k+l)x_2+1)^T\).
LHS \(\neq\) RHS (differ by \((1,1)^T\)). The distributive law fails, so \(V\) is not a vector space.
(Also: the additive identity would be \((-1,-1)^T\), not \((0,0)^T\), and \(1\cdot x=x\) is fine, but one failed axiom already disproves it.)
tests: prove/disprove vector space · Hard
Hard

Q9. Let \(B=[b_1,b_2]\) have independent columns and set \(x_1=b_1+b_2\), \(x_2=b_1-b_2\), \(x_3=2b_1\). Are \(x_1,x_2,x_3\) independent? Prove your answer using coefficient vectors and the \(m\gt k\) rule. [2 Marks]

Coefficient vectors: \(\lambda_1=(1,1)^T,\ \lambda_2=(1,-1)^T,\ \lambda_3=(2,0)^T\) in \(\mathbb{R}^2\).
Since \(\{b_i\}\) are independent, \(\{x_j\}\) are independent iff \(\{\lambda_j\}\) are. But we have \(m=3\) vectors in a \(k=2\)-dimensional space; \(m\gt k\) forces dependence.
Explicitly \(\lambda_3=\lambda_1+\lambda_2\Rightarrow x_3=x_1+x_2\). Hence dependent. \(\blacksquare\)
tests: independence of transformed vectors, m>k rule · Hard

Q9. Let \(\Sigma=\begin{bmatrix}4&2\\2&5\end{bmatrix}\). (a) Prove \(\Sigma\) is symmetric positive-definite. (b) Compute the Cholesky factor \(L\) with \(\Sigma=LL^T\). [4 Marks]

(a) Symmetric since \(\Sigma^T=\Sigma\). Leading principal minors: \(4\gt0\) and \(\det\Sigma=20-4=16\gt0\) ⇒ positive-definite (Sylvester's criterion). Equivalently for \(x\neq0\), \(x^T\Sigma x=4x_1^2+4x_1x_2+5x_2^2=(2x_1+x_2)^2+4x_2^2\gt0\).
(b) \(l_{11}=\sqrt4=2\); \(l_{21}=a_{21}/l_{11}=2/2=1\); \(l_{22}=\sqrt{a_{22}-l_{21}^2}=\sqrt{5-1}=2\).
$$L=\begin{bmatrix}2&0\\1&2\end{bmatrix},\quad LL^T=\begin{bmatrix}4&2\\2&5\end{bmatrix}=\Sigma\ ✓$$ The condition in (a) is necessary because Cholesky requires the square roots \(\sqrt{a_{ii}-\sum l_{ik}^2}\) to be real and positive — guaranteed only for SPD matrices.
