Module 2 — Neuron & Perceptron · source: DNN_M2_ANN_Perceptron.pdf

Weighted Sum / Net Input (Pre-activation)

$$z=\sum_{i=1}^{n} w_i x_i + b = w^\top x + b$$

where: \(x_i\)=input features; \(w_i\)=weights (feature importance); \(b\)=bias; \(z\)=net input / logit / pre-activation.

use: the linear part of every neuron; the activation function is applied to \(z\).

DNN_M2 · p12

Artificial Neuron Output

$$\hat y = f\!\left(\sum_{i=1}^{n} w_i x_i + b\right) = f(w^\top x + b)$$

where: \(f(\cdot)\)=activation function; \(\hat y\)=neuron output.

use: general form of a single neuron; choose \(f\) per task (identity/sigmoid/softmax/ReLU).

DNN_M2 · p12

Augmented Notation (bias as \(w_0\))

$$\tilde x=[1,x_1,\dots,x_n]^\top,\quad w=[w_0,w_1,\dots,w_n]^\top,\quad h=w^\top\tilde x$$

where: \(w_0\)=bias term absorbed into the weight vector; \(\tilde x\)=augmented input with a leading 1.

use: lets a single dot product include the bias; used throughout perceptron/regression algebra.

DNN_M2 · p48

Perceptron Step / Sign Activation

$$\hat y=\begin{cases}1 & \text{if } w^\top x+b\ge 0\\ -1\ (\text{or }0) & \text{otherwise}\end{cases}$$

where: threshold at 0; classical output \(\{-1,+1\}\), logic-gate output \(\{0,1\}\).

use: perceptron / hard binary decision; not differentiable, so trained by the perceptron rule.

DNN_M2 · p23,34

Perceptron Learning Rule

$$w_i \leftarrow w_i + \eta\,(t-\hat y)\,x_i,\qquad b \leftarrow b + \eta\,(t-\hat y)$$

where: \(\eta\)=learning rate; \(t\)=target label; \(\hat y\)=predicted label; update only on misclassification.

use: trains a perceptron; converges in finite steps if data is linearly separable.

DNN_M2 · p33,50

Linear Separability / Decision Boundary

$$w_1x_1+w_2x_2+\dots+w_nx_n+b=0$$

where: an \((n{-}1)\)-D hyperplane in \(n\)-D space (a line in 2D).

use: perceptron boundary; XOR has no single such line, motivating multilayer nets.

Module 3 — Linear Regression · source: DNN_M3_Linear NN Regression (1).pdf · L2-Linear Regression.ipynb

Linear Regression Hypothesis

$$\hat y = w_0 + w_1x_1 + \dots + w_dx_d = w^\top x,\qquad \hat{\mathbf y}=Xw$$

where: \(x\in\mathbb R^{d+1}\) (augmented); \(w\in\mathbb R^{d+1}\); \(X\in\mathbb R^{N\times(d+1)}\)=design matrix; identity activation \(f(z)=z\).

use: prediction for regression; the vectorized form \(Xw\) computes all \(N\) predictions at once.

DNN_M3 · p7,14

Identity Activation & Derivative

$$f(z)=z,\qquad f'(z)=1$$

where: used at the output for regression.

use: passes value & gradient through unchanged; enables gradient-based optimisation for continuous targets.

DNN_M3 · p15-16

Squared Error — Single Example

$$\ell(w;x^{(i)},y^{(i)})=\tfrac12\big(\hat y^{(i)}-y^{(i)}\big)^2=\tfrac12\big(w^\top x^{(i)}-y^{(i)}\big)^2$$

where: \(\tfrac12\)=convenience factor that cancels in the derivative.

use: per-example regression loss; sum/average gives the cost.

DNN_M3 · p17

Mean Squared Error Cost (MSE)

$$J(w)=\frac{1}{N}\sum_{i=1}^{N}\tfrac12\big(w^\top x^{(i)}-y^{(i)}\big)^2=\frac{1}{2N}\lVert Xw-y\rVert^2$$

where: \(N\)=#examples; \(\lVert\cdot\rVert^2=(Xw-y)^\top(Xw-y)\).

use: convex objective for linear regression; minimise to find \(w^*=\arg\min_w J(w)\).

DNN_M3 · p17-18

Gradient of MSE

$$\nabla J(w)=\frac{1}{N}\sum_{i=1}^{N}\big(w^\top x^{(i)}-y^{(i)}\big)x^{(i)}=\frac{1}{N}X^\top(Xw-y)$$

where: \(X^\top\in\mathbb R^{(d+1)\times N}\); \((Xw-y)\in\mathbb R^N\); \(\nabla J\in\mathbb R^{d+1}\).

use: the descent direction for batch GD; note the recurring "error × input" structure.

DNN_M3 · p22

Batch Gradient Descent Update

$$w^{(t+1)}=w^{(t)}-\eta\,\nabla J(w^{(t)})=w^{(t)}-\frac{\eta}{N}X^\top\big(Xw^{(t)}-y\big)$$

where: \(\eta\)=learning rate; stop when \(\lVert\nabla J\rVert<\epsilon\) or max iterations.

use: iterative weight optimisation using all examples per step.

DNN_M3 · p21,23

Bias / Weight Gradient (notebook form)

$$\frac{\partial J}{\partial w}=\frac1N X^\top(\hat{\mathbf y}-\mathbf y),\qquad \frac{\partial J}{\partial b}=\frac1N\sum_{i=1}^{N}(\hat y^{(i)}-y^{(i)})$$

where: \(\hat{\mathbf y}-\mathbf y\)=residual/error vector.

use: exact gradients implemented in the L2 lab; update \(w\!\mathrel{-}=\!\eta\partial_w J\), \(b\!\mathrel{-}=\!\eta\partial_b J\).

L2-Linear Regression.ipynb

Normal Equation (closed form)

$$w^*=(X^\top X)^{-1}X^\top y$$

where: requires \(X^\top X\) invertible; no learning rate or iterations needed.

use: exact least-squares solution; used to verify GD / check "is the update moving toward the optimum" in exam problems.

L2-Linear Regression.ipynb · EC-2 Q4

Evaluation: MSE, RMSE, MAE

$$\text{MSE}=\frac1N\sum(\hat y^{(i)}-y^{(i)})^2,\quad \text{RMSE}=\sqrt{\text{MSE}},\quad \text{MAE}=\frac1N\sum|y^{(i)}-\hat y^{(i)}|$$

where: RMSE is in target units; MAE is robust to outliers.

use: report regression accuracy on the test set.

DNN_M3 · p34

R² (Coefficient of Determination)

$$R^2=1-\frac{\sum_{i}(y^{(i)}-\hat y^{(i)})^2}{\sum_{i}(y^{(i)}-\bar y)^2}=1-\frac{SS_{\text{res}}}{SS_{\text{tot}}}$$

where: \(\bar y=\frac1N\sum y^{(i)}\)=mean target; \(SS_{\text{res}}\)=residual sum of squares; \(SS_{\text{tot}}\)=total.

use: fraction of variance explained; 1=perfect, 0=predicts mean, <0=worse than baseline.

DNN_M3 · p35

Feature Scaling

$$\text{Min-Max: } x'_j=\frac{x_j-\min(x_j)}{\max(x_j)-\min(x_j)},\qquad \text{Z-score: } x'_j=\frac{x_j-\mu_j}{\sigma_j}$$

where: \(\mu_j,\sigma_j\)=feature mean & std.

use: standardise features before GD so no feature dominates; critical for fast convergence.

Module 4 — Classification (Logistic, Softmax, SGD) · source: DNN_M4_Linear NN Classification.pdf

Sigmoid Function & Derivative

$$\sigma(z)=\frac{1}{1+e^{-z}},\qquad \sigma'(z)=\sigma(z)\big(1-\sigma(z)\big)$$

where: range (0,1); \(\sigma(0)=0.5\), \(\sigma'(0)=0.25\) (max); symmetry \(\sigma(-z)=1-\sigma(z)\).

use: binary-classification output; derivative computed from the function value itself.

DNN_M4 · p13-14 · Numerical p45

Logistic Regression Model

$$z=w^\top x,\qquad \hat y=\sigma(z)=\frac{1}{1+e^{-w^\top x}}=P(y=1\mid x)$$

where: \(\hat y\in[0,1]\)=probability of class 1.

use: binary classification; predict class 1 if \(\hat y\ge0.5\) (i.e. \(w^\top x\ge0\)).

DNN_M4 · p12,19-20

Binary Cross-Entropy (single & total)

$$\ell=-\big[y\log\hat y+(1-y)\log(1-\hat y)\big],\quad J(w)=-\frac1N\sum_{i=1}^{N}\big[y^{(i)}\log\hat y^{(i)}+(1-y^{(i)})\log(1-\hat y^{(i)})\big]$$

where: \(y\in\{0,1\}\); if \(y{=}1\), \(\ell=-\log\hat y\); if \(y{=}0\), \(\ell=-\log(1-\hat y)\).

use: loss for binary classification; convex with sigmoid, penalises confident errors.

DNN_M4 · p21-22

BCE Gradient (per example)

$$\nabla_w\ell=\big(\hat y^{(i)}-y^{(i)}\big)\,x^{(i)}$$

where: \(\hat y^{(i)}=\sigma(w^\top x^{(i)})\); "error × input" — same structure as linear regression.

use: SGD weight update for logistic regression (sigmoid+BCE pairing gives this clean form).

DNN_M4 · p26

BCE Derivative w.r.t. Output

$$\frac{\partial\ell}{\partial\hat y}=\frac{\hat y-y}{\hat y(1-\hat y)}$$

where: derivative before combining with the sigmoid derivative.

use: chained with \(\sigma'\) it simplifies to \(\hat y-y\); explains why sigmoid+BCE is numerically well-behaved.

Numerical · p72

SGD Update Rule

$$w^{(t+1)}=w^{(t)}-\eta\,\nabla\ell\big(w^{(t)};x^{(i)},y^{(i)}\big)$$

where: one randomly-selected example \((x^{(i)},y^{(i)})\) per step; shuffle each epoch.

use: fast, low-memory training; noisy path but escapes sharp minima.

DNN_M4 · p25,27

Softmax Function

$$\text{softmax}(z)_k=\hat y_k=\frac{e^{z_k}}{\sum_{j=1}^{K}e^{z_j}}=P(y=k\mid x)$$

where: \(z_k=w_k^\top x\)=logit for class \(k\); outputs in (0,1) summing to 1.

use: multi-class output activation; predicted class = \(\arg\max_k\hat y_k\).

DNN_M4 · p57

Numerically-Stable Softmax

$$\text{softmax}(z)_k=\frac{e^{z_k-c}}{\sum_j e^{z_j-c}},\qquad c=\max_k z_k$$

where: subtracting the max leaves softmax unchanged (translation invariance) but prevents overflow.

use: always subtract \(\max(z)\) before exponentiating in code / numericals (log-sum-exp trick).

DNN_M4 · p91 · Numerical p58

Multi-class Logits (batch)

$$z=W^\top x\in\mathbb R^{K},\qquad Z=XW\in\mathbb R^{N\times K}$$

where: \(W\in\mathbb R^{(d+1)\times K}\)=weight matrix (one column \(w_k\) per class).

use: compute all class scores; apply softmax row-wise to get \(\hat Y\).

DNN_M4 · p54,56

Categorical Cross-Entropy

$$J(W)=-\frac1N\sum_{i=1}^{N}\sum_{k=1}^{K}y_k^{(i)}\log\hat y_k^{(i)}$$

where: \(y^{(i)}\)=one-hot label; only the true class's term contributes per example.

use: multi-class loss; reduces to BCE when \(K=2\).

DNN_M4 · p61

Softmax + CE Gradient

$$\frac{\partial\ell}{\partial z_j}=\hat y_j-y_j$$

where: derived by chaining \(\partial\ell/\partial\hat y_i=-y_i/\hat y_i\) with the softmax Jacobian \(\hat y_k(\delta_{kj}-\hat y_j)\).

use: the elegant "predicted − true" gradient; core of multi-class backprop.

DNN_M4 · p68 · Numerical p49,61

Mini-batch Gradient & Update

$$\nabla_W J_{\mathcal B}=\frac1B X_{\mathcal B}^\top(\hat Y_{\mathcal B}-Y_{\mathcal B}),\qquad W^{(t+1)}=W^{(t)}-\frac{\eta}{B}X_{\mathcal B}^\top(\hat Y_{\mathcal B}-Y_{\mathcal B})$$

where: \(B\)=batch size (32–256); \(X_{\mathcal B},\hat Y_{\mathcal B},Y_{\mathcal B}\)=mini-batch inputs, predictions, one-hot labels.

use: standard deep-learning optimiser — vectorized, stable, GPU-efficient.

DNN_M4 · p68-69

Iterations per Epoch

$$\text{iterations/epoch}=\left\lceil \frac{N}{B}\right\rceil$$

where: \(N\)=dataset size; \(B\)=batch size. E.g. \(N{=}60000, B{=}128\Rightarrow469\).

use: plan training length / weight-update count (× epochs).

DNN_M4 · p67

Confusion-Matrix Metrics

$$\text{Acc}=\frac{TP+TN}{TP+TN+FP+FN},\ \text{Prec}=\frac{TP}{TP+FP},\ \text{Rec}=\frac{TP}{TP+FN},\ F_1=\frac{2\,\text{Prec}\cdot\text{Rec}}{\text{Prec}+\text{Rec}}$$

where: TP/TN/FP/FN from the confusion matrix; \(F_1\)=harmonic mean.

use: evaluate classifiers; pick metric by error cost (precision vs recall) — critical for imbalanced data.

DNN_M4 · p40-41,43

Macro & Weighted Averages, Top-K

$$\text{Prec}_{\text{macro}}=\frac1K\sum_k \text{Prec}_k,\quad \text{Prec}_{\text{wt}}=\sum_k \frac{N_k}{N}\text{Prec}_k,\quad \text{Top-}K=\frac1N\sum_i \mathbb 1[y^{(i)}\in\text{Top-}K(\hat y^{(i)})]$$

where: per-class metrics combined equally (macro) or by frequency (weighted); Top-K counts a hit if the true class is among the top K predictions.

use: multi-class evaluation, especially with many/imbalanced classes.

Module 5 — DFNN, Forward Prop & Backpropagation · source: DNN_M5_DFNN (1).pdf

Layer Pre-activation & Activation

$$z^{(\ell)}=h^{(\ell-1)}W^{(\ell)}+b^{(\ell)},\qquad h^{(\ell)}=\sigma^{(\ell)}\big(z^{(\ell)}\big),\qquad h^{(0)}=x,\ \hat y=h^{(L)}$$

where: \(W^{(\ell)}\in\mathbb R^{n_{\ell-1}\times n_\ell}\); \(b^{(\ell)}\in\mathbb R^{n_\ell}\); \(\sigma^{(\ell)}\)=layer activation (element-wise).

use: one layer of forward propagation; chain across \(\ell=1\dots L\).

DNN_M5 · p19

Vectorized Forward Pass (mini-batch)

$$H^{(0)}=X_{\mathcal B},\quad Z^{(\ell)}=H^{(\ell-1)}W^{(\ell)}+\mathbf 1_B\,b^{(\ell)\top},\quad H^{(\ell)}=\sigma^{(\ell)}(Z^{(\ell)}),\quad \hat Y_{\mathcal B}=H^{(L)}$$

where: \(\mathbf 1_B\in\mathbb R^{B\times1}\)=ones vector broadcasting the bias; \(H^{(\ell)}\in\mathbb R^{B\times n_\ell}\).

use: compute predictions for a whole batch; cost \(O(B\sum_\ell n_{\ell-1}n_\ell)\).

DNN_M5 · p20,30

Total Parameters

$$\text{Params}=\sum_{\ell=1}^{L} n_\ell\,(n_{\ell-1}+1)$$

where: \(n_{\ell-1}\cdot n_\ell\) weights \(+\ n_\ell\) biases per layer.

use: size a network / answer "parameters in the first hidden layer" exam questions.

DNN_M5 · p21

Task Loss Functions

$$\text{MSE}=\tfrac12\lVert\hat y-y\rVert^2,\quad \text{BCE}=-[y\log\hat y+(1-y)\log(1-\hat y)],\quad \text{CCE}=-\sum_{k=1}^{C}y_k\log\hat y_k$$

where: choose by task — regression / binary / multi-class.

use: per-example loss; batch loss \(J=\frac1B\sum_{i\in\mathcal B}\ell^{(i)}\).

DNN_M5 · p22,31

Mini-batch SGD Parameter Update

$$W^{(\ell)}\leftarrow W^{(\ell)}-\eta\,\frac{\partial J}{\partial W^{(\ell)}},\qquad b^{(\ell)}\leftarrow b^{(\ell)}-\eta\,\frac{\partial J}{\partial b^{(\ell)}}$$

where: \(\eta>0\)=learning rate; gradients from backprop.

use: the actual learning step for every layer of a DFNN.

DNN_M5 · p24

Output-Layer Error Signal

$$\delta^{(L)}=\frac{\partial J}{\partial Z^{(L)}}=\frac1B\big(\hat Y-Y\big)$$

where: holds for all three matched pairs — MSE+identity, BCE+sigmoid, CCE+softmax.

use: the starting point of backpropagation.

DNN_M5 · p32

Backpropagation — Error Recursion

$$\delta^{(\ell)}=\big(\delta^{(\ell+1)}W^{(\ell+1)\top}\big)\odot\sigma'^{(\ell)}\big(z^{(\ell)}\big)$$

where: \(\odot\)=element-wise (Hadamard) product; \(\sigma'^{(\ell)}\)=activation derivative at that layer.

use: propagate the error signal from layer \(\ell{+}1\) back to layer \(\ell\); the core backprop equation.

DNN_M5 · p34

Parameter Gradients from \(\delta\)

$$\frac{\partial J}{\partial W^{(\ell)}}=\frac1B\,H^{(\ell-1)\top}\delta^{(\ell)},\qquad \frac{\partial J}{\partial b^{(\ell)}}=\frac1B\,\mathbf 1_B^\top\delta^{(\ell)}$$

where: the same \(\delta^{(\ell)}\) feeds both weight and bias gradients.

use: compute gradients once error signals are known; then apply the SGD update.

DNN_M5 · p35

Single-Example Update (vector form)

$$W^{(\ell)}\leftarrow W^{(\ell)}-\eta\,h^{(\ell-1)\top}\delta^{(\ell)},\qquad b^{(\ell)}\leftarrow b^{(\ell)}-\eta\,\delta^{(\ell)}$$

where: the \(B=1\) special case of the batch gradients.

use: hand-computable update used in the numerical worked examples.

DNN_M5 · p39

Chain Rule (backprop foundation)

$$\frac{\partial J}{\partial z^{(\ell)}}=\frac{\partial J}{\partial h^{(\ell)}}\frac{\partial h^{(\ell)}}{\partial z^{(\ell)}},\qquad \frac{\partial J}{\partial h^{(\ell)}}=\delta^{(\ell+1)}W^{(\ell+1)\top},\quad \frac{\partial h^{(\ell)}}{\partial z^{(\ell)}}=\sigma'^{(\ell)}(z^{(\ell)})$$

where: composition of local derivatives through the network.

use: derives every backprop equation; the key idea that makes deep-net training tractable.

DNN_M5 · p34
Numerical Methods — Activation & Loss Derivatives, Gradient Flow · source: DNN_M5_DFNN_Numerical.pdf

Tanh & Derivative

$$\tanh(z)=\frac{e^{z}-e^{-z}}{e^{z}+e^{-z}},\qquad \tanh'(z)=1-\tanh^2(z)=\frac{4}{(e^z+e^{-z})^2}$$

where: range (−1,1), zero-centred, odd; \(\tanh'(0)=1\) (max, 4× sigmoid).

use: hidden-layer activation with stronger gradients than sigmoid.

Numerical · p50-51

ReLU & Derivative

$$\text{ReLU}(z)=\max(0,z),\qquad \text{ReLU}'(z)=\begin{cases}1 & z>0\\ 0 & z\le0\end{cases}$$

where: range [0,∞); gradient 1 for positive inputs, 0 otherwise (dead-neuron zone).

use: default hidden activation; cheap and avoids vanishing gradients for \(z>0\).

Numerical · p56 · DNN_M5 p37

MSE & MAE Derivatives

$$\ell_{\text{MSE}}=\tfrac12(\hat y-y)^2\Rightarrow\frac{\partial\ell}{\partial\hat y}=\hat y-y,\qquad \ell_{\text{MAE}}=|\hat y-y|\Rightarrow\frac{\partial\ell}{\partial\hat y}=\text{sign}(\hat y-y)$$

where: MSE gradient scales with error; MAE gradient is constant ±1 (robust to outliers, undefined at 0).

use: regression backprop; MAE for outlier-heavy data.

Numerical · p65,68

Cross-Entropy Derivative (w.r.t. output)

$$\ell=-\sum_{c}y_c\log\hat y_c\ \Rightarrow\ \frac{\partial\ell}{\partial\hat y_j}=-\frac{y_j}{\hat y_j}$$

where: with one-hot \(y\), only the true class \(k\) gives \(-1/\hat y_k\); others 0.

use: combined with the softmax Jacobian to yield \(\hat y_j-y_j\).

Numerical · p75-76

Gradient-Flow (Vanishing) Recursion

$$|\delta^{[l-1]}|=|\delta^{[l]}|\cdot\lVert W^{[l]}\rVert\cdot|g'^{[l-1]}|$$

where: \(\lVert W^{[l]}\rVert\)=spectral norm; \(g'\)=activation derivative. Sigmoid \(g'\le0.25\).

use: quantify vanishing/exploding gradients — e.g. factor \(0.8\times0.25=0.2\)/layer shrinks \(|\delta|\) fast.

Numerical · p33-34

Network Design Heuristics

$$L\le\log_2\!\big(M/(d\cdot c)\big)+1,\qquad \text{Parameters}\le \frac{M}{5}$$

where: \(M\)=#training samples; \(d\)=#features; \(c\)=#classes; \(L\)=#layers.

use: pick depth and cap capacity so the model isn't over-parameterised for the data.

Numerical · p36-41

Two-Layer Numerical Forward/Backward (reference)

$$z^{[1]}=W^{[1]}x+b^{[1]},\ a^{[1]}=\text{ReLU}(z^{[1]});\quad z^{[2]}=W^{[2]}a^{[1]}+b^{[2]},\ a^{[2]}=\sigma(z^{[2]})$$ $$\delta^{[2]}=a^{[2]}-y,\ \tfrac{\partial L}{\partial W^{[2]}}=\delta^{[2]}(a^{[1]})^\top;\quad \delta^{[1]}=\big(W^{[2]\top}\delta^{[2]}\big)\odot\text{ReLU}'(z^{[1]}),\ \tfrac{\partial L}{\partial W^{[1]}}=\delta^{[1]}x^\top$$

where: the exact template of the EC-2 exam Q3 (2→3 ReLU→2 sigmoid, BCE).

use: memorise this full forward→loss→backward→update chain for hand computation.

Perceptron Forward Pass & Activation

$$Z=XW+b,\qquad A=\text{sign}(Z)=\begin{cases}+1 & Z\ge0\\ -1 & Z<0\end{cases}$$

where: \(X\)=batch of inputs; \(W,b\)=weights/bias initialised to 0; output \(\pm1\).

use: OR/AND/XOR gate demo — computes predictions for all examples at once.

Perceptron Cost (hinge-style)

$$J=\frac1m\sum_{i=1}^{m}\max\!\big(0,\,-y^{(i)}x^{(i)}W\big)$$

where: \(m\)=#examples; penalises misclassified points (where \(y\cdot(xW)<0\)).

use: cost tracked over iterations to visualise convergence (flat for XOR — never converges).

L1-Perceptron.ipynb

Perceptron Weight/Bias Update (batch)

$$W\leftarrow W-\frac{\alpha}{2}\,X^\top(A-Y),\qquad b\leftarrow b-\frac{\alpha}{2}\sum_{i}(A^{(i)}-Y^{(i)})$$

where: \(\alpha\)=learning rate (0.1); \((A-Y)\)=prediction error.

use: the vectorized perceptron learning rule as implemented in the L1 lab.

$$x_2=-\frac{W_0}{W_1}x_1-\frac{b}{W_1}$$

where: derived from \(W_0x_1+W_1x_2+b=0\); plotted against the data points.

use: visualise how the trained perceptron separates the classes.

Softmax Jacobian (element-wise)

$$\frac{\partial\,\hat y_i}{\partial z_j}=\hat y_i\,(\delta_{ij}-\hat y_j),\qquad \frac{\partial\,\hat y_i}{\partial z_i}=\hat y_i(1-\hat y_i)\ (\text{diagonal})$$

where: \(\hat y=\text{softmax}(z)\); \(\delta_{ij}=1\) if \(i{=}j\) else 0; the diagonal term is the "own-class" sensitivity.

use: exact derivative of softmax before chaining with the loss; in the 3-output worked example only the diagonal \(\hat y_i(1-\hat y_i)=[0.1218,0.2492,0.2370]\) is used to backprop each output.

Three-Layer Worked Backprop (per-weight chain)

$$\frac{\partial E}{\partial W^{(\ell)}_{jk}}=\underbrace{\frac{\partial E}{\partial a_k}}_{\text{upstream error}}\cdot\underbrace{\frac{\partial a_k}{\partial z_k}}_{\text{activation}'}\cdot\underbrace{\frac{\partial z_k}{\partial W_{jk}}}_{=\,a^{(\ell-1)}_j}$$

where: \(a^{(\ell-1)}_j\)=incoming activation on the weight; activation′ is softmax/sigmoid/ReLU derivative for that layer; upstream error is accumulated from all downstream nodes.

use: the exact hand-computation template of the DFFNNUMERICAL 3→3→3→3 example — "(upstream error) × (local activation derivative) × (incoming activation)" per weight, then \(W'=W-lr\cdot\partial W\).
