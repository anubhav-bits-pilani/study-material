Q1. State the containment relationship between Artificial Intelligence (AI), Machine Learning (ML) and Deep Learning (DL), and give a one-line definition of each. (01+02 = 03 Marks)

Relationship: DL ⊂ ML ⊂ AI (each is a subset of the previous).
• AI = the broad science of making machines perform tasks that normally require human intelligence.
• ML = an approach to AI in which a machine learns to perform a task from experience/data rather than hand-coded rules.
• DL = a subset of ML that uses artificial neural networks with multiple (≥3) layers to learn progressively higher-level representations from data.

Q2. Name the four core components every deep-learning problem must have, and say which component gradient descent belongs to. (02+01 = 03 Marks)

The four components are: (1) Data to learn from; (2) a Model that transforms data into predictions; (3) an Objective / loss function measuring how well the model does; (4) a learning algorithm that adjusts parameters to optimise the objective.
Gradient descent is the learning algorithm (component 4) — it searches for the parameters that minimise the loss.

Q4. A team observes that their logistic-regression model's accuracy plateaus as they add more training data, whereas a large neural network keeps improving. Explain this behaviour using the "scale drives DL" intuition, and list two enabling factors that make training such large networks feasible today. (02+02 = 04 Marks)

Traditional ML models (logistic regression, SVM) have limited capacity, so their performance saturates once they have enough data to fit their simple hypothesis. Large neural networks have far greater capacity and automatically learn features, so given more data + more parameters they keep improving (Andrew Ng's scaling intuition: bigger network + more data → better performance).
Enabling factors (any two): large volumes of unstructured data (images/text/audio), cheap high-quality sensors, cheap compute (GPUs/clusters), and cheap storage.

Q5. Define "objective/loss function" and state the convention about whether it should be maximised or minimised. What is the "family of models"? (02+01 = 03 Marks)

A loss function is a formal measure of how good or bad a model is. By convention lower is better, so it is minimised during training.
The family of models is the set of all input→output mappings reachable by varying the model's parameters; training selects the member of this family with the smallest loss.

Q8. Explain why a single perceptron cannot represent the XOR function, and what structural change fixes it. Reference the linear-separability condition. (03 Marks)

XOR outputs 1 for \((0,1),(1,0)\) and 0 for \((0,0),(1,1)\). These two classes cannot be separated by any single straight line \(w_1x_1+w_2x_2+b=0\) — no linear boundary puts the diagonal pairs on the same side, so the data is not linearly separable. A single perceptron only draws one hyperplane, so it fails.
Fix: add a hidden layer with non-linear activations (a multilayer perceptron). The hidden layer re-maps inputs into a space where the classes become linearly separable, then the output neuron combines them.
tests: XOR not linearly separable · Medium

Q9. Train a perceptron for the NOT gate. Single input \(x\in\{0,1\}\); model \(\hat y=f(w_1x+w_0)\) with step output in \(\{0,1\}\); start \(w_1=0,\,w_0=0\), \(\eta=1\). Targets: \(x=0\to t=1\), \(x=1\to t=0\). Perform updates until all examples are classified correctly and give the final weights. (01+03+01 = 05 Marks)

Rule: \(w_1\leftarrow w_1+\eta(t-\hat y)x\), \(w_0\leftarrow w_0+\eta(t-\hat y)\). Present \((x=0),(x=1)\) each epoch.
Epoch 1, \(x=0,t=1\): \(z=0\ge0\Rightarrow\hat y=1\). Correct, no update.
 \(x=1,t=0\): \(z=w_1+w_0=0\ge0\Rightarrow\hat y=1\). Wrong, error \(=-1\): \(w_1=0+(-1)(1)=-1\), \(w_0=0+(-1)=-1\). Now \(w=(w_1,w_0)=(-1,-1)\).
Epoch 2, \(x=0,t=1\): \(z=w_0=-1\lt0\Rightarrow\hat y=0\). Wrong, error \(=+1\): \(w_1=-1+0=-1\) (since \(x=0\)), \(w_0=-1+1=0\). Now \(w=(-1,0)\).
 \(x=1,t=0\): \(z=w_1+w_0=-1\lt0\Rightarrow\hat y=0\). Correct.
Epoch 3: \(x=0\Rightarrow z=0\ge0\Rightarrow1=t\) ✓; \(x=1\Rightarrow z=-1\lt0\Rightarrow0=t\) ✓. All correct.
Final: \(w_1=-1,\ w_0=0\) — matches the deck's NOT-gate solution. Converges because a 1-D NOT gate is linearly separable (Perceptron Convergence Theorem).
tests: perceptron convergence (multi-step) · Hard

Q2. A model fails during training. Setup: input \(x=1\); each layer is a single scalar weight; all weights \(w=2\); \(dL/dy=1\); \(\eta=0.01\).
