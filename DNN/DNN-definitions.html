Module 1 — Deep Learning Fundamentals · source: DNN_M1_Introduction.pdf

Deep Learning

A subset of machine learning using artificial neural networks with multiple processing layers to learn progressively higher-level representations from data.

DNN_M1 · p4

Artificial Intelligence (AI)

The broad science of making machines perform tasks that require human-like intelligence; encompasses machine learning and deep learning plus non-learning approaches.

DNN_M1 · p6

Machine Learning (ML)

An approach to AI in which a machine learns to perform tasks from experience/data rather than from explicit hand-coded rules.

DNN_M1 · p6

Depth (of a model)

The number of layers that contribute to modelling the data; more layers = deeper model.

DNN_M1 · p7

Feature (Covariate)

An input attribute of an example from which the model makes predictions; \(d\) features define the input dimensionality.

DNN_M1 · p23

Label (Target)

In supervised learning, the attribute to be predicted for each example.

DNN_M1 · p23

Model

The computational machinery that ingests data of one type and produces predictions, possibly of a different type; in DL a chain of successive transformations.

DNN_M1 · p25

Objective / Loss Function

A formal measure of how good or bad a model is; by convention lower is better, so it is minimised during training.

DNN_M1 · p26

Learning Algorithm

A procedure that searches for the parameters minimising the loss function; gradient descent is the popular choice in DL.

DNN_M1 · p27

Supervised Learning

Learning to predict labels from input features using a dataset of labelled examples.

DNN_M1 · p32-33

Unsupervised Learning

Learning from data containing only features (no labels), e.g. clustering, density estimation, or synthetic-data generation.

DNN_M1 · p32

Reinforcement Learning

Training an agent that interacts with an environment and takes actions over time steps to maximise reward.

DNN_M1 · p32
Module 2 — Neurons & Perceptron · source: DNN_M2_ANN_Perceptron.pdf

Biological Neuron

A brain cell that receives signals via dendrites, processes them in the soma, and transmits output along its axon through synapses.

DNN_M2 · p8

Artificial Neuron

A processing element that computes a weighted sum of inputs plus a bias and applies an activation function to produce one output.

DNN_M2 · p10-12

Weight

A learnable parameter \(w_i\) scaling input feature \(x_i\), representing that feature's importance; knowledge is stored in the weights.

DNN_M2 · p11

Bias

A learnable offset \(b\) (or \(w_0\)) added to the weighted sum, shifting the activation threshold / decision boundary.

DNN_M2 · p11

Activation Function

A (usually non-linear) function \(f(\cdot)\) applied to a neuron's net input to produce its output signal, which feeds the next layer.

DNN_M2 · p12 · DFFNNUMERICAL p4

Artificial Neural Network (ANN)

A brain-inspired computational model of interconnected neurons (input, hidden, output layers) that learns patterns from data.

DNN_M2 · p15

Connectionism

The principle that intelligence emerges from many simple interconnected neurons, with knowledge stored in connection weights and learning modifying those strengths.

DNN_M2 · p19-20

Perceptron

The simplest artificial neuron (Rosenblatt, 1958): a single-layer linear classifier that outputs the sign/step of the weighted sum.

DNN_M2 · p22

Perceptron Learning Rule

The update \(w_i\leftarrow w_i+\eta(t-\hat y)x_i\) applied to misclassified examples; converges for linearly separable data.

DNN_M2 · p33

Perceptron Convergence Theorem

If the training data is linearly separable, the perceptron learning algorithm is guaranteed to converge in a finite number of steps.

DNN_M2 · p33

Linearly Separable Data

Two classes that can be perfectly separated by an \((n{-}1)\)-dimensional hyperplane in \(n\)-dimensional feature space.

DNN_M2 · p45

XOR Problem

The exclusive-OR function, which is not linearly separable and therefore cannot be solved by a single perceptron — the classic motivation for multilayer networks.

DNN_M2 · p41

Epoch

One complete pass of the learning algorithm through the entire training dataset.

DNN_M2 · p35 · DNN_M4 p67
Module 3 — Regression Terms · source: DNN_M3_Linear NN Regression (1).pdf

Regression

A supervised task that predicts a continuous-valued output \(y\in\mathbb R\) from input features.

DNN_M3 · p4

Linear Regression

A model assuming the output is a linear combination of the input features, \(y=w_0+\sum_i w_ix_i\).

DNN_M3 · p7

Identity Activation

The activation \(f(z)=z\) (derivative 1) used in the output neuron for regression, allowing any real-valued output.

DNN_M3 · p15

Design Matrix

The matrix \(X\in\mathbb R^{N\times(d+1)}\) whose rows are augmented training examples (a leading 1 for the bias).

DNN_M3 · p12

Mean Squared Error (MSE)

The average squared difference between predictions and targets; a convex, differentiable regression loss.

DNN_M3 · p17,34

Gradient Descent

An iterative optimisation that updates parameters opposite the loss gradient, \(w\leftarrow w-\eta\nabla J\), to reach a minimum.

DNN_M3 · p20

Learning Rate (η)

The step-size hyperparameter for gradient descent; too large overshoots/diverges, too small converges slowly.

DNN_M3 · p23

Batch Gradient Descent

Gradient descent that computes the gradient over all \(N\) training examples per update — smooth but slow for large data.

DNN_M3 · p21

RMSE

Root mean squared error, \(\sqrt{\text{MSE}}\); in the same units as the target, making it easier to interpret.

DNN_M3 · p34

MAE

Mean absolute error, the average of \(|y-\hat y|\); a regression metric less sensitive to outliers than MSE.

DNN_M3 · p34

R² (Coefficient of Determination)

The proportion of target variance explained by the model; 1 = perfect fit, 0 = predicts the mean, <0 = worse than baseline.

DNN_M3 · p35

Feature Scaling / Standardization

Transforming features to comparable ranges (min-max to [0,1] or z-score to zero mean/unit variance) so no feature dominates and GD converges faster.

DNN_M3 · p40

Normal Equation

The closed-form least-squares solution \(w^*=(X^\top X)^{-1}X^\top y\), requiring no iterations or learning rate.

Module 4 — Classification Terms · source: DNN_M4_Linear NN Classification.pdf

Classification

A supervised task predicting a discrete class label from input features.

DNN_M4 · p4

Binary Classification

Classification into two classes, \(y\in\{0,1\}\) (or \(\{-1,+1\}\)).

DNN_M4 · p6,8

Multi-class Classification

Classification into \(K>2\) mutually exclusive classes, with output a probability distribution over classes.

DNN_M4 · p6,47

Multi-label Classification

Classification where each example may belong to several classes simultaneously (e.g. multiple movie genres).

DNN_M4 · p6

Logistic Regression

A linear model for binary classification that applies the sigmoid to a weighted sum to output \(P(y=1\mid x)\).

DNN_M4 · p12

Sigmoid (Logistic) Function

\(\sigma(z)=1/(1+e^{-z})\); a smooth monotonic function mapping any real number to (0,1), ideal for probabilities.

DNN_M4 · p13

Logit

The pre-activation value \(z=w^\top x\) before applying sigmoid/softmax; an unbounded real number.

DNN_M4 · p19,56

Decision Boundary

The surface \(w^\top x=0\) (a hyperplane) separating predicted classes, where the predicted probability equals 0.5.

DNN_M4 · p20

Cross-Entropy Loss

A loss derived from maximum likelihood that measures divergence between predicted and true probability distributions; heavily penalises confident wrong predictions.

DNN_M4 · p21,61

Stochastic Gradient Descent (SGD)

Gradient descent that updates weights using one randomly chosen example at a time, giving fast, noisy updates.

DNN_M4 · p25

Mini-batch SGD

Gradient descent using a small batch of \(B\) examples per update — balancing the speed of SGD with the stability of batch GD.

DNN_M4 · p65

Batch Size (B)

The number of examples processed per weight update in mini-batch training (typically 32–256, powers of 2).

DNN_M4 · p67

Softmax Function

An activation converting a vector of logits into a probability distribution (positive values summing to 1) over \(K\) classes.

DNN_M4 · p57

One-Hot Encoding

Representing a class label as a binary vector with a 1 at the true class position and 0 elsewhere.

DNN_M4 · p53

Confusion Matrix

A table of TP, TN, FP, FN counts summarising a classifier's prediction outcomes against true labels.

DNN_M4 · p39

Precision

Of examples predicted positive, the fraction that are truly positive: TP/(TP+FP).

DNN_M4 · p40

Recall (Sensitivity)

Of actual positives, the fraction correctly identified: TP/(TP+FN).

DNN_M4 · p41

F1 Score

The harmonic mean of precision and recall; a balanced metric useful for imbalanced datasets.

DNN_M4 · p41

Accuracy

The fraction of all predictions that are correct; misleading for imbalanced classes.

DNN_M4 · p40,42

Macro / Weighted Average

Ways to combine per-class metrics: macro treats all classes equally; weighted weights each class by its frequency.

DNN_M4 · p87

Top-K Accuracy

A metric counting a prediction correct if the true class is among the model's top K predicted classes; useful for large K.

DNN_M4 · p88
Module 5 — Deep Feed-Forward Networks · source: DNN_M5_DFNN (1).pdf

Deep Feed-Forward Neural Network (DFNN)

A network with one or more hidden layers between input and output where information flows forward through non-linear transformations.

DNN_M5 · p15

Multi-Layer Perceptron (MLP)

A feed-forward network stacking layers of neurons with non-linear activations, capable of learning non-linear decision boundaries (e.g. solving XOR).

DNN_M5 · p7

Hidden Layer

An intermediate layer between input and output that transforms inputs into new feature representations.

DNN_M5 · p7,18

Non-Linearity

A property of a function that violates \(f(ax_1+bx_2)=af(x_1)+bf(x_2)\); essential so stacked layers don't collapse to a single linear map.

DNN_M5 · p10

ReLU

The Rectified Linear Unit \(\max(0,z)\); the default hidden-layer activation — cheap and free of vanishing gradients for positive inputs.

DNN_M5 · p13

Tanh

The hyperbolic tangent activation, range (−1,1), zero-centred with stronger gradients (max derivative 1) than sigmoid.

DNN_M5 · p11 · Numerical p50

Dying ReLU

A failure mode where ReLU neurons always output 0 (and thus never update); addressed by Leaky ReLU, PReLU, or ELU.

DNN_M5 · p13

Forward Propagation

Computing a network's output by passing activations forward layer by layer from input to output.

DNN_M5 · p28

Backpropagation

An algorithm that efficiently computes loss gradients w.r.t. all parameters by applying the chain rule backward through the network.

DNN_M5 · p33

Error Signal (δ)

The gradient of the loss w.r.t. a layer's pre-activation, \(\delta^{(\ell)}=\partial J/\partial z^{(\ell)}\); propagated backward and shared by weight and bias gradients.

DNN_M5 · p33

Chain Rule

The calculus rule for differentiating composed functions; the mathematical foundation of backpropagation.

DNN_M5 · p34

Hadamard Product (⊙)

Element-wise multiplication of two equally-shaped matrices/vectors, used in the backprop error recursion.

DNN_M5 · p34

Depth vs Width

Depth = number of layers (hierarchical features, expressiveness); width = units per layer (capacity, overfitting risk).

DNN_M5 · p44

Universal Approximation Theorem

A single-hidden-layer network with enough neurons can approximate any continuous function on a compact domain (Cybenko/Hornik, 1989).

DNN_M5 · p46

Vanishing Gradients

Gradients shrinking exponentially in early layers so they barely learn; mitigated by ReLU, careful init, and normalization.

DNN_M5 · p47

Exploding Gradients

Gradients growing exponentially large, causing numerical instability (NaN/Inf); mitigated by gradient clipping and proper init.

DNN_M5 · p47

Xavier / Glorot Initialization

A random weight-initialisation scheme suited to sigmoid/tanh layers that keeps signal variance stable across layers.

DNN_M5 · p55

He Initialization

A random weight-initialisation scheme tuned for ReLU activations.

DNN_M5 · p55

Regularization

Techniques (L2/weight decay, dropout, early stopping, batch normalization) that reduce overfitting.

DNN_M5 · p53

Overfitting

When a model fits training data too closely (training loss low, validation loss rising) and generalises poorly.

DNN_M5 · p58-59

Underfitting

When a model is too simple to capture the data's structure, giving high loss on both training and validation sets.

DNN_M5 · p59

Funnel Architecture

A network whose hidden layers decrease in width (\(n_1>n_2>\dots\)), compressing representations — often preferred when data is limited.

DNN_M5 · p51 · EC-2 Q5
Numerical & Lab Terms · source: DNN_M5_DFNN_Numerical.pdf · L1-Perceptron.ipynb · L2-Linear Regression.ipynb

Gradient Flow

How gradient magnitude changes layer-to-layer during backprop; per step it scales by \(\lVert W\rVert\cdot|g'|\), governing vanishing/exploding behaviour.

Numerical · p33

Spectral Norm (‖W‖)

The largest singular value of a weight matrix; used to bound how much a layer amplifies or shrinks the gradient.

Numerical · p33

Dead Neuron

A neuron whose pre-activation is ≤0 under ReLU, so it outputs 0 and receives 0 gradient — its weights don't update.

Numerical · p8,24

Parameter Count

The total learnable weights and biases in a network, \(\sum_\ell n_\ell(n_{\ell-1}+1)\); a proxy for model capacity.

DNN_M5 · p21 · Numerical p37

Binary Cross-Entropy (BCE)

The loss \(-[y\log\hat y+(1-y)\log(1-\hat y)]\) for binary classification with \(y\in\{0,1\}\), \(\hat y\in(0,1)\).

Numerical · p70

Categorical Cross-Entropy (CCE)

The multi-class loss \(-\sum_c y_c\log\hat y_c\) with one-hot \(y\) and softmax \(\hat y\).

Numerical · p74

Feed-Forward vs Feedback ANN

Feed-forward networks have unidirectional flow with no loops (used for classification/recognition); feedback networks allow loops (used for content-addressable memory).

DFFNNUMERICAL · p3-4

Monotonic Function

A function that is entirely non-increasing or non-decreasing; sigmoid, tanh, and ReLU are monotonic.

DFFNNUMERICAL · p7

Sign / Step Activation

The perceptron activation returning \(+1\) if \(z\ge0\) else \(-1\); implemented as \(\text{np.sign}(Z)\) in the L1 lab.

Cost History

The recorded sequence of loss values across training iterations, plotted to visualise convergence (flat for non-separable XOR).
