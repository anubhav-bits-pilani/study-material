Module 1 — Introduction to Deep Learning · source: DNN_M1_Introduction.pdf

What is Deep Learning?

A subset of machine learning based on artificial neural networks that stack multiple layers of processing to extract progressively higher-level features from data. "Deep" refers to adding more layers; typically ≥3 layers.

DNN_M1 · p4

AI vs ML vs DL

AI = making machines perform human tasks; ML = an approach to AI where machines learn from experience; DL = a technique for implementing ML that recognises patterns via layered neural networks. DL ⊂ ML ⊂ AI.

DNN_M1 · p5-6

Depth & Layered Representations

DL learns successive layers of increasingly meaningful representations from data. The number of layers contributing to the model is its depth; representations are learned via neural networks stacked layer on layer.

DNN_M1 · p7

Why Deep Learning Now?

Enabled by large volumes of unstructured data (images/text/audio/video), cheap high-quality sensors, cheap compute (CPU/GPU/clusters), and cheap storage. DL automates feature generation and scales well.

DNN_M1 · p9

Scale Drives DL Progress

As labelled-data volume grows, large neural networks keep improving while traditional ML (logistic regression, SVM) plateaus. Bigger networks + more data → better performance (Andrew Ng's scaling intuition).

DNN_M1 · p10

Four Core Components of a DL Problem

Every DL system needs: (1) Data to learn from, (2) a Model to transform data, (3) an Objective/loss function measuring how well the model does, and (4) a learning algorithm (e.g. gradient descent) that adjusts parameters to optimise the objective.

DNN_M1 · p22

Data: Features, Examples, Labels

Data \(D=\{X,t\}\): each example (sample) has \(d\) features (covariates); \(N\) examples total. In supervised learning the attribute to be predicted is the label/target. More features ⇒ higher dimensionality.

DNN_M1 · p23-24

Objective (Loss) Function

A formal measure of how good/bad a model is. By convention lower is better, so objective functions are called loss functions. Training minimises this loss.

DNN_M1 · p26

Model Family & Training

A model starts as a program whose behaviour depends on parameters. Training finds the best parameters w.r.t. the loss; the set of all input–output mappings reachable by varying parameters is the family of models.

DNN_M1 · p29-30

Kinds of Learning Problems

Supervised (data + labels: classification, regression), Unsupervised (features only: clustering, density estimation, GAN synthesis), and Reinforcement Learning (agent acts in an environment over time). This course focuses on supervised DL.

DNN_M1 · p32

Supervised Learning Tasks

Regression ("how much/how many"), Classification (binary, multi-class, multi-label), Recommender systems, and Sequence learning (tagging/parsing, ASR, TTS, machine translation).

DNN_M1 · p34
Module 2 — Artificial Neural Network / Perceptron · source: DNN_M2_ANN_Perceptron.pdf

Biological Neuron

Dendrites receive signals, the soma (cell body) processes them, the axon transmits the output, and synapses connect neurons. The brain has ~10¹⁰ neurons, each with ~10⁴–10⁵ connections, doing massive parallel computation — inspiration for artificial neurons.

DNN_M2 · p6-8

Artificial Neuron

A processing element that computes a weighted sum of inputs plus a bias, then applies an activation function to produce one output \(\hat y\). Each weight \(w_i\) encodes the importance of feature \(x_i\); knowledge is stored in the weights.

DNN_M2 · p10-12

Biological vs Artificial Neuron

Biological: analog, adaptive synapses, fault-tolerant, learns by experience. Artificial: a simple deterministic math model with adjustable weights that learns via algorithms. Artificial neurons capture the essential computation, greatly simplified.

DNN_M2 · p13

Artificial Neural Network (ANN)

A computational model of interconnected neurons that learns patterns from data through training and can approximate complex functions. Connections may be forward, recurrent, or self-loops; layers are input, hidden, and output.

DNN_M2 · p15-16

When to Use ANNs

Good when input is high-dimensional/noisy, output is discrete/real/vector-valued, the target function form is unknown, and human-readable explanations aren't required — e.g. speech recognition, image classification, financial prediction.

DNN_M2 · p17

Connectionism

Neural networks are connectionist machines: intelligence emerges from many simple neurons, knowledge is stored in connection weights, and learning modifies connection strengths through parallel distributed processing.

DNN_M2 · p19-20

The Perceptron

The simplest artificial neuron (Rosenblatt, 1958): a single-layer linear classifier that outputs a sign/step of the weighted sum. Output is \(+1\) if \(\sum w_ix_i+b\ge0\) else \(-1\) (classical) or \(\{0,1\}\) for logic gates.

DNN_M2 · p22-23

Perceptrons & Logic Gates

Any linearly separable Boolean function (AND, OR, NOT, NAND, NOR) can be represented by a single perceptron by choosing weights/bias that satisfy the truth-table inequalities. One AND solution: \(w_0=-1, w_1=w_2=0.75\); one OR solution: \(w_0=-1, w_1=w_2=2\).

DNN_M2 · p25-31

How the Perceptron Learns

Iteratively: predict \(\hat y=\text{sign}(w^\top x+b)\); if wrong, nudge weights toward the target using the perceptron rule \(w_i\leftarrow w_i+\eta(t-\hat y)x_i\). Guaranteed to converge in finite steps if the data is linearly separable (Convergence Theorem).

DNN_M2 · p33

Worked Example: NOT Gate Learning

Starting from \(w_0=w_1=0\), \(\eta=1\): the algorithm updates on the misclassified example, iterating over epochs until predictions match all targets. Converges to \(w_1=-1, w_0=0\) — demonstrates the update rule step by step.

DNN_M2 · p34-39

The XOR Problem

XOR is not linearly separable — no single line \(w_1x_1+w_2x_2+b=0\) separates its classes, so a single perceptron cannot solve it. Motivates multi-layer networks with non-linear activations.

DNN_M2 · p41-42

Linearly Separable Data

Two point sets are linearly separable in \(n\)-D if an \((n-1)\)-D hyperplane can separate them (a straight line in 2D). Infinitely many separating lines can exist. Separability is the condition for perceptron convergence.

DNN_M2 · p45
Module 3 — Linear Neural Networks for Regression · source: DNN_M3_Linear NN Regression (1).pdf

Regression

A supervised task predicting a continuous-valued output \(y\in\mathbb R\) from features \(x\in\mathbb R^d\); learn \(f:\mathbb R^d\to\mathbb R\) with \(y\approx f(x)\). Examples: house prices, temperature, stock prices.

DNN_M3 · p4-5

Linear Regression

Assumes the output is a linear combination of features: \(y=w_0+w_1x_1+\dots+w_dx_d\). Interpretable and efficient; forms the base case of a neural network.

DNN_M3 · p7-8

Linear Model as a Single Neuron

Linear regression = one neuron computing a weighted sum with an identity activation \(f(z)=z\). Prediction \(\hat y=w^\top x\); vectorized over all examples, \(\hat y = Xw\).

DNN_M3 · p13-14

Identity Activation

\(f(z)=z\), differentiable everywhere with \(f'(z)=1\), output range \((-\infty,\infty)\). Ideal for regression: allows any real output, passes the gradient through unchanged, and loses no information.

DNN_M3 · p15-16

Squared Error Loss (MSE)

Measures fit as the mean of squared residuals \(\tfrac12(\hat y-y)^2\). Differentiable, convex (single global minimum for linear models), penalises large errors quadratically, and corresponds to maximum likelihood under Gaussian noise.

DNN_M3 · p17-18

Gradient Descent

Iteratively move weights opposite the gradient of the loss (steepest descent): \(w\leftarrow w-\eta\nabla J\). The learning rate \(\eta\) sets step size; too large overshoots, too small is slow. Each step moves perpendicular to loss contours toward the minimum.

DNN_M3 · p20-24

Batch Gradient Descent

Uses all \(N\) examples per update. Compute \(\nabla J=\tfrac1N X^\top(Xw-y)\), update, and repeat until \(\|\nabla J\|<\epsilon\) or max iterations. Smooth, deterministic convergence.

DNN_M3 · p21-23

Worked Example: House Price

Tiny 3-point dataset, \(\eta=0.1\), \(w^{(0)}=0\): initial loss 7.5; one GD step gives \(w^{(1)}=[0.367,0.833]\) and loss ≈1.51 — an 80% reduction in one iteration. Illustrates forward pass → error → gradient → update.

DNN_M3 · p26-30

Train vs Test Error

Fit weights on the training set (90–99%) but evaluate on unseen test data (1–10%) to measure generalisation. Goal is to minimise test error, not just training error.

DNN_M3 · p33

Regression Evaluation Metrics

MSE (mean squared error), RMSE (√MSE, same units as target), MAE (mean absolute error, robust to outliers), and R² (fraction of variance explained; 1 = perfect, 0 = predicts the mean, <0 = worse than baseline).

DNN_M3 · p34-35

Implementation Tips

Try \(\eta\in\{0.001,0.01,0.1,1\}\) and plot loss vs iterations; stop on small gradient/loss change or max iterations. Zero init works for linear regression. Feature scaling (standardisation/min-max) is critical for fast convergence.

DNN_M3 · p39-40

Debugging Checklist

NaN/Inf loss → \(\eta\) too large or unscaled features; oscillating loss → \(\eta\) too large; loss not decreasing → \(\eta\) too small or a gradient-sign bug (update must subtract); high test error → overfitting (regularise / more data).

DNN_M3 · p41
Module 4 — Linear Neural Networks for Classification · source: DNN_M4_Linear NN Classification.pdf

Classification

Supervised task predicting a discrete class label \(y\in\{1,\dots,K\}\) from features. Unlike regression's continuous output, classification assigns inputs to categories (spam/not-spam, cat/dog).

DNN_M4 · p4-5

Types of Classification

Binary (\(y\in\{0,1\}\)), Multi-class (\(K>2\), one class per example), and Multi-label (an example may belong to several classes at once, e.g. movie genres).

DNN_M4 · p6

Why Not Linear Regression for Classification?

Linear regression outputs \((-\infty,\infty)\), but we need probabilities in \([0,1]\). A linear model can predict <0 or >1, so we squash the output with a function mapping \((-\infty,\infty)\to[0,1]\) — the sigmoid.

DNN_M4 · p10

Logistic Regression

A linear model + sigmoid for binary classification: compute \(z=w^\top x\), then \(\hat y=\sigma(z)=P(y=1\mid x)\in[0,1]\). It's a single neuron with sigmoid activation.

DNN_M4 · p12,18-19

Sigmoid Activation

\(\sigma(z)=1/(1+e^{-z})\): range (0,1), monotonic, smooth, symmetric (\(\sigma(-z)=1-\sigma(z)\)), with \(\sigma(0)=0.5\). Its derivative \(\sigma'(z)=\sigma(z)(1-\sigma(z))\) (max 0.25 at 0) makes gradient-based learning easy.

DNN_M4 · p13-14

Decision Rule & Boundary

Predict class 1 if \(\hat y\ge0.5\), else 0 — equivalently class 1 when \(w^\top x\ge0\). The decision boundary \(w^\top x=0\) is a hyperplane in feature space.

DNN_M4 · p20

Binary Cross-Entropy Loss

The right loss for classification (not squared error): \(-[y\log\hat y+(1-y)\log(1-\hat y)]\). Derived from maximum likelihood, convex for logistic regression, and heavily penalises confident wrong predictions.

DNN_M4 · p21-23

Stochastic Gradient Descent (SGD)

Update weights using one random example per step, giving a noisy gradient estimate. Much faster and lower-memory than batch GD; the noise helps escape sharp minima. Gradient of BCE per example is the clean \((\hat y-y)x\).

DNN_M4 · p24-27

Worked Example: Pass/Fail SGD

Study-hours dataset, \(\eta=0.5\), \(w^{(0)}=0\): after two SGD iterations weights move to \([0.116,0.847]\) and predictions shift correctly toward 0 for low hours and 1 for high hours — shows forward pass, error, gradient, and update per example.

DNN_M4 · p31-35

Confusion Matrix

Tabulates TP, TN, FP (Type I error), FN (Type II error). Basis for all classification metrics. Diagonal = correct predictions.

DNN_M4 · p39

Classification Metrics

Accuracy = (TP+TN)/total; Precision = TP/(TP+FP); Recall/Sensitivity = TP/(TP+FN); F1 = harmonic mean of precision & recall. Choose based on error costs.

DNN_M4 · p40-41

Which Metric to Use?

Accuracy misleads on imbalanced data. Precision matters when false positives are costly (spam filtering); recall matters when false negatives are costly (disease detection); F1 balances both and suits imbalanced datasets.

DNN_M4 · p42

Multi-class Classification

Assign each input to one of \(K>2\) classes; output a probability distribution over classes summing to 1. Uses \(K\) output neurons and softmax; predicted class = argmax probability.

DNN_M4 · p47

One-Hot Encoding

Represents class \(k\) as a length-\(K\) binary vector (1 at position \(k\), else 0). Treats classes equally (no ordering), matches softmax output format, and simplifies loss computation.

DNN_M4 · p53

Softmax

Converts \(K\) logits into a probability distribution: \(\hat y_k=e^{z_k}/\sum_j e^{z_j}\). Outputs in (0,1) summing to 1, order-preserving, translation-invariant, differentiable, and reduces to sigmoid when \(K=2\).

DNN_M4 · p57-58

Categorical Cross-Entropy

Multi-class loss \(-\sum_k y_k\log\hat y_k\); with one-hot labels only the true class's term contributes. Penalises confident wrong predictions and pairs cleanly with softmax (gradient \(\hat y-y\)).

DNN_M4 · p61-63

Mini-batch SGD

Best of both worlds: update using a small batch of \(B\) examples (typically 32–256). Vectorized (GPU-friendly), less noisy than single-example SGD, more efficient than batch GD. Iterations/epoch = \(\lceil N/B\rceil\).

DNN_M4 · p65-71

Inference (Prediction)

For a new input: compute logits \(z=W^\top x\), apply softmax, pick \(\hat k=\arg\max_k\hat y_k\), optionally reporting the probability as a confidence score.

DNN_M4 · p81-82

Multi-class Metrics & Averaging

Per-class precision/recall/F1 (one-vs-all) combined via macro-average (equal weight) or weighted-average (by class frequency). Top-K accuracy (Top-1/Top-5) is used when \(K\) is large (e.g. ImageNet).

DNN_M4 · p84-88

Comparison of Linear Models

Regression → identity + MSE, output \(\mathbb R\), 1 neuron. Binary → sigmoid + BCE, output [0,1], 1 neuron. Multi-class → softmax + categorical CE, distribution over \(K\), \(K\) neurons (weight matrix \(W\)). Same 4-component framework throughout.

DNN_M4 · p94-97
Module 5 — Deep Feed-Forward Neural Networks · source: DNN_M5_DFNN (1).pdf

Limitation of Linear Models

A single neuron \(\hat y=f(w^\top x+b)\) can only draw a linear decision boundary, so it fails on non-linearly separable problems like XOR. Real-world mappings (images→classes, words→sentiment) are non-linear.

DNN_M5 · p4-6

MLP Solves XOR

Stacking a hidden layer of neurons with non-linear activations re-maps inputs into a new feature space where the classes become linearly separable; the output layer then combines them. Depth + non-linearity enables complex boundaries.

DNN_M5 · p7-8

Why Non-Linearity Matters

Without a non-linear activation, stacked linear layers collapse into a single linear map — so a deep network would be no more expressive than one layer. Non-linear activations let networks learn complex patterns.

DNN_M5 · p10

Activation Functions (Sigmoid, Tanh, ReLU)

Sigmoid (0,1) and tanh (−1,1) saturate and cause vanishing gradients; ReLU \(\max(0,z)\) is cheap, avoids vanishing gradients for \(z>0\), and gives sparse activations. Tanh is zero-centred; Leaky ReLU fixes "dying ReLU".

DNN_M5 · p11-12

Why ReLU Works Well

Fast (just a threshold, no exponentials), gradient of 1 for \(z>0\) flows unchanged enabling deep training, and produces sparse activations. Caveat: "dying ReLU" (always-0 neurons) — mitigated by Leaky ReLU/PReLU/ELU.

DNN_M5 · p13

Deep Feed-Forward Neural Network (DFNN)

A network with one or more hidden layers where information flows forward through non-linear transformations. Same four components as linear models — Data, Model (multi-layer), Objective (loss), Learning (backprop + SGD) — plus depth and non-linearity.

DNN_M5 · p15

Layer-wise Computation

For each layer \(\ell\): pre-activation \(z^{(\ell)}=h^{(\ell-1)}W^{(\ell)}+b^{(\ell)}\), then activation \(h^{(\ell)}=\sigma^{(\ell)}(z^{(\ell)})\), with \(h^{(0)}=x\) and output \(\hat y=h^{(L)}\). Vectorized over a mini-batch for GPU efficiency.

DNN_M5 · p19-20

Parameter Count

Layer \(\ell\) has \(n_\ell(n_{\ell-1}+1)\) parameters (weights + biases). Total is the sum over layers. Example 784→256→128→10 = 235,146 params; deep nets can reach millions/billions.

DNN_M5 · p21

Forward Propagation

Given input \(x\), compute predictions by passing activations forward layer by layer, storing all \(z^{(\ell)}, h^{(\ell)}\) for use in backprop. Cost \(O(B\sum_\ell n_{\ell-1}n_\ell)\) per pass.

DNN_M5 · p28-30

Backpropagation

Efficiently computes gradients of the loss w.r.t. all parameters by applying the chain rule backward. Define error signal \(\delta^{(\ell)}=\partial J/\partial z^{(\ell)}\); propagate it from output to input, then use it for weight/bias gradients. One forward + one backward pass ≈ 2× forward cost (dynamic programming).

DNN_M5 · p33-38

Output Layer Gradient (Elegant Pairing)

For the three matched loss–activation pairs — MSE+identity, BCE+sigmoid, CCE+softmax — the output-layer error takes the same simple form \(\delta^{(L)}=\tfrac1B(\hat Y-Y)\).

DNN_M5 · p32

Depth vs Width

Depth (more layers) yields hierarchical features and better generalisation/expressiveness; width (more units/layer) increases capacity but risks overfitting. Deep nets can represent exponentially more functions than shallow ones with the same parameter budget.

DNN_M5 · p44-45

Universal Approximation Theorem

A single-hidden-layer network with enough neurons can approximate any continuous function on a compact set (Cybenko/Hornik, 1989). But shallow nets may need exponentially many units; deep nets learn hierarchical structure far more parameter-efficiently.

DNN_M5 · p46

Deep-Network Training Challenges

Vanishing gradients (early layers barely learn — use ReLU, good init, normalization), exploding gradients (NaN/Inf — gradient clipping, proper init), and the degradation problem (very deep nets hard to optimize — residual/skip connections).

DNN_M5 · p47

Output Layer Design by Task

Regression: \(K\) units, identity activation, MSE. Binary: 1 unit, sigmoid, BCE. Multi-class: \(C\) units, softmax, categorical CE. The output activation must match the loss.

DNN_M5 · p50

Architecture Guidelines

Start simple (2–3 hidden layers, 10–100 units), then grow. Common patterns: funnel (decreasing width, compression), constant width, hourglass (wide→narrow→wide). Scale network size with dataset size to avoid overfitting.

DNN_M5 · p51

Parameter Initialization

Never initialise all weights to zero (symmetry). Use random init: Xavier/Glorot for sigmoid/tanh, He for ReLU; biases to zero. Proper init is critical for successful training.

DNN_M5 · p55

Regularization

Prevent overfitting via L2 (weight decay), Dropout, Early stopping, and Batch Normalization. (Covered in depth in later modules.)

DNN_M5 · p53

Diagnosing Training Issues

NaN/Inf → decrease \(\eta\), normalize; loss flat → \(\eta\) too small or bug; oscillating → \(\eta\) too large; train↓/val↑ → overfitting; both high → underfitting (bigger net); gradients→0 vanishing (ReLU/better init); gradients→∞ exploding (clip, lower \(\eta\)).

DNN_M5 · p59
Numerical Methods — Worked Problems · source: DNN_M5_DFNN_Numerical.pdf · DFFNNUMERICAL.pdf · Weight_Bias_Cost_Function.pptx

Complete Training Cycle (2-layer net)

End-to-end worked example: 2→3 (ReLU) →2 (sigmoid) network, input \(x=[1.0,0.5]\), target \([1,0]\), BCE loss, \(\eta=0.1\). Steps: forward prop (\(z^{[1]},a^{[1]},z^{[2]},a^{[2]}\)) → BCE loss (0.560) → output error \(\delta^{[2]}=a^{[2]}-y\) → layer gradients → hidden error via ReLU′ → weight update. This is the canonical exam problem.

DNN_M5_Numerical · p3-31

Forward Propagation, Step by Step

\(z^{[1]}=W^{[1]}x+b^{[1]}=[0.7,-0.1,0.2]\); ReLU zeros the negative unit → \(a^{[1]}=[0.7,0,0.2]\) (a "dead" neuron); \(z^{[2]}=W^{[2]}a^{[1]}+b^{[2]}=[0.6,-0.02]\); sigmoid → \(\hat y=[0.646,0.495]\).

DNN_M5_Numerical · p5-12

Backward Propagation, Step by Step

\(\delta^{[2]}=a^{[2]}-y=[-0.354,0.495]\); \(\partial L/\partial W^{[2]}=\delta^{[2]}(a^{[1]})^\top\); hidden error \(\delta^{[1]}=(W^{[2]\top}\delta^{[2]})\odot g'^{[1]}(z^{[1]})\). Because ReLU′ is 0 for the dead neuron, its gradient is 0 → no update.

DNN_M5_Numerical · p17-26

Weight Update

\(\theta_{\text{new}}=\theta_{\text{old}}-\alpha\,\partial L/\partial\theta\) applied to every \(W^{[\ell]},b^{[\ell]}\) with \(\alpha=0.1\). Dead-neuron rows stay essentially unchanged since their gradients are 0.

DNN_M5_Numerical · p28-30

Gradient Flow / Vanishing Gradients

Per backward step gradient magnitude scales by \(\|W\|\cdot|g'|\). With \(\|W\|=0.8\) and sigmoid \(g'=0.25\), factor = 0.2/layer: \(|\delta^{[4]}|=1\to|\delta^{[1]}|=0.008\) — early layers get a vanishingly weak signal (the vanishing-gradient problem in deep sigmoid nets).

DNN_M5_Numerical · p33-34

Designing a Network (Layer/Neuron Sizing)

Use rules of thumb \(L\le\log_2(M/(d\cdot c))+1\) and Parameters \(\le M/5\) to pick depth and width from dataset size \(M\), features \(d\), classes \(c\). Worked cases: tabular [20,6,3], MNIST-like [784,32,10], text [1000,512,256,128,5] — iterate down until the parameter budget is met, then add regularization.

DNN_M5_Numerical · p36-41

Softmax + Cross-Entropy Simplification

Chaining the CE gradient \(-y_k/\hat y_k\) with the softmax Jacobian \(\hat y_k(\delta_{kj}-\hat y_j)\) collapses to the clean result \(\partial\ell/\partial z_j=\hat y_j-y_j\) — the gradient is just (predicted − true) probability.

DNN_M5_Numerical · p49,57-61

Activation Functions — Numerical Evaluation

Worked vector example computing sigmoid, tanh, and ReLU and their derivatives element-wise. Sigmoid′ peaks at 0.25, tanh′ at 1.0 (4× stronger), ReLU′ is 1/0. Confirms tanh's stronger gradients and ReLU's dead-zone.

DNN_M5_Numerical · p44-56

Loss Functions & Their Derivatives

MSE ½(ŷ−y)² → ŷ−y; MAE |ŷ−y| → sign(ŷ−y) (constant ±1, robust to outliers); BCE → (ŷ−y)/(ŷ(1−ŷ)); Categorical CE → −yⱼ/ŷⱼ. Understanding these derivatives is the basis for backprop.

DNN_M5_Numerical · p63-79

ANN Backpropagation Overview

Conceptual 7-step recipe: init small non-zero weights → input example → forward propagate to \(\hat y\) → measure error vs target → back-propagate error and update weights by responsibility (scaled by learning rate) → repeat per observation → repeat epochs. Backprop is what made training multilayer nets feasible.

DFFNNUMERICAL · p10-11

Gradient Descent Across Epochs (Intuition)

For \(\hat y=wx+b\) with \(\eta=0.01\): weight rises fast then flattens (0→2.09), bias drifts up (0→0.54), and cost MSE drops sharply early (122→6.3 by epoch 2, →0.146 by epoch 80). Largest cost reduction happens in the earliest updates.

Deep Learning Timeline

Key milestones: Hebbian Learning Rule (Hebb, 1949), McCulloch–Pitts Neuron, ADALINE/MADALINE (Widrow & Hoff), Perceptron (Rosenblatt), the XOR Problem critique (Minsky & Papert, 1969), Backpropagation theory (Werbos), LeNet-5 CNN (LeCun), LSTM (Hochreiter & Schmidhuber), Deep Belief Nets (Hinton), AlexNet wins ImageNet 2012 (Krizhevsky/Sutskever/Hinton), GANs (Goodfellow), Transformer (Vaswani et al.), BERT, GPT-3 and ChatGPT (OpenAI). Shows the alternating "AI winters" and breakthroughs that shaped the field.

DNN_M1 · p11 (image)

Deep Learning Breakthroughs / Applications

Real-world successes that motivate DL: speech recognition surpassing human transcription (Microsoft, 2016), fluent neural machine translation (Google Translate), image segmentation and object detection/recognition, superhuman game play (AlphaGo/AlphaZero mastering Go/Chess/Shogi from self-play), and conversational language models (ChatGPT). Illustrates DL's dominance across perception, language, and decision tasks.

Worked Example: 3-3-3-3 Network — Forward Pass

Full forward propagation of a 3→3→3→3 net (hidden layers ReLU then sigmoid, output softmax). Inputs \(I=[0.1,0.3,0.5]\), all biases \([1,1,1]\). Layer 1: \(h1_{in}=I\,W_{ij}+b=[1.2,1.6,1.5]\), ReLU → \(h1_{out}=[1.2,1.6,1.5]\). Layer 2: \(h2_{in}=[3.0,3.0,2.4]\), sigmoid → \(h2_{out}=[0.952,0.952,0.916]\). Worked Example: Cross-Entropy Loss (3 outputs)

Per-output log loss \(E_i=-y_i\log(o_{out,i})-(1-y_i)\log(1-o_{out,i})\): \(E_1=-\log(0.858)=0.0665\), \(E_2=-\log(0.4717)=0.3263\), \(E_3=-\log(0.6138)=0.2119\). Total cost \(=\tfrac13(0.0665+0.3263+0.2119)=0.2015\). Only the true-class term dominates when the prediction is confident.

Worked Example: Output-Layer Backprop (\(W_{kl}\))

Backprop the error to the hidden2→output weights via \(\partial E/\partial W = (\partial E/\partial o_{out})(\partial o_{out}/\partial o_{in})(\partial o_{in}/\partial W)\). Cross-entropy derivative \(\partial E/\partial o_{out}=[-1.1655,-2.1199,-1.6291]\); softmax (diagonal) derivative \(\partial o_{out}/\partial o_{in}=o_{out}(1-o_{out})=[0.1218,0.2492,0.2370]\); \(\partial o_{in}/\partial W=h2_{out}\). Result \(\partial W_{kl}=\begin{bmatrix}-0.1351&-0.5029&-0.3675\\-0.1351&-0.5029&-0.3675\\-0.1300&-0.4839&-0.3536\end{bmatrix}\). With \(lr=0.01\), \(W'=W-lr\cdot\partial W\) changes each weight by only ~0.001–0.005.

Worked Example: Hidden & Input-Layer Backprop (\(W_{jk}\), \(W_{ij}\))

Continue backward with the chain rule. Sigmoid derivative at layer 2: \(h2_{out}(1-h2_{out})=[0.0451,0.0451,0.0762]\); error flows back through the output weights, \(\partial E_{tot}/\partial h2_{out}=[-0.4082,-0.6824,-0.7597]\), giving \(\partial W_{jk}=\begin{bmatrix}-0.0220&-0.0369&-0.0694\\-0.0294&-0.0492&-0.0926\\-0.0276&-0.0461&-0.0868\end{bmatrix}\). For the input layer, ReLU derivative is \([1,1,1]\) (all pre-activations \(>0\)) and \(\partial h1_{in}/\partial W_{ij}=I_{out}\) (the inputs). Demonstrates the full output→hidden→input gradient cascade.
