Module 2 — Data Preprocessing & Scaling · source: ML_CS 2_1Aug2026.pdf

IQR Outlier Bounds

$$\text{IQR}=Q_3-Q_1,\quad \text{Lower}=Q_1-1.5\cdot\text{IQR},\quad \text{Upper}=Q_3+1.5\cdot\text{IQR}$$

where: \(Q_1\) = 25th percentile, \(Q_3\) = 75th percentile, IQR = inter-quartile range.

use: any value below the lower bound or above the upper bound is a univariate outlier. (Ex: Q1=10, Q3=20 ⇒ bounds −5 and 35.)

ML_CS 2 · p38-39

3-Sigma (Z-Score) Outlier Bounds

$$\text{Lower}=\mu-3\sigma,\qquad \text{Upper}=\mu+3\sigma$$

where: \(\mu\) = mean, \(\sigma\) = standard deviation of the attribute.

use: for approximately normal data ~99% of values lie within μ ± 3σ; points outside are outliers. (μ=50, σ=5 ⇒ bounds 35 and 65.)

ML_CS 2 · p40

Min-Max Normalization

$$v' = \frac{v-\min_A}{\max_A-\min_A}\,(\text{new\_max}_A-\text{new\_min}_A)+\text{new\_min}_A$$

where: \(v\) = original value, \(\min_A,\max_A\) = attribute min/max, new range = \([\text{new\_min}_A,\text{new\_max}_A]\) (often [0,1]).

use: rescale a feature to a bounded range when its bounds are known / data ≈ uniform. (Ex: income 12k-98k ⇒ 73k maps to 0.716.)

ML_CS 2 · p48

Z-Score Standardization

$$v' = \frac{v-\mu}{\sigma}$$

where: \(\mu\) = attribute mean, \(\sigma\) = attribute standard deviation.

use: standardize when an algorithm assumes Gaussian data; not range-bounded, less outlier-sensitive. (Ex: μ=54000, σ=16000 ⇒ 73600 maps to 1.225.)

ML_CS 2 · p48

Decimal Scaling

$$v' = \frac{v}{10^{\,j}}\quad\text{where } j \text{ is the smallest integer s.t. } \max(|v'|)<1$$

where: \(v\) = original value, \(j\) = number of decimal shifts.

use: normalize by moving the decimal point based on the maximum absolute value.

ML_CS 2 · p48

Equal-Width Binning Interval

$$W=\frac{B-A}{N}$$

where: \(A\) = lowest value, \(B\) = highest value, \(N\) = number of bins, \(W\) = width of each interval.

use: discretize a continuous attribute into N equal-width bins (outliers may dominate; skewed data handled poorly).

Module 3 — Linear Regression, Gradient Descent & Regularization · source: ML_CS 34_916 Aug 2026.pdf

Linear Regression Hypothesis

$$h_\theta(x)=\theta_0+\theta_1 x_1+\theta_2 x_2+\dots+\theta_d x_d=\theta^{\top}x$$

where: \(h_\theta(x)\) = predicted value, \(\theta_0\) = intercept/bias, \(\theta_j\) = weight of feature \(x_j\).

use: the model form for simple (one \(x\)) and multiple (many \(x\)) linear regression; \(x_0=1\) absorbs the intercept in vector form.

ML_CS 34 · p8-9

Cost Function — Mean Squared Error (Least Squares)

$$J(\theta)=\frac{1}{2n}\sum_{i=1}^{n}\big(h_\theta(x^{(i)})-y^{(i)}\big)^2$$

where: \(n\) = number of training examples, \(h_\theta(x^{(i)})\) = prediction, \(y^{(i)}\) = actual target.

use: the convex objective minimized to fit linear regression; the ½ simplifies the derivative.

ML_CS 34 · p11-16

Normal Equation (Closed-Form Solution)

$$\theta=(X^{\top}X)^{-1}X^{\top}y$$

where: \(X\) = design matrix (rows = examples, with a leading 1 column), \(y\) = target vector, \(\theta\) = parameter vector.

use: solve for optimal parameters directly without iteration; requires an invertible \(X^{\top}X\) (costly for very many features).

ML_CS 34 · p24-30

Gradient Descent — General Update

$$\theta_j := \theta_j-\alpha\,\frac{\partial}{\partial \theta_j}J(\theta)\quad(\text{update all } j \text{ simultaneously})$$

where: \(\alpha\) = learning rate, \(\partial J/\partial\theta_j\) = gradient of cost w.r.t. \(\theta_j\).

use: iteratively step downhill toward the minimum of the cost; repeat until convergence.

ML_CS 34 · p46-49

Gradient Descent for Linear Regression (per parameter)

$$\theta_0 := \theta_0-\alpha\,\frac{1}{n}\sum(h_\theta(x)-y),\qquad \theta_j := \theta_j-\alpha\,\frac{1}{n}\sum\big((h_\theta(x)-y)\,x_j\big)$$

where: \(h_\theta(x)=\theta_0+\theta_1x_1+\theta_2x_2\), \(n\) = #examples, \(\alpha\) = learning rate, \(x_j\) = j-th feature.

use: the concrete batch-GD update for fitting a regression line; drives the "one iteration" numerical problems (e.g. RRCHD from BMI & diastolic pressure).

ML_CS 34 · p55, p63

R-squared (Coefficient of Determination)

$$R^2 = 1-\frac{SS_{res}}{SS_{tot}}=1-\frac{\sum_i (y_i-\hat y_i)^2}{\sum_i (y_i-\bar y)^2}$$

where: \(y_i\) = actual, \(\hat y_i\) = predicted, \(\bar y\) = mean of \(y\); \(SS_{res}\) = unexplained variation, \(SS_{tot}\) = total variation.

use: fraction of variance in \(y\) explained by the model (1 = perfect fit); compares regression models.

ML_CS 34 · p74

Root Mean Squared Error (RMSE)

$$\text{RMSE}=\sqrt{\frac{1}{n}\sum_{i=1}^{n}\big(y_i-\hat y_i\big)^2}$$

where: \(y_i\) = actual, \(\hat y_i\) = predicted, \(n\) = #examples.

use: regression error in the target's units, penalizing large errors more; asked directly in EC2 Q1.

EC2 · Q1 / ML_CS 34 · p102

Mean Absolute Error (MAE)

$$\text{MAE}=\frac{1}{n}\sum_{i=1}^{n}\big|\,y_i-\hat y_i\,\big|$$

where: \(y_i\) = actual, \(\hat y_i\) = predicted, \(n\) = #examples.

use: average absolute regression error, less sensitive to large outliers than RMSE; asked directly in EC2 Q1.

EC2 · Q1

Linear Basis Function / Polynomial Model

$$h_w(x)=\sum_{j=0}^{M} w_j\,\phi_j(x),\qquad \phi_j(x)=x^{\,j}\ \ (\phi_0(x)=1)$$

where: \(\phi_j\) = basis functions, \(w_j\) = weights, \(M\) = polynomial order; model is linear in \(w\).

use: fit non-linear input→output relationships (e.g. quadratic Car Price vs Mileage) while keeping linear-model machinery.

ML_CS 34 · p76-79

Ridge Regression (L2) Cost

$$J(\theta)=\frac{1}{2n}\sum_{i=1}^{n}\big(h_\theta(x^{(i)})-y^{(i)}\big)^2+\lambda\sum_{j=1}^{d}\theta_j^{2}$$

where: \(\lambda\) = regularization strength, \(\theta_j\) = weights (bias \(\theta_0\) not penalized).

use: shrink weights toward zero to reduce variance/overfitting; weights stay small but non-zero.

ML_CS 34 · p96

Lasso Regression (L1) Cost

$$J(\theta)=\frac{1}{2n}\sum_{i=1}^{n}\big(h_\theta(x^{(i)})-y^{(i)}\big)^2+\lambda\sum_{j=1}^{d}\lvert\theta_j\rvert$$

where: \(\lambda\) = regularization strength, \(|\theta_j|\) = absolute value of each weight.

use: drives some weights exactly to 0 (sparse model, feature selection); L1 is non-differentiable at 0.

ML_CS 34 · p97

Elastic Net Cost

$$J(\theta)=\text{MSE}(\theta)+r\,\lambda\sum_{j}\lvert\theta_j\rvert+\frac{(1-r)}{2}\,\lambda\sum_{j}\theta_j^{2}$$

where: \(r\) = mix ratio (r=0 ⇒ Ridge, r=1 ⇒ Lasso), \(\lambda\) = strength.

use: combine L1 sparsity and L2 stability; preferred for highly correlated features (sklearn: ElasticNet(alpha, l1_ratio)).

ML_CS 34 · p98

Ridge GD Update (weight decay form)

$$w_j := w_j\,(1-\alpha\lambda)-\alpha\,\frac{1}{n}\sum\big((h_w(x)-y)\,x_j\big)$$

where: \(\alpha\) = learning rate, \(\lambda\) = regularization constant, \(w_j\) = weight (bias \(w_0\) updated without the \((1-\alpha\lambda)\) shrink).

use: gradient-descent step for ridge regression; the factor \((1-\alpha\lambda)\) shrinks each weight every iteration.

ML_CS 34 · p100-101

Lasso GD Update

$$w_j := w_j-\alpha\,\frac{1}{n}\sum\big((h_w(x)-y)\,x_j\big)-\alpha\lambda\,\operatorname{sign}(w_j)$$

where: \(\alpha\) = learning rate, \(\lambda\) = regularization constant, \(\operatorname{sign}(w_j)\) = +1/−1 sub-gradient of \(|w_j|\).

use: GD step for lasso; the fixed \(\alpha\lambda\) penalty pushes weights toward zero faster.

ML_CS 34 · p100-101

Module 4 — Logistic Regression & Classification Metrics · source: ML_CS 5 6.pdf

Sigmoid / Logistic Function

$$\sigma(z)=\frac{1}{1+e^{-z}}$$

where: \(z\) = real-valued input (the linear score), \(\sigma(z)\in(0,1)\).

use: squashes any real number into a probability; σ(z)≥0.5 ⇔ z≥0.

ML_CS 5 · p12

Logistic Regression Hypothesis

$$z=w_0x_0+w_1x_1+\dots+w_nx_n,\qquad h_w(x)=\frac{1}{1+e^{-z}}$$

where: \(w_i\) = weights, \(x_i\) = features (\(x_0=1\)), \(h_w(x)\) = estimated P(y=1|x).

use: predicts class probability; classify as 1 if \(h_w(x)\ge0.5\), else 0.

ML_CS 5 · p7

Linear Discriminant Decision Rule

$$y=\operatorname{sign}(w_0+w^{\top}x),\qquad \text{boundary: } w_0+w^{\top}x=0$$

where: \(w_0\) = bias, \(w\) = weight vector, \(x\) = input vector.

use: a linear classifier assigns class by which side of the hyperplane a point lies on.

ML_CS 5 · p9

Logistic Regression Cost (Cross-Entropy / Log Loss)

$$J(\theta)=-\frac{1}{m}\sum_{i=1}^{m}\Big[y^{(i)}\log h_\theta(x^{(i)})+(1-y^{(i)})\log\big(1-h_\theta(x^{(i)})\big)\Big]$$

where: \(m\) = #examples, \(y^{(i)}\in\{0,1\}\) = true label, \(h_\theta(x^{(i)})\) = predicted probability.

use: convex classification cost; per-example cost is \(-\log h\) when y=1 and \(-\log(1-h)\) when y=0.

ML_CS 5 · p20-22

Gradient Descent for Logistic Regression

$$\theta_j := \theta_j-\alpha\,\frac{1}{m}\sum_{i=1}^{m}\big(h_\theta(x^{(i)})-y^{(i)}\big)\,x_j^{(i)}$$

where: \(\alpha\) = learning rate, \(h_\theta\) = sigmoid hypothesis, \(x_j^{(i)}\) = j-th feature of example i.

use: same update form as linear regression but with the sigmoid hypothesis; drives the logistic-regression numerical exercises.

ML_CS 5 · p23-24, p28

Logit (Log-Odds) & Odds Ratio

$$\operatorname{logit}(p)=\log\frac{p}{1-p}=w^{\top}x,\qquad \text{odds ratio}=e^{\,w_j}$$

where: \(p\) = predicted probability, \(w_j\) = coefficient of feature \(j\).

use: logit is the inverse sigmoid; \(e^{w_j}\) is the multiplicative change in odds per unit increase in feature \(j\) (e.g. 1.35× per CGPA point).

ML_CS 5 · p29, p58

Accuracy

$$\text{Accuracy}=\frac{TP+TN}{TP+TN+FP+FN}$$

where: TP/TN = correct positive/negative predictions, FP/FN = false positive/negative.

use: overall correctness; misleading under class imbalance — use only when classes are balanced.

ML_CS 5 · p34-36

Precision, Recall (TPR) & F1-Score

$$\text{Precision}=\frac{TP}{TP+FP},\quad \text{Recall}=\frac{TP}{TP+FN},\quad F_1=\frac{2\cdot\text{Prec}\cdot\text{Rec}}{\text{Prec}+\text{Rec}}$$

where: TP = true positives, FP = false positives, FN = false negatives.

use: precision = correctness of positive predictions; recall = coverage of actual positives; F1 = harmonic mean balancing both (needed for EC2 per-class metrics).

ML_CS 5 · p44 / EC2 · Q3

ROC Rates — TPR & FPR

$$\text{TPR}=\frac{TP}{TP+FN},\qquad \text{FPR}=\frac{FP}{FP+TN}$$

where: TPR = true positive (detection) rate, FPR = false positive (false alarm) rate.

use: the axes of the ROC curve (TPR vs FPR) plotted across thresholds; TNR=1−FPR, FNR=1−TPR.

ML_CS 5 · p43-44

Module 5 — Exam-Referenced Prerequisite Formulas · source: EC2 & EC3 instruction sheets

Distance Metrics (Euclidean & Manhattan)

$$d_{\text{Euc}}(p,q)=\sqrt{\sum_i (p_i-q_i)^2},\qquad d_{\text{Man}}(p,q)=\sum_i \lvert p_i-q_i\rvert$$

where: \(p,q\) = two points, \(p_i,q_i\) = their i-th coordinates.

use: proximity measures for kNN and clustering; EC3 Q1 asks a k=3 kNN classification using Manhattan distance.

EC3 · Q1

Bayes' Theorem

$$P(A\mid B)=\frac{P(B\mid A)\,P(A)}{P(B)},\qquad P(B)=\sum_k P(B\mid A_k)P(A_k)$$

where: \(P(A|B)\) = posterior, \(P(B|A)\) = likelihood, \(P(A)\) = prior, \(P(B)\) = evidence (total probability).

use: compute posterior class probability (e.g. P(disease | positive test)) from priors and likelihoods.

EC3 · Q2

Naive Bayes Classifier

$$\hat y=\arg\max_{c}\ P(c)\prod_{j=1}^{d} P(x_j\mid c)$$

where: \(c\) = class, \(P(c)\) = prior, \(P(x_j|c)\) = conditional likelihood of feature \(x_j\) (assumed independent given \(c\)).

use: predict the class maximizing posterior under the conditional-independence assumption (EC3 "play cricket?" table).

EC3 · Q3

Likelihood & MLE (Binomial)

$$L(p)=\binom{n}{h}p^{h}(1-p)^{n-h},\qquad \hat p_{\text{MLE}}=\frac{h}{n}$$

where: \(n\) = #trials, \(h\) = #successes (heads), \(p\) = success probability.

use: estimate a parameter by maximizing (log-)likelihood of i.i.d. data; EC3 Q3 coin-toss MLE.

EC3 · Q3

Entropy

$$H=-\sum_{i=1}^{K} p_i\log_2 p_i$$

where: \(p_i\) = proportion of instances in class \(i\), \(K\) = number of classes.

use: measure of class impurity/disorder at a node; 0 = pure, max when classes are equal.

EC2 · Q6

Information Gain

$$IG(S,A)=H(S)-\sum_{v\in \text{values}(A)}\frac{|S_v|}{|S|}\,H(S_v)$$

where: \(H(S)\) = entropy before split, \(S_v\) = subset with attribute value \(v\), \(|S_v|/|S|\) = weight.

use: pick the split attribute with the largest entropy reduction (EC2 Q6: compare a1 vs a2 at the root).

EC2 · Q6

Gini Index

$$\text{Gini}=1-\sum_{i=1}^{K} p_i^{2}$$

where: \(p_i\) = estimated probability of class \(i\) at the node, \(K\) = number of classes.

use: alternative node-impurity measure for decision-tree splits; lower weighted Gini = better split (EC2 Q6c).

EC2 · Q6

SVM Hyperplane, Weight Vector & Bias

$$w=\sum_i \alpha_i y_i x_i,\qquad y_i(w\cdot x_i+b)=1\ \text{ for each support vector}$$

where: \(\alpha_i\) = Lagrange multipliers, \(y_i\) = class labels (±1), \(x_i\) = support vectors, \(b\) = bias.

use: build the SVM decision boundary \(w\cdot x+b=0\); average the \(b\) solved from each support-vector equation (EC3 Q4a).

EC3 · Q4

Polynomial Kernel

$$K(u,v)=(u\cdot v+1)^{2},\qquad D_{ij}=y_i y_j\,K(x_i,x_j)$$

where: \(u,v\) = input vectors, \(y_i,y_j\) = class labels, \(D\) = kernel/Gram matrix of the dual formulation.

use: the kernel trick maps points to higher dimensions for non-linear separation; EC3 Q4c computes matrix D.

EC3 · Q4

K-Means Objective & Centroid Update

$$J=\sum_{k=1}^{K}\sum_{x\in C_k}\lVert x-\mu_k\rVert^2,\qquad \mu_k=\frac{1}{|C_k|}\sum_{x\in C_k} x$$

where: \(C_k\) = cluster \(k\), \(\mu_k\) = its centroid, \(K\) = number of clusters.

use: assign each point to the nearest centroid then recompute centroids as cluster means; iterate (EC3 Q5a).

EC3 · Q5

AdaBoost Final Prediction & Weight Update

$$H(x)=\operatorname{sign}\!\Big(\sum_{t} \alpha_t\,h_t(x)\Big),\qquad w_i \leftarrow w_i\,e^{\pm\alpha_t}\ \text{(then normalize)}$$

where: \(\alpha_t\) = weight of weak learner \(t\), \(h_t(x)\) = its prediction (±1), \(w_i\) = instance weight (increase if misclassified, decrease if correct).

use: combine weak learners by weighted vote; reweight misclassified instances up each round and renormalize to sum to 1 (EC3 Q6c, Q6d).

EC3 · Q6

Out-of-Bag (OOB) Error

$$\text{OOB error}=\frac{\#\text{misclassified OOB samples}}{\#\text{OOB samples}}$$

where: OOB samples = training rows not drawn in a given bootstrap sample.

use: validate a bagged/random-forest model on the ~⅓ of data left out of each bootstrap (EC3 Q6b).

Simple Linear Regression — Slope & Intercept (OLS)

$$\theta_1=\frac{\sum_i (x_i-\bar x)(y_i-\bar y)}{\sum_i (x_i-\bar x)^2},\qquad \theta_0=\bar y-\theta_1\bar x$$

where: \(\bar x,\bar y\) = feature/target means, \(\theta_1\) = slope, \(\theta_0\) = intercept.

use: direct least-squares fit of a single-predictor line, no iteration. (Worked ex: \(\sum(x_i-\bar x)(y_i-\bar y)=615\), \(\sum(x_i-\bar x)^2=4206\) ⇒ \(\theta_1\approx0.1462\), \(\theta_0=10-0.1462\times74\approx-0.8188\).)

ML_CS 34 · p14-16 (image)

Vectorized MSE Gradient

$$\nabla J(\mathbf{w})=\frac{1}{N}\mathbf{X}^{\top}\mathbf{e},\qquad \mathbf{e}=\hat{\mathbf{y}}-\mathbf{y}=\mathbf{X}\mathbf{w}-\mathbf{y}$$

where: \(\mathbf{X}\) = design matrix (\(N\times(d{+}1)\)), \(\mathbf{e}\) = error/residual vector, \(N\) = #examples.

use: one matrix expression for the whole-batch gradient; the GD step is \(\mathbf{w}\leftarrow\mathbf{w}-\eta\,\nabla J(\mathbf{w})\). (Worked ex: loss \(7.5\to1.51\) after one step with \(\eta=0.1\) — an 80% reduction.)

ML_CS 34 · p59-61 (image)

Gradient-Descent Convergence Criterion (L2 norm)

$$\lVert \boldsymbol{\theta}_{new}-\boldsymbol{\theta}_{old}\rVert_2 \lt \epsilon,\qquad \lVert \mathbf{v}\rVert_2=\sqrt{\textstyle\sum_i v_i^2}=\sqrt{v_1^2+v_2^2+\dots+v_{|v|}^2}$$

where: \(\epsilon\) = small tolerance, \(\lVert\cdot\rVert_2\) = Euclidean (L2) norm of the parameter-change vector.

use: stop iterating when successive parameter vectors change by less than \(\epsilon\) (equivalently when \(\lVert\nabla J(\boldsymbol{\theta})\rVert\lt\epsilon\) or max iterations reached).

ML_CS 34 · p54 (image)

Gaussian & Sigmoidal Basis Functions

$$\phi_j(x)=\exp\!\left\{-\frac{(x-\mu_j)^2}{2s^2}\right\},\qquad \phi_j(x)=\sigma\!\left(\frac{x-\mu_j}{s}\right),\ \ \sigma(a)=\frac{1}{1+e^{-a}}$$

where: \(\mu_j\) = centre/location, \(s\) = scale/width, \(\sigma\) = logistic sigmoid.

use: local basis functions for linear-basis-function regression — \(\mu_j\) and \(s\) control location and width/slope; the polynomial basis \(\phi_j(x)=x^{\,j}\) is the global alternative.

ML_CS 34 · p79 (image)

AUC via Trapezoidal Rule

$$\text{AUC}=\sum_i \big(\text{FPR}_i-\text{FPR}_{i+1}\big)\cdot\frac{\text{TPR}_i+\text{TPR}_{i+1}}{2}$$

where: \((\text{FPR}_i,\text{TPR}_i)\) = successive ROC points taken in decreasing FPR order.

use: numerically integrate the area under the ROC curve — each term is a trapezoid (width × average height); vertical steps (width 0) add nothing. (Worked ex: \(0.16+0.12+0.12+0.12+0.08=0.60\).)

ML_CS 5 · p45-47 (image)

Error Rate (Misclassification Rate)

$$\text{Error rate}=\frac{FP+FN}{TP+TN+FP+FN}=1-\text{Accuracy}$$

where: \(FP,FN\) = incorrect predictions, denominator = total instances.

use: overall fraction of wrong predictions — the complement of accuracy (asked in the cancer confusion-matrix practice exercise alongside precision/recall/F-score).
