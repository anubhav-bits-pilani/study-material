Q2. Name the four levels of measurement in increasing order and give the key property that distinguishes each from the previous one. [2M]

Nominal → Ordinal → Interval → Ratio.
Nominal: labelled categories, no order. Ordinal: adds a meaningful order but differences are not quantifiable. Interval: adds equal, meaningful differences but has no true zero (e.g. °C). Ratio: adds a true zero, so ratios are meaningful (e.g. weight, age). The level chosen dictates which statistics are valid.

Q7. Explain why two events with non-zero probability that are mutually exclusive cannot be independent. [1.5M]

Mutually exclusive ⇒ \(P(A\cap B)=0\). Independent ⇒ \(P(A\cap B)=P(A)P(B)\). If both \(P(A),P(B)>0\), then \(P(A)P(B)>0\neq0\), a contradiction. So mutually exclusive events with positive probability must be dependent — knowing one occurred tells you the other did not.

Q9. Explain the difference between sampling with and without replacement, and state which one produces independent trials. [1.5M]

Q1. In \(P(H\mid E)=\dfrac{P(E\mid H)P(H)}{P(E)}\), name each of \(P(H)\), \(P(E\mid H)\), \(P(E)\) and \(P(H\mid E)\). [2M]

Q2. A disease affects 1% of a population. A test is positive with probability 0.9 for a diseased person and 0.9 overall (evidence). Using Bayes' rule, find \(P(\text{disease}\mid+)\). [1.5M]

\(P(D\mid+)=\dfrac{P(+\mid D)P(D)}{P(+)}=\dfrac{0.9\times0.01}{0.9}=\textbf{0.01}.\) (Here the test gives no information because \(P(+\mid D)=P(+)\); posterior = prior.)

MAP picks the larger numerator: \(0.012>0.008\) ⇒ predict \(y_1\). Posterior \(=\dfrac{0.012}{0.012+0.008}=\dfrac{0.012}{0.020}=\textbf{0.6}.\)
