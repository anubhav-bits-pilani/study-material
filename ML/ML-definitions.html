M1 · Introduction to Machine Learning · 12 items

Machine learning

The field of study that gives computers the ability to learn from data without being explicitly programmed; operationally (Mitchell), a program learns if its performance \(P\) at task \(T\) improves with experience \(E\).

1.1.1 · slide 15

Well-posed learning task

A learning problem fully specified by the triple \(\langle T, P, E \rangle\): the task \(T\), the performance measure \(P\) used to score it, and the experience \(E\) (training data or interaction) from which the program learns.

1.1.1 · slides 15–17

Supervised learning

Learning a function \(f\) from labelled examples \((x_1, y_1), \dots, (x_n, y_n)\) so as to predict \(y\) for previously unseen \(x\).

1.2.1 · slides 27, 31, 36

Classification

A supervised task whose target \(y = f(x)\) is discrete (a class label such as benign/malignant); binary classification has two classes.

1.2.1, 1.4.3 · slides 31–33, 119

Regression

A supervised task whose target \(y = f(x)\) is real-valued (for example, a used-car price).

1.2.1, 1.4.3 · slides 36, 119

Unsupervised learning

Learning from unlabelled inputs \(x_1, \dots, x_n\) to output hidden structure, such as clusters with small intra-cluster and large inter-cluster distances, or a lower-dimensional representation.

1.2.2 · slides 37–39

Reinforcement learning

A feedback-based paradigm in which an agent takes actions in an environment and learns, by trial and error from rewards and penalties rather than labels, a policy for a sequence of decisions.

1.2.3 · slides 41–44

Semi-supervised learning

Learning from partially labelled data, a small labelled set plus a large unlabelled set, by combining supervised and unsupervised techniques.

1.2.4 · slide 47

Batch, mini-batch and online learning

Batch learning trains on all available data at a time, mini-batch learning on a subset at a time, and online (incremental) learning on a single instance at a time, updating the model as each new example arrives.

1.3.1 · slide 48

Instance-based and model-based learning

Instance-based (lazy) learning stores the training examples and predicts by comparing a new point with the stored ones (k-NN); model-based (eager) learning detects patterns in the training data and builds a predictive model whose parameters are then used without the data.

1.3.2, 6.1 · slides 49, 373

Inductive learning hypothesis

The assumption that any hypothesis found to approximate the target function well over a sufficiently large set of training examples will also approximate it well over other, unobserved examples.

1.4.1 · slide 119

Hypothesis space

The set \(H\) of all candidate functions \(h\) a learner may output. In attribute-constraint notation each attribute is a value, "?" (any value) or \(\varnothing\) (no value): the most general hypothesis \((?, ?, \dots, ?)\) classifies every instance as positive, the most specific \((\varnothing, \dots, \varnothing)\) classifies none as positive.

1.4.2 · slide 123
M2 · Machine Learning Workflow · 23 items

Data object and attribute

A data object (record, point, case, sample, entity, instance) is a single entity described by a collection of attributes; an attribute (variable, field, characteristic, dimension, feature) is a property or characteristic of an object, such as eye colour or temperature.

2.1.1 · slide 64

Nominal attribute

An attribute whose values only distinguish objects (distinctness, \(=\) and \(\ne\)), with no order: zip codes, ID numbers, eye colour.

2.1.2 · slides 65–66

Ordinal attribute

An attribute whose values have distinctness and a meaningful order (\(<, >\)) but no meaningful differences: grades, rankings, {good, better, best}.

2.1.2 · slides 65–66

Interval attribute

A numeric attribute with distinctness, order and meaningful differences (\(+, -\)) but no true zero, so ratios are meaningless: calendar dates, temperature in Celsius or Fahrenheit.

2.1.2 · slides 65–67

Ratio attribute

A numeric attribute with a true zero, so all four operations (\(=, <, +, \times\)) are meaningful: temperature in Kelvin, length, counts, elapsed time.

2.1.2 · slides 65–67

Discrete and continuous attributes

A discrete attribute has a finite or countably infinite set of values (zip codes, counts, words), with binary attributes as a special case; a continuous attribute takes real-number values (temperature, height), in practice recorded with finite precision.

2.1.3 · slide 70

Sparsity

The property of a data set in which most attribute values are zero, so only the presence of non-zero values counts; the fraction of zero entries in the data matrix.

2.1.4 · slide 71

Noise

An extraneous object or a modification of an attribute's original values (a distorted voice on a poor phone line) that obscures the true signal.

2.2.1 · slide 82

Outlier

A data object whose characteristics differ considerably from most other objects in the data set; it may be noise to remove or the very target of the analysis (fraud, intrusion).

2.2.1 · slide 83

Missing values and duplicate data

A missing value is an attribute value that was not collected or does not apply, handled by eliminating objects or attributes, estimating (imputing) it, or ignoring it during analysis. Duplicate data are exact or near copies of objects, typically created when heterogeneous sources are merged.

2.2.1, 2.2.2 · slides 84–85

Data aggregation

Combining two or more attributes or objects into a single one (days into months, cities into regions) to reduce data, change scale and obtain more stable, less variable values.

2.2.3 · slide 89

Interquartile range (IQR)

The spread of the middle half of the data, \(\text{IQR} = Q_3 - Q_1\); values below \(Q_1 - 1.5\,\text{IQR}\) or above \(Q_3 + 1.5\,\text{IQR}\) are flagged as outliers.

2.3.1 · slide 95

Three-sigma rule

For approximately normal data, values outside \([\mu - 3\sigma, \ \mu + 3\sigma]\) are treated as outliers, since about 99.7% of a normal distribution lies within three standard deviations of the mean.

2.3.2 · slide 97

Training, validation and test sets

Disjoint partitions of the data: the training set fits the model's parameters, the validation set compares models and tunes hyper-parameters, and the test set estimates generalisation error once, at the end.

2.4.1, 6.5.1 · slides 99, 419

Stratified and cluster sampling

Stratified sampling splits the data into groups (strata, usually classes) and samples each in proportion to its size, so every subset keeps the original class distribution; cluster sampling selects whole groups (clusters) at random instead of individual records.

2.4.2 · slide 101

Undersampling and oversampling

Ways to rebalance an imbalanced training set: undersampling discards majority-class records, oversampling adds (duplicated or synthetic) minority-class records.

2.4.3 · slide 102

SMOTE

Synthetic Minority Oversampling Technique: creates a new minority point \(x_i + \lambda(x_{\text{nn}} - x_i)\), \(\lambda \sim U(0, 1)\), on the segment between a minority example and one of its nearest minority-class neighbours.

2.4.3, 4.4.4 · slides 102, 275

Min-max normalisation

Linear rescaling of a feature to a target range, usually \([0, 1]\): \(x' = \frac{x - \min}{\max - \min}(\text{new\_max} - \text{new\_min}) + \text{new\_min}\).

2.5.1 · slides 104–105

Z-score standardisation

Rescaling a feature to mean 0 and standard deviation 1, \(z = (x - \mu)/\sigma\), i.e. the distance from the mean in units of standard deviation.

2.5.1, 6.2.5 · slides 104–105, 385

Feature extraction, selection and construction

Feature extraction creates a smaller set of new features from the originals (dimensionality reduction such as PCA); feature selection keeps a subset of the existing features, removing irrelevant, redundant or mostly-missing ones; feature construction builds new features by polynomial expansion, feature crossing or domain logic.

2.5.2 · slides 106–111

Discretisation (binning)

Converting a continuous attribute into a discrete one by mapping its values to intervals: equal-width binning uses \(N\) intervals of width \(W = (B - A)/N\), equal-depth (equal-frequency) binning puts about the same number of records in each interval.

2.5.3 · slides 112–113

One-hot and label encoding

One-hot (dummy) encoding maps a categorical attribute with \(m\) values to \(m\) binary indicator variables, exactly one of which is 1; label encoding maps each category to an integer \(0, \dots, m - 1\), implying an order and spacing that only ordinal data really have.

2.5.4 · slide 114

Curse of dimensionality

The collection of problems that arise as the number of features grows: data become increasingly sparse in the space they occupy, distances between points become nearly equal, and far more data are needed to cover the space.

2.5.5, 6.3.4 · slides 108, 392
M3 · Linear Models for Regression · 16 items

Linear regression

A supervised model that predicts a real-valued target as a linear function of the features, \(h_\theta(x) = \theta^\top x = \theta_0 + \theta_1 x_1 + \dots + \theta_d x_d\); simple linear regression has one feature, multiple linear regression several.

3.1.1 · slides 132–133

Residual

The error of one prediction, the vertical distance between the actual value and the fitted value, \(y_i - h_\theta(x_i)\).

3.1.2 · slide 136

Cost function

A function \(J(\theta)\) that scores how badly a parameter setting fits the training data; for linear regression the squared-error cost \(J(\theta) = \frac{1}{2n}\sum_i (h_\theta(x_i) - y_i)^2\), i.e. the sum of squared errors (SSE) or the mean squared error (MSE = SSE/\(n\)) up to a constant factor.

3.1.2 · slides 135–144

Convex function

A real-valued function for which the line segment between any two points on its graph lies on or above the graph; every local minimum of a convex function is a global minimum.

3.1.2, 3.3.5 · slide 147

Normal equations

The linear system \(X^\top X \theta = X^\top y\) obtained by setting \(\nabla J(\theta) = 0\), where the design matrix \(X\) holds one training example per row with a leading 1 for the intercept; when \(X^\top X\) is invertible, \(\theta = (X^\top X)^{-1} X^\top y\) is the closed-form least-squares fit.

3.2.1 · slides 148–153

Gradient descent

An iterative optimiser that repeatedly moves the parameters a small step against the gradient of the cost, \(\theta_j \leftarrow \theta_j - \eta \, \partial J / \partial \theta_j\), updating all \(\theta_j\) simultaneously; the learning rate \(\eta\) (or \(\alpha\)) sets the step size: too small converges slowly, too large oscillates or diverges.

3.3.1, 3.3.2 · slides 155–174

Batch, mini-batch and stochastic gradient descent

Batch gradient descent computes the derivative from all training examples before each update, mini-batch from a small group, and stochastic gradient descent (SGD) from one example at a time; an epoch is one full pass over all \(n\) examples (1 update for batch, \(n\) for SGD).

3.3.4 · slides 189–194

Basis function and polynomial regression

A basis function is a fixed function \(\phi_j(x)\) used as a feature, giving \(y(x, w) = \sum_{j=0}^{M} w_j \phi_j(x)\) with \(\phi_0(x) = 1\), a model still linear in \(w\). Polynomial regression is the case \(\phi_j(x) = x^j\), an \(M\)-th order polynomial in \(x\).

3.4.1 · slides 199–202

Bias and variance

Bias is error from wrong assumptions in the model, how far its average prediction is from the true relationship (high when the model is too simple); variance is error from sensitivity to the training data, how much predictions change with a different training sample (high when the model is too flexible).

3.4.2 · slide 204

Underfitting and overfitting

Underfitting: the model is too simple to capture the pattern (high bias), so training and test error are both high. Overfitting: the model fits the training data too well, noise included (high variance), so training error is low but test error is much higher.

3.4.2 · slides 205, 213

Regularisation

Adding a penalty on the size of the weights to the cost function, scaled by a regularisation constant \(\lambda \ge 0\), to discourage overly complex models and reduce overfitting.

3.5 · slides 212–218

Ridge regression (L2)

Least squares with the penalty \(\lambda \sum_j w_j^2\) (Tikhonov regularisation); it shrinks weights smoothly towards zero but never exactly to zero.

3.5.1 · slide 219

Lasso regression (L1)

Least Absolute Shrinkage and Selection Operator: least squares with the penalty \(\lambda \sum_j \lvert w_j \rvert\), which can set weights exactly to zero and so performs feature selection; the penalty is not differentiable at zero.

3.5.2 · slides 220, 222

Elastic Net

Least squares with a mix of the L1 and L2 penalties controlled by a ratio \(r\); in sklearn (l1_ratio) \(r = 1\) gives Lasso and \(r = 0\) gives Ridge.

3.5.3 · slide 221

Coefficient of determination (R²)

The fraction of the variation in \(y\) explained by the model, \(R^2 = 1 - \text{SSE}/\text{SST}\), where \(\text{SST} = \sum (y_i - \bar{y})^2\) is the total, \(\text{SSR} = \sum (\hat{y}_i - \bar{y})^2\) the explained and \(\text{SSE} = \sum (y_i - \hat{y}_i)^2\) the unexplained variation; with an intercept on training data \(\text{SST} = \text{SSR} + \text{SSE}\) and \(R^2 \in [0, 1]\).

3.6.1 · slides 136, 197

Generalisation error

The expected error of a model on new, unseen data from the same distribution, estimated by its error on a held-out test set rather than on the training data.

3.6.2, 6.5.1 · slides 196, 417
M4 · Linear Models for Classification (Logistic Regression) · 17 items

Logistic regression

A statistical model for binary classification that predicts the probability that an input belongs to the positive class by applying the logistic (sigmoid) function to a linear score, \(h_w(x) = \sigma(w^\top x)\).

4.1.2 · slide 231

Sigmoid (logistic) function

The function \(\sigma(z) = \frac{1}{1 + e^{-z}}\), which maps any real number into \((0, 1)\), with \(\sigma(0) = 0.5\).

4.1.2 · slide 236

Decision boundary

The set of inputs where the classifier is indifferent between classes; for logistic regression it is where \(h(x) = 0.5\), i.e. the hyperplane \(w_0 + w^\top x = 0\).

4.1.2 · slides 233, 238

Cross-entropy (log-loss)

The cost \(J(w) = -\frac{1}{m}\sum_i [y_i \log h(x_i) + (1 - y_i)\log(1 - h(x_i))]\), which is near zero for confident correct predictions, unbounded for confident wrong ones, and convex in \(w\).

4.2.1 · slides 244–246

Odds and logit

The odds of an event are \(\frac{p}{1 - p}\); the logit is the log-odds \(\operatorname{logit}(p) = \log\frac{p}{1 - p}\), the inverse of the logistic function, which logistic regression models as linear in the features.

4.2.3 · slides 253, 282

Odds ratio

The factor \(e^{w_j}\) by which the odds of the positive class are multiplied for a one-unit increase in feature \(x_j\), other features held fixed.

4.2.3 · slide 253

Regularisation parameter C

The inverse regularisation strength \(C = 1/\alpha\) used by sklearn's LogisticRegression; the higher \(C\), the less the model is regularised.

4.3 · slide 255

Confusion matrix

A table cross-tabulating actual against predicted classes; for two classes its cells are true positives (TP), false negatives (FN), false positives (FP) and true negatives (TN).

4.4.1 · slides 258–260

Accuracy

The fraction of all predictions that are correct, \(\frac{TP + TN}{TP + TN + FP + FN}\).

4.4.1, 11.1.2 · slides 259, 733

Precision

The fraction of predicted positives that are actually positive, \(\frac{TP}{TP + FP}\); also called positive predictive value.

4.4.1, 11.1.2 · slides 260, 733

Recall

The fraction of actual positives that are predicted positive, \(\frac{TP}{TP + FN}\); also called sensitivity, true positive rate (TPR) or detection rate.

4.4.1, 11.1.2 · slides 260, 733

False positive rate

The fraction of actual negatives wrongly predicted positive, \(FPR = \frac{FP}{FP + TN} = 1 - \text{specificity}\), where specificity (TNR) is \(\frac{TN}{TN + FP}\); also called the false alarm rate.

4.4.1, 4.4.3 · slides 264–265

F1 score

The harmonic mean of precision and recall, \(F_1 = \frac{2PR}{P + R}\).

4.4.1, 11.1.2 · slide 733

Accuracy paradox

Under class imbalance (one class much rarer than the other), a model can have high accuracy yet be useless: always predicting the majority class can score 99% while detecting none of the rare class.

4.4.2, 4.4.4 · slides 259, 274–275

ROC curve

Receiver Operating Characteristic: the plot of true positive rate against false positive rate as the decision threshold is swept over a classifier's continuous scores.

4.4.3 · slides 265–269

AUC

The area under the ROC curve, a threshold-free measure of separability: 1 for a perfect model, 0.5 for random guessing; it equals the probability that a random positive is scored above a random negative.

4.4.3 · slides 266, 270

One-vs-All and One-vs-One

Multiclass strategies built from binary classifiers: One-vs-All (one-vs-rest) trains one classifier per class against all others and predicts the highest score; One-vs-One trains one classifier per pair of classes, \(N(N - 1)/2\) in total, and predicts by majority vote.

4.5, 7.5 · slides 280–281, 481
M5 · Decision Tree Classifier · 14 items

Decision tree

A hierarchical model that classifies or predicts by applying attribute tests from the root to a leaf. The root node has no incoming edge; each internal node has one incoming edge, two or more outgoing edges and an attribute test; each leaf has one incoming edge, no outgoing edges and a class label. The tree represents a disjunction of conjunctions of attribute-value constraints.

5.1.1 · slides 287, 289, 294

Hunt's algorithm

The recursive partitioning scheme for growing a tree: if all records at a node share a class make it a leaf with that label; otherwise choose an attribute test, split the records into purer subsets and recurse on each.

5.1.2 · slide 292

ID3

Iterative Dichotomiser 3: a greedy top-down tree learner that at each node selects the attribute with the highest information gain, creates a branch per value, and recurses on the remaining attributes until nodes are pure or attributes run out (majority vote).

5.1.2 · slide 315

Impurity

A measure of how mixed the class labels in a node are; it is zero for a pure node (all records one class) and largest for an evenly mixed node. Entropy, the Gini index and classification error are impurity measures.

5.2 · slides 300–301

Entropy

The impurity measure \(\text{Entropy}(S) = -\sum_i p_i \log_2 p_i\), where \(p_i\) is the fraction of records in \(S\) of class \(i\); 0 for a pure node, \(\log_2 k\) (1 bit for two classes) for a uniform one.

5.2.1 · slides 302–303

Information gain

The expected reduction in entropy from partitioning \(S\) on attribute \(A\): \(\text{Gain}(S, A) = \text{Entropy}(S) - \sum_v \frac{\lvert S_v \rvert}{\lvert S \rvert}\text{Entropy}(S_v)\).

5.2.1 · slide 304

Gini index

The impurity measure \(\text{Gini}(S) = 1 - \sum_i p_i^2\), the probability that two records drawn at random from the node belong to different classes; used by CART.

5.2.2 · slide 327

Classification error (impurity)

The impurity measure \(\text{Error}(S) = 1 - \max_i p_i\), the fraction of records not in the node's majority class.

5.2.3 · slide 338

Split information and gain ratio

Split information is the entropy of \(S\) with respect to the values of \(A\), \(\text{SplitInfo}(S, A) = -\sum_v \frac{\lvert S_v \rvert}{\lvert S \rvert}\log_2 \frac{\lvert S_v \rvert}{\lvert S \rvert}\), large when a split fragments the data into many subsets. The gain ratio \(\text{Gain}(S, A)/\text{SplitInfo}(S, A)\) uses it to penalise many-valued attributes such as a customer ID.

5.2.4 · slides 339–343

Binary split

An attribute test with exactly two outcomes, either a grouping of a nominal attribute's values into two subsets or a threshold test \(A < c\) on a continuous attribute, with candidate thresholds at midpoints of adjacent sorted values.

5.2.2, 5.2.5 · slides 330, 335–336

Pre-pruning

Stopping tree growth early, before the training data are perfectly classified, using a stopping condition such as a gain threshold, a minimum number of records per node or a maximum depth.

5.3.2 · slide 353

Post-pruning

Growing the tree fully, then scanning it bottom-up and replacing a subtree by a leaf whenever doing so does not worsen accuracy on a validation set.

5.3.3 · slide 357

Minimum Description Length (MDL) principle

Choose the hypothesis \(h\) minimising \(L_{C_1}(h) + L_{C_2}(D \mid h)\), the bits to encode the hypothesis plus the bits to encode the data given it (its exceptions), where an event of probability \(p\) costs \(-\log_2 p\) bits. It formalises Occam's razor, the preference for the shortest hypothesis that still fits the data reasonably well.

5.3.4 · slides 360–362

CART

Classification and Regression Trees: an algorithm that builds binary trees for both tasks, splitting by the Gini index for classification and by variance (squared-error) reduction for regression, with leaves predicting the majority class or the mean target.

5.4 · slide 328
M6 · Instance-Based Learning (K-Nearest Neighbour) · 11 items

Dissimilarity matrix

An \(n \times n\) triangular matrix holding the distance \(d(i, j)\) between every pair of the \(n\) data objects, with zeros on the diagonal.

6.2 · slide 378

Minkowski distance

The distance of order \(h\) between two \(p\)-dimensional objects, \(d(i, j) = \left(\sum_f \lvert x_{if} - x_{jf} \rvert^h\right)^{1/h}\), a metric for \(h \ge 1\). \(h = 1\) is the Manhattan (city-block, \(L_1\)) distance, Hamming distance for bit vectors; \(h = 2\) the Euclidean (\(L_2\)) distance; \(h \to \infty\) the supremum (Chebyshev, \(L_\infty\)) distance \(\max_f \lvert x_{if} - x_{jf} \rvert\).

6.2.1 · slides 382–384

Simple matching distance

For nominal attributes, \(d(i, j) = \frac{p - m}{p}\), the fraction of the \(p\) attributes on which objects \(i\) and \(j\) do not match.

6.2.2 · slide 379

Symmetric and asymmetric binary attributes

With \(q\) attributes equal to 1 for both objects, \(r\) and \(s\) equal to 1 for only one, and \(t\) equal to 0 for both: a symmetric binary attribute has equally important states (gender), so \(d(i, j) = \frac{r + s}{q + r + s + t}\); an asymmetric one is informative only when 1 (a positive test), so 0–0 matches are ignored and \(d(i, j) = \frac{r + s}{q + r + s}\), one minus the Jaccard coefficient \(\frac{q}{q + r + s}\).

6.2.2 · slides 380–381

Gower distance

A dissimilarity for mixed attribute types: the (optionally weighted) average of per-attribute dissimilarities in \([0, 1]\), using range-scaled differences for numeric, mismatch for nominal and binary, and rank-normalised differences for ordinal attributes.

6.2.4 · slides 387–388

k-nearest neighbour (k-NN)

An instance-based method that predicts for a query \(x_q\) from its \(k\) closest training points: the majority class for classification, the mean target value for regression.

6.3.1 · slides 375, 393

Distance-weighted k-NN

A k-NN variant in which each neighbour's vote or value is weighted by a kernel of its distance, \(w_i = K(d(x_q, x_i))\), such as \(1/d^2\) or \(\exp(-(d/\sigma_0)^2)\).

6.3.3 · slide 397

Locally weighted regression

A lazy method that approximates the target near each query point \(x_q\) by fitting a local (usually linear) model whose training errors are weighted by a kernel of their distance from \(x_q\).

6.4.1 · slides 403–407

Model selection and model assessment

Model selection estimates the performance of different models (or hyper-parameter settings) to choose the best one; model assessment estimates the chosen model's generalisation error on new data. The holdout method does either by evaluating on a single held-out portion of the data not used for training.

6.5.1, 11.1.1 · slides 417–419, 733

k-fold cross-validation

Splitting the data into \(k\) folds, training on \(k - 1\) folds and validating on the remaining one, rotating so each fold is validated once, and averaging the \(k\) scores.

6.5.2 · slides 422–423

Leave-one-out and stratified cross-validation

Leave-one-out cross-validation is k-fold CV with \(k = n\): each model trains on all examples but one and is tested on the one left out. Stratified k-fold CV makes every fold preserve the class proportions of the whole data set.

6.5.2 · slide 422
M7 · Support Vector Machines · 15 items

Support vector machine (SVM)

A classifier that separates two classes with the hyperplane of maximum margin, optionally after an implicit kernel mapping to a higher-dimensional feature space; the simplest form, for linearly separable data, is the linear SVM.

7.1.2, 7.4.1 · slides 437, 464, 479

Separating hyperplane

The set \(\{x : w^\top x + b = 0\}\) that divides the input space into the regions classified \(+1\) and \(-1\) by \(f(x) = \operatorname{sign}(w^\top x + b)\); \(w\) is its normal vector and \(b\) its offset.

7.1.1 · slides 431–434

Margin

The width by which the decision boundary could be increased before hitting a data point; in canonical form it equals \(2/\lVert w \rVert\).

7.1.2 · slide 436

Support vectors

The training points lying on the margin, \(y_i(w^\top x_i + b) = 1\) in the hard-margin case, which alone determine the maximum-margin hyperplane; they are the points with \(\alpha_i > 0\).

7.1.2 · slides 437–438

Hard-margin SVM (primal problem)

The convex quadratic program \(\min_{w, b} \tfrac{1}{2}\lVert w \rVert^2\) subject to \(y_i(w^\top x_i + b) \ge 1\) for all \(i\), which requires every training point to be correctly classified outside the margin.

7.2.1 · slides 438–443

Lagrange multiplier

A variable \(\alpha_i \ge 0\) attached to the \(i\)-th constraint of the primal problem in the Lagrangian \(L = \tfrac{1}{2}\lVert w \rVert^2 - \sum_i \alpha_i[y_i(w^\top x_i + b) - 1]\); a valid solution never has a negative multiplier.

7.2.2 · slide 444

Dual problem

The equivalent optimisation over the multipliers, \(\max_\alpha \sum_i \alpha_i - \tfrac{1}{2}\sum_{i, j}\alpha_i\alpha_j y_i y_j x_i^\top x_j\) subject to \(\alpha_i \ge 0\) and \(\sum_i \alpha_i y_i = 0\), from which \(w = \sum_i \alpha_i y_i x_i\).

7.2.2 · slides 443–444

KKT conditions

The Karush–Kuhn–Tucker optimality conditions for the SVM: stationarity (\(w = \sum \alpha_i y_i x_i\), \(\sum \alpha_i y_i = 0\)), primal feasibility, dual feasibility (\(\alpha_i \ge 0\)) and complementary slackness \(\alpha_i[y_i(w^\top x_i + b) - 1] = 0\), so only points on the margin can have \(\alpha_i > 0\).

7.2.2 · slides 444, 464

Soft-margin SVM

The SVM for noisy or non-separable data: \(\min \tfrac{1}{2}\lVert w \rVert^2 + C\sum_i \xi_i\) subject to \(y_i(w^\top x_i + b) \ge 1 - \xi_i\), \(\xi_i \ge 0\), which allows some points inside the margin or misclassified.

7.3.1 · slides 456, 459

Slack variable

The amount \(\xi_i \ge 0\) by which point \(i\) violates the margin: 0 on or outside the correct margin, between 0 and 1 inside the margin but correctly classified, above 1 misclassified.

7.3.1 · slides 456–457

Cost parameter C

The soft-margin hyper-parameter that weights the total slack against the margin: large \(C\) penalises violations heavily (narrow margin, risk of overfitting), small \(C\) tolerates them (wide margin).

7.3.2 · slides 457, 459

Hinge loss

The loss \(\max(0, 1 - y f(x))\) on a prediction \(f(x) = w^\top x + b\); it equals the optimal slack, so the soft-margin SVM minimises \(\tfrac{1}{2}\lVert w \rVert^2 + C\sum_i \max(0, 1 - y_i f(x_i))\).

7.3.1 · slides 456–459

Kernel function

A function \(K(x_i, x_j) = \phi(x_i)^\top \phi(x_j)\) that returns the inner product of two points in a feature space without computing \(\phi\); a valid (Mercer) kernel gives a symmetric positive semi-definite Gram matrix.

7.4.1, 7.4.2 · slides 467–468

Kernel trick

Replacing every inner product \(x_i^\top x_j\) in the SVM dual and decision function by a kernel \(K(x_i, x_j) = \phi(x_i)^\top \phi(x_j)\), so the SVM learns a linear boundary in the feature space of the mapping \(\Phi: x \to \phi(x)\), where the data may be separable, without ever computing \(\phi\) explicitly.

7.4.1 · slides 466–469, 476

Polynomial, Gaussian (RBF) and sigmoid kernels

The polynomial kernel \((1 + x_i^\top x_j)^p\) is the inner product over all monomials of degree up to \(p\) (degree 1, or the homogeneous \(x_i^\top x_j\), is the linear kernel). The Gaussian RBF kernel \(\exp\left(-\frac{\lVert x_i - x_j \rVert^2}{2\sigma^2}\right)\) is a similarity in \((0, 1]\) with an infinite-dimensional feature space. The sigmoid kernel \(\tanh(\beta_0 x_i^\top x_j + \beta_1)\) is not positive semi-definite for every parameter choice.

7.4.2 · slides 477–478
M8 · Bayesian Learning · 17 items

Likelihood and log-likelihood

The likelihood is the probability (or density) of the observed data viewed as a function of the parameter, \(L(\theta) = \prod_{i=1}^{n} f(x_i \mid \theta)\) for i.i.d. samples; the log-likelihood \(LL(\theta) = \sum_i \log f(x_i \mid \theta)\) has the same maximiser and turns products into sums.

8.1.1 · slides 493, 501

Maximum likelihood estimation (MLE)

Choosing the parameters that make the observed data most likely, \(\hat{\theta}_{\text{MLE}} = \arg\max_\theta LL(\theta)\), found by differentiating \(LL\) and solving.

8.1.1 · slides 493, 501, 509

Maximum a posteriori (MAP) estimation

Choosing the parameters (or hypothesis) with the highest posterior probability, \(\hat{\theta}_{\text{MAP}} = \arg\max_\theta P(D \mid \theta)P(\theta)\); it equals the MLE when the prior is uniform.

8.1.4 · slides 502, 509

Prior, posterior and evidence

The prior \(P(h)\) is the probability of hypothesis \(h\) before seeing the data; the posterior \(P(h \mid D)\) is its probability after observing the training data \(D\); the evidence \(P(D) = \sum_h P(D \mid h)P(h)\) is the probability of the data averaged over all hypotheses, which normalises the posterior.

8.2.1 · slide 492

Bayes' theorem

\(P(h \mid D) = \frac{P(D \mid h)\,P(h)}{P(D)}\): posterior equals likelihood times prior, divided by the evidence.

8.2.1 · slide 492

Bayes optimal classifier

The classifier that predicts \(\arg\max_{v} \sum_{h \in H} P(v \mid h)P(h \mid D)\), combining the predictions of all hypotheses weighted by their posteriors; no other classifier using the same hypothesis space and prior performs better on average.

8.2.2 · slides 505–506

Gibbs classifier

A classifier that draws one hypothesis at random according to the posterior \(P(h \mid D)\) and uses it to classify; its expected error is at most twice that of the Bayes optimal classifier.

8.2.3 · slide 508

Conditional independence

\(X\) is conditionally independent of \(Z\) given \(Y\) if \(P(X \mid Y, Z) = P(X \mid Y)\); Naïve Bayes assumes every pair of features is conditionally independent given the class, so \(P(X_1, \dots, X_n \mid Y) = \prod_i P(X_i \mid Y)\).

8.3.1 · slide 526

Naïve Bayes classifier

A generative classifier that predicts \(\hat{y} = \arg\max_y P(Y = y)\prod_i P(X_i = x_i \mid Y = y)\) under the conditional independence assumption, with probabilities estimated from training frequencies.

8.3.1, 8.3.2 · slides 527, 531

Zero-frequency problem and Laplace smoothing

The zero-frequency problem: an attribute value never seen with a class gives \(P(X_i = v \mid c) = 0\) and zeroes that class's whole Naïve Bayes product. Laplace smoothing fixes it by adding 1 to every count, \(P(A_i = v \mid c) = \frac{N_{vc} + 1}{N_c + d}\), with \(d\) the number of distinct values of \(A_i\).

8.3.3 · slides 532–535

m-estimate

The smoothed estimate \(P(A_i \mid c) = \frac{N_{ic} + m\,p}{N_c + m}\), where \(p\) is a prior estimate of the probability and \(m\) the equivalent sample size; Laplace smoothing is the case \(p = 1/d\), \(m = d\).

8.3.3 · slide 535

Gaussian Naïve Bayes

Naïve Bayes for continuous features that models each \(P(X_i \mid Y = y_k)\) as a normal density \(N(\mu_{ik}, \sigma_{ik}^2)\) with mean and variance estimated per (feature, class) pair.

8.3.4 · slides 540–542

Bag of words

A representation of a document by the counts (or presence) of each vocabulary word, ignoring word order and grammar.

8.3.5 · slide 551

Multinomial Naïve Bayes

Naïve Bayes for text that models word counts: \(P(w \mid c)\) is the smoothed share of class-\(c\) tokens that are \(w\), and each occurrence of a word in the document multiplies in its probability.

8.3.5 · slides 552–558

Bernoulli Naïve Bayes

Naïve Bayes for text with one binary feature per vocabulary word (present or absent in the document); \(P(w \mid c)\) is the smoothed share of class-\(c\) documents containing \(w\), and absent words contribute \(1 - P(w \mid c)\).

8.3.5 · slides 559–562

Generative model

A model of the class-conditional distribution \(P(X \mid Y)\) and the prior \(P(Y)\), from which \(P(Y \mid X)\) follows by Bayes' theorem and synthetic data can be sampled (Naïve Bayes, Gaussian mixtures).

8.3.1, 8.4 · slides 521–522

Discriminative model

A model of \(P(Y \mid X)\) (or the decision boundary) directly, without modelling how the inputs are generated (logistic regression, SVM).

8.4 · slides 521, 566
M9 · Ensemble Learning · 13 items

Ensemble learning

Combining the predictions of several base models (by averaging, voting or a learned combiner) so the ensemble is more accurate or stable than any single member. A homogeneous ensemble uses one model type trained on different data or weights (bagging, random forest, boosting); a heterogeneous ensemble combines different model types (stacking).

9.1.1 · slides 582–587

Weak learner

A model that performs only slightly better than random guessing, such as a decision stump; a strong learner is one with high accuracy, which ensembles build from many weak learners.

9.1.1 · slides 582–587, 631

Bootstrap sample

A sample of \(n\) records drawn with replacement from a training set of \(n\) records; it contains about 63.2% of the distinct records, some more than once.

9.2.1 · slides 589–596

Bagging

Bootstrap aggregating: training base models in parallel on independent bootstrap samples and aggregating them by averaging (regression) or majority vote (classification, the class chosen by most members; soft voting averages class probabilities instead); it mainly reduces variance.

9.2.1 · slides 597–602, 612

Out-of-bag (OOB) error

The error of a bagged ensemble estimated by predicting each record using only the models whose bootstrap samples did not contain it, giving a validation estimate without a separate hold-out set.

9.2.1, 9.2.2 · slides 596, 603

Random forest

A bagging ensemble of decision trees in which each tree is grown on a bootstrap sample and only a random subset of features is considered at each split; predictions are averaged or voted.

9.2.2 · slide 603

Boosting

Training base learners sequentially, each concentrating on the records the previous ones got wrong, and combining them in a weighted sum; it mainly reduces bias.

9.3.1 · slides 605, 641

AdaBoost

Adaptive Boosting: starting from equal record weights, each round fits a weak learner \(h_t\), computes its weighted error \(\varepsilon_t = \sum_{i: h_t(x_i) \ne y_i} w_i\) (the total weight of misclassified records) and its performance \(\alpha_t = \tfrac{1}{2}\ln\frac{1 - \varepsilon_t}{\varepsilon_t}\), increases the weights of misclassified records, renormalises, and finally predicts \(\operatorname{sign}(\sum_t \alpha_t h_t(x))\).

9.3.2 · slides 618–629

Decision stump

A one-level decision tree that splits on a single attribute test (e.g. Monthly Spend \(> 50\)); the usual weak learner in AdaBoost.

9.3.2 · slides 618, 626

Gradient boosting

Boosting that starts from a constant prediction and repeatedly fits a new tree to the current residuals (the negative gradient of the loss), adding it scaled by a learning rate.

9.3.3 · slides 615–616, 641

Shrinkage

Scaling each new tree's contribution by a learning rate \(\eta < 1\) (eta) before adding it to the ensemble, which makes boosting more conservative and reduces overfitting.

9.3.3, 9.3.4 · slides 635, 642

XGBoost

eXtreme Gradient Boosting: a gradient-boosted tree library that adds a regularised objective (penalties on the number of leaves and leaf values), shrinkage, depth-wise growth with pruning, sparsity-aware handling of missing values and cache-aware parallel computation.

9.3.4 · slides 630–643

Stacking

A heterogeneous ensemble in which several different base learners are trained and a second-level meta-model (often logistic regression) takes their predictions, ideally out-of-fold ones, as inputs and learns how to combine them into the final prediction.

9.4 · slides 644–648
M10 · Unsupervised Learning · 14 items

Cluster analysis

Finding groups of objects such that objects in a group are similar to one another and different from objects in other groups, without class labels.

10.1.1 · slides 654, 702–703

Partitional clustering

A division of the data objects into non-overlapping subsets (clusters) such that each object is in exactly one subset.

10.1.2 · slide 704

Hierarchical clustering

A set of nested clusters organised as a hierarchical tree (a dendrogram), built by repeatedly merging (agglomerative) or splitting (divisive) clusters.

10.1.2 · slide 704

Centroid

The mean of the points assigned to a cluster, \(\mu_k = \frac{\sum_n r_{nk} x_n}{\sum_n r_{nk}}\); usually not itself a data point.

10.2.1 · slide 659

K-means

A partitional algorithm that minimises \(J = \sum_n \sum_k r_{nk}\lVert x_n - \mu_k \rVert^2\), where the 1-of-K indicators \(r_{nk} \in \{0, 1\}\), \(\sum_k r_{nk} = 1\), record each point's cluster, by alternating an assignment step (each point to its nearest centroid) and an update step (recompute centroids) until assignments stop changing.

10.2.1, 10.2.2 · slides 655–660, 674

Elbow method

Choosing the number of clusters (or \(k\) in k-NN) by plotting an error measure such as SSE against \(K\) and taking the value at the bend, beyond which the curve flattens.

10.2.3, 6.3.2 · slides 670, 394

K-medoids

A partitional clustering algorithm whose cluster representatives are medoids, the actual data points with the smallest average dissimilarity to the other points of their cluster; it swaps a medoid with a non-medoid whenever that lowers the total dissimilarity, and is robust to outliers.

10.3 · slides 669, 711–715

Cluster validity indices

Numerical measures of clustering quality: an external index compares cluster labels with known class labels (entropy), an internal index uses only the data, typically cohesion (how close points within a cluster are, the within-cluster SSE) and separation (how distinct clusters are from one another), and a relative index compares two clusterings or clusters.

10.4.1, 10.1.1 · slides 718–722

Silhouette coefficient

For a point \(i\) with average distance \(a\) to its own cluster and smallest average distance \(b\) to another cluster, \(s = 1 - a/b\) if \(a < b\) (or \(b/a - 1\) otherwise); it lies in \([-1, 1]\), closer to 1 is better, and can be averaged over a cluster or a clustering.

10.4.2 · slide 722

Hard and soft clustering

Hard clustering assigns each point to exactly one cluster (K-means); soft (probabilistic) clustering gives each point a probability of belonging to every cluster (GMM).

10.5.1 · slides 673–675

Gaussian mixture model (GMM)

A density that is a weighted sum of \(K\) Gaussian components, \(p(x) = \sum_k \pi_k \mathcal{N}(x \mid \mu_k, \Sigma_k)\), where the mixing coefficient \(\pi_k = p(z_k = 1) \ge 0\) is the prior probability that a point comes from component \(k\) and \(\sum_k \pi_k = 1\).

10.5.2 · slides 680–688, 725

Responsibility

The posterior probability \(\gamma(z_{nk}) = \frac{\pi_k \mathcal{N}(x_n \mid \mu_k, \Sigma_k)}{\sum_j \pi_j \mathcal{N}(x_n \mid \mu_j, \Sigma_j)}\) that component \(k\) generated point \(x_n\); a point's responsibilities sum to 1.

10.5.3 · slide 690

Expectation-Maximisation (EM) algorithm

An iterative method for maximum likelihood with latent variables that alternates an E-step (compute responsibilities from the current parameters) and an M-step (re-estimate \(\pi_k, \mu_k, \Sigma_k\) by responsibility-weighted MLE) until the log-likelihood converges.

10.5.3 · slides 689–692

Covariance type

The constraint on GMM covariance matrices: spherical (round clusters, one variance each), diagonal (axis-aligned ellipses), tied (one shared covariance for all components) or full (any ellipse per component).

10.5.4 · slide 700
M11 · ML Model Evaluation, Comparison & FAccT ML · 11 items

MAD, MAPE and RMSE

Regression error metrics: the mean absolute deviation \(\text{MAD} = \frac{1}{n}\sum_i \lvert y_i - \hat{y}_i \rvert\) (also MAE); the mean absolute percentage error \(\text{MAPE} = \frac{100\%}{n}\sum_i \frac{\lvert y_i - \hat{y}_i \rvert}{\lvert y_i \rvert}\), scale-free but undefined when some \(y_i = 0\); and the root mean squared error \(\text{RMSE} = \sqrt{\frac{1}{n}\sum_i (y_i - \hat{y}_i)^2}\), in the target's units.

11.1.2 · slides 730, 733

Confidence interval for accuracy

An interval \(\hat{p} \pm z_{\alpha/2}\sqrt{\hat{p}(1 - \hat{p})/n}\) that contains a model's true accuracy with the stated confidence, given test accuracy \(\hat{p}\) on \(n\) independent test cases.

11.2.1 · slide 734

Statistical significance of a model difference

The conclusion that an observed accuracy gap between two models is unlikely to be due to the random choice of test data alone, judged by a hypothesis test (for example a two-proportion z test, or McNemar's test on a shared test set) at a chosen level such as 5%.

11.2.1 · slide 734

FAccT

Fairness, Accountability and Transparency in ML: fairness is the absence of bias towards an individual or group in a model's decisions, accountability assigns responsibility for failures, and transparency makes models understandable and compliant with regulation (privacy and robustness are related concerns).

11.3.1 · slides 735–736, 740

Algorithmic bias

Systematic, unfair differences in a model's outcomes across individuals or groups, arising because the model learns and amplifies patterns, including biases, present in its training data (the COMPAS risk-assessment case).

11.3.1 · slides 738, 740

Negative legacy

Bias inherited from historical data whose labels or records reflect past discrimination, so a model trained to reproduce them perpetuates it.

11.3.1 · slide 739

Fairness through unawareness

The insufficient criterion that a model is fair if no sensitive feature (race, gender) is used directly as an input; it fails because proxies, non-protected features correlated with the protected attribute (shopping location standing in for ethnicity), let the model infer it anyway (redundant encoding).

11.3.2 · slides 741–742

Demographic parity

The group-fairness criterion that the positive-prediction (selection) rate \(P(\hat{Y} = 1 \mid G = g)\) is equal across groups \(g\).

11.3.1, 11.3.2 · slides 740–742

Equal opportunity and equalized odds

Equal opportunity requires equal true positive rates across groups; equalized odds requires both equal true positive rates and equal false positive rates.

11.3.1 · slides 740–742

Interpretability

The degree to which a human can examine and understand the basis of a model's decisions; trees, linear and logistic regression and k-NN are inherently interpretable.

11.4.1 · slides 743–744

Black-box model

A model whose internal decision logic is too complex to inspect directly (random forests, boosted ensembles, deep networks), typically trading interpretability for predictive performance.

11.4.1, 11.4.2 · slides 748–749
