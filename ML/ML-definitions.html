Module 1 — Introduction · source: ML_CS 1_26th July 2026.pdf

Machine Learning

The field of study that gives computers the ability to learn from data without being explicitly programmed; formally, a program that improves its performance P at a task T with experience E.

ML_CS 1 · p16

Task, Performance, Experience (T, P, E)

The three elements of a well-defined learning problem <P, T, E>: T is what the system does, P is the metric measuring success, and E is the data/experience it learns from.

ML_CS 1 · p17-18

Supervised Learning

Learning a function f(x) from labelled examples (xᵢ, yᵢ) to predict the output y of unseen inputs.

ML_CS 1 · p33

Classification

Supervised learning where the target y is categorical; the model assigns each input to a discrete class.

ML_CS 1 · p33

Regression

Supervised learning where the target y is real-valued; the model predicts a continuous quantity.

ML_CS 1 · p39

Unsupervised Learning

Learning hidden structure from unlabelled data x₁…xₙ, e.g. clustering to minimise intra-cluster and maximise inter-cluster distances.

ML_CS 1 · p40

Reinforcement Learning

A feedback-based paradigm in which an agent learns a sequence of actions in an environment through rewards and penalties, without labelled data.

ML_CS 1 · p44

Semi-Supervised Learning

Learning that combines a small amount of labelled data with a large amount of unlabelled data.

ML_CS 1 · p50

Batch / Mini-Batch / Online Learning

Training regimes distinguished by data usage: batch uses all data per update, mini-batch uses a subset, and online (incremental) uses one instance at a time.

ML_CS 1 · p51

Instance-Based Learning

A "lazy" approach that stores training examples and classifies new points by comparing them to stored instances (e.g. KNN) rather than building an explicit model.

ML_CS 1 · p52

Model-Based Learning

An approach that detects patterns in training data and fits an explicit predictive model whose parameters generalise to new data.

ML_CS 1 · p52

Feature (Attribute / Predictor)

An input variable describing an object, used by a model to predict the target.

ML_CS 1 · p30

Module 2 — ML Workflow & Data · source: ML_CS 2_1Aug2026.pdf

Data Object

A single record/point/sample/instance/entity described by a collection of attributes.

ML_CS 2 · p7

Attribute

A property or characteristic of an object (aka variable, field, feature, dimension), e.g. a person's eye colour or temperature.

ML_CS 2 · p7

Nominal Attribute

A categorical attribute whose values only distinguish objects (=, ≠) with no order, e.g. zip codes, eye colour, sex.

ML_CS 2 · p8-11

Ordinal Attribute

A categorical attribute whose values can be ordered (<, >) but whose differences are not meaningful, e.g. grades, mineral hardness, {good, better, best}.

ML_CS 2 · p8-11

Interval Attribute

A numeric attribute with meaningful differences (+, −) but no true zero, e.g. calendar dates, temperature in Celsius/Fahrenheit.

ML_CS 2 · p8-11

Ratio Attribute

A numeric attribute with a true zero so both differences and ratios are meaningful, e.g. temperature in Kelvin, length, counts, age.

ML_CS 2 · p8-11

Discrete vs Continuous Attribute

Discrete attributes take a finite/countable set of values (counts, zip codes; binary is a special case); continuous attributes take real-number values (temperature, weight).

ML_CS 2 · p13

Dimensionality

The number of attributes describing each object; high dimensionality introduces sparsity and analysis challenges.

ML_CS 2 · p14

Noise

An extraneous object or the modification/distortion of original attribute values (e.g. voice distortion, TV "snow").

ML_CS 2 · p25

Outlier

A data object with characteristics considerably different from most other objects; may be nuisance noise or the actual analysis target (e.g. fraud).

ML_CS 2 · p26

Data Engineering

The process of converting raw data into prepared (clean, integrated) data.

ML_CS 2 · p29

Feature Engineering

Tuning prepared data to create the features expected by the model — extraction, selection, construction and transformation.

ML_CS 2 · p29, p49

Aggregation

Combining two or more attributes/objects into a single one for data reduction, change of scale, or more stable (lower-variance) data.

ML_CS 2 · p32

Data Cleansing

Removing or correcting noisy, inconsistent, intentional-error, missing, or duplicate records from raw data.

ML_CS 2 · p34

Interquartile Range (IQR)

The spread between the 75th and 25th percentiles, IQR = Q3 − Q1, used to detect outliers via the 1.5·IQR rule.

ML_CS 2 · p38

Sampling

Selecting a representative subset of data for analysis; a representative sample has approximately the same properties of interest as the full dataset.

ML_CS 2 · p41-42

Sampling Bias vs Sampling Noise

Sampling noise is random error from a small sample; sampling bias is systematic error from a flawed sampling process (persists even at large sample size).

ML_CS 2 · p41

Stratified Sampling

Sampling that preserves the proportions of subgroups (strata/classes) present in the full population.

ML_CS 2 · p44

Feature Scaling

Mapping continuous values from one range to a target range so features are comparable and fit distributional assumptions.

ML_CS 2 · p46

Normalization (Min-Max)

Rescaling a feature into a fixed range such as [0,1] or [−1,1]; used when bounds are known and the algorithm makes no distribution assumption.

ML_CS 2 · p47-48

Standardization (Z-Score)

Rescaling a feature to zero mean and unit variance; used when the algorithm assumes Gaussian data, not range-bounded and less outlier-sensitive.

ML_CS 2 · p47-48

Curse of Dimensionality

The phenomenon where increasing feature count makes data increasingly sparse, degrading learning; addressed by dimensionality reduction (e.g. PCA).

ML_CS 2 · p51

Feature Selection

Choosing a useful subset of existing input features — removing redundant, irrelevant or mostly-missing ones — to train the model.

ML_CS 2 · p52

Feature Construction

Creating new features by polynomial expansion, feature crossing (interactions), or domain business logic.

ML_CS 2 · p53

Discretization (Binning)

Converting a continuous attribute into a discrete one via interval or conceptual labels ("binning"/"bucketing").

ML_CS 2 · p55-56

One-Hot / Dummy Encoding

Mapping a categorical attribute to one or more binary indicator variables.

ML_CS 2 · p57

Label Encoding

Mapping categorical values to integer codes for a numeric representation.

ML_CS 2 · p57

Inductive Learning Hypothesis

The assumption that a hypothesis approximating the target function well over a large training set will also approximate it well over unseen examples.

ML_CS 2 · p62

Hypothesis

A candidate function/rule constraining attribute values; the most general labels every instance positive, the most specific labels none positive.

ML_CS 2 · p66

Module 3 — Linear Models for Regression · source: ML_CS 34_916 Aug 2026.pdf

Linear Regression

A model predicting a continuous target as a linear combination of input features and parameters; simple (one predictor) or multiple (several predictors).

ML_CS 34 · p9

Hypothesis / Model h(·)

The function mapping inputs to predicted outputs, parameterised by the θ's learned from data.

ML_CS 34 · p8

Cost Function

A function measuring the discrepancy between predictions and actual targets (e.g. mean squared error) that is minimized during training.

ML_CS 34 · p11-16

Convex Function

A function whose line segment between any two graph points lies on or above the graph, guaranteeing a single global minimum.

ML_CS 34 · p23

Closed-Form (Normal Equation) Solution

An analytic solution θ = (XᵀX)⁻¹Xᵀy that computes optimal linear-regression parameters directly, without iteration.

ML_CS 34 · p24

Vectorization

Expressing model computations as matrix/vector operations over the whole dataset instead of explicit loops.

ML_CS 34 · p25

Gradient Descent

An iterative optimization algorithm that repeatedly updates parameters in the direction of the negative gradient of the cost until convergence.

ML_CS 34 · p31

Learning Rate (α)

The step-size hyperparameter in gradient descent; too small converges slowly, too large may overshoot or diverge.

ML_CS 34 · p50

Batch Gradient Descent

Gradient descent that computes the gradient from all training data before each parameter update.

ML_CS 34 · p66

Stochastic Gradient Descent (SGD)

Gradient descent that updates parameters from a single training instance at a time — fast but noisy.

ML_CS 34 · p66

Mini-Batch Gradient Descent

Gradient descent that computes the gradient from small batches of data — the default for deep learning, balancing speed and stability.

ML_CS 34 · p66

R-squared

The proportion of variance in the target explained by the regression model; a goodness-of-fit measure (1 = perfect).

ML_CS 34 · p74

Basis Function

A transformation Φⱼ(x) of the input (e.g. a power of x) that lets a model linear in its weights fit non-linear relationships.

ML_CS 34 · p78

Polynomial Regression

Regression using polynomial basis functions of the input; still a linear model because it is linear in the weights.

ML_CS 34 · p76

Bias

Error from wrong/too-simple modelling assumptions; high bias underfits the data.

ML_CS 34 · p81

Variance

Error from sensitivity to the particular training set; high variance overfits, changing greatly with different data.

ML_CS 34 · p81

Underfitting

When a model is too simple to capture the data pattern — high bias, with both training and test error high.

ML_CS 34 · p82

Overfitting

When a model is too complex and learns training noise — low training error but high test error (poor generalization), i.e. high variance.

ML_CS 34 · p82

Regularization

Adding a penalty on weight magnitude to the cost to control model complexity and overfitting.

ML_CS 34 · p89

Ridge Regression (L2 / Tikhonov)

Regularized regression penalizing the sum of squared weights, shrinking them toward but not exactly zero.

ML_CS 34 · p96

Lasso Regression (L1)

Regularized regression penalizing the sum of absolute weights, able to set some weights exactly to zero (sparse model, feature selection).

ML_CS 34 · p97

Elastic Net

Regularization mixing L1 and L2 penalties via a ratio r (r=0 ⇒ Ridge, r=1 ⇒ Lasso); preferred with highly correlated features.

ML_CS 34 · p98

Module 4 — Logistic Regression & Evaluation · source: ML_CS 5 6.pdf

Generative Classifier

A probabilistic classifier that models the joint distribution P(X, Y) (e.g. Naive Bayes).

ML_CS 5 · p4

Discriminative Classifier

A probabilistic classifier that directly learns the decision boundary separating classes (e.g. logistic regression).

ML_CS 5 · p4

Logistic Regression

A statistical model for binary classification that predicts the probability an input belongs to a class using the logistic (sigmoid) function on a linear score.

ML_CS 5 · p7

Sigmoid (Logistic) Function

The function σ(z)=1/(1+e⁻ᶻ) that maps any real input to a value in (0,1), interpreted as a probability.

ML_CS 5 · p12

Discriminant Function

A function that takes an input vector x and assigns it to one of K classes Cₖ; a linear discriminant produces a hyperplane boundary.

ML_CS 5 · p9

Decision Boundary

The surface where a classifier's output switches class (for logistic regression, where output = 0.5); it may be linear or non-linear.

ML_CS 5 · p14

Cross-Entropy / Log Loss

The convex cost function for logistic regression that heavily penalizes confident wrong predictions and is zero when predictions match the labels.

ML_CS 5 · p20

Logit (Log-Odds)

logit(p)=log(p/(1−p)), the inverse of the logistic function; the linear score equals the log of the odds.

ML_CS 5 · p58

Odds Ratio

The exponential of a regression coefficient, e^w — the multiplicative change in odds for a one-unit increase in that predictor.

ML_CS 5 · p29

Confusion Matrix

A table of predicted vs actual classes (TP, FP, FN, TN) that is the basis of all classification metrics.

ML_CS 5 · p33

Accuracy

The fraction of all predictions that are correct; misleading under class imbalance.

ML_CS 5 · p34

Precision

Of instances predicted positive, the fraction that are actually positive: TP/(TP+FP).

ML_CS 5 · p44

Recall (True Positive Rate)

Of actual positive instances, the fraction correctly detected: TP/(TP+FN).

ML_CS 5 · p44

F1-Score

The harmonic mean of precision and recall, balancing the two into a single metric.

ML_CS 5 · p44 / EC2 · Q3

False Positive Rate (FPR)

Of actual negatives, the fraction wrongly predicted positive: FP/(FP+TN); the x-axis of the ROC curve.

ML_CS 5 · p44

ROC Curve

A plot of true positive rate against false positive rate across decision thresholds, showing the detection vs false-alarm trade-off.

ML_CS 5 · p41

AUC (Area Under ROC Curve)

A scalar measure of class separability: 1 for a perfect model, 0.5 for random guessing; higher is better.

ML_CS 5 · p42

Class Imbalance

A dataset where the class of interest is rare relative to the majority class (e.g. fraud, cancer), making accuracy a poor metric.

ML_CS 5 · p50

SMOTE

Synthetic Minority Oversampling Technique: generates new minority-class samples based on distances to nearest neighbours to balance training data.

ML_CS 5 · p51

One-vs-All (One-vs-Rest)

A multiclass strategy training N binary classifiers (each class vs the rest) and choosing the highest-scoring class.

ML_CS 5 · p56

One-vs-One

A multiclass strategy training N(N−1)/2 binary classifiers for every class pair and combining them by voting.

ML_CS 5 · p57

Module 5 — Exam-Referenced Terms · source: EC2 & EC3 instruction sheets

k-Nearest Neighbors (kNN)

An instance-based classifier that labels a new point by majority vote of its k closest training points under a distance metric.

EC3 · Q1

Manhattan Distance

The sum of absolute coordinate differences between two points (L1 distance).

EC3 · Q1

Bayes' Theorem

The rule P(A|B)=P(B|A)P(A)/P(B) for updating the probability of a hypothesis given evidence.

EC3 · Q2

Naive Bayes Classifier

A generative classifier applying Bayes' theorem under the assumption that features are conditionally independent given the class.

EC3 · Q3

Maximum Likelihood Estimation (MLE)

Estimating a parameter by choosing the value that maximizes the likelihood (usually log-likelihood) of the observed i.i.d. data.

EC3 · Q3

Entropy

A measure of impurity/disorder of class labels at a node, −Σ pᵢ log₂ pᵢ; zero when the node is pure.

EC2 · Q6

Information Gain

The reduction in entropy achieved by splitting on an attribute; the attribute with the highest gain is chosen.

EC2 · Q6

Gini Index

A node-impurity measure, 1 − Σ pᵢ², used as an alternative to entropy for decision-tree splits.

EC2 · Q6

Support Vector Machine (SVM)

A classifier that finds the maximum-margin separating hyperplane defined by support vectors and Lagrange multipliers.

EC3 · Q4

Kernel Trick

Using a kernel function (e.g. polynomial K(u,v)=(u·v+1)²) to implicitly map data into a higher-dimensional space where it becomes linearly separable.

EC3 · Q4

K-Means Clustering

A centroid-based algorithm that hard-assigns points to the nearest of K centroids and iteratively recomputes centroids as cluster means.

EC3 · Q5

Gaussian Mixture Model (GMM)

A probabilistic clustering model representing data as a mixture of Gaussian components with mixing weights, giving soft responsibilities per point.

EC3 · Q5

Bagging

An ensemble method training models on bootstrap samples and aggregating their predictions by voting/averaging.

EC3 · Q6

Random Forest

An ensemble of bagged decision trees that additionally randomly subsamples features at each split for extra decorrelation.

EC3 · Q6

Out-of-Bag (OOB) Samples

Training instances not selected in a given bootstrap sample, used to estimate a bagged model's error.

EC3 · Q6

AdaBoost

A boosting ensemble that sequentially reweights training instances (up-weighting misclassified ones) and combines weak learners by weight α.

EC3 · Q6

Binary Classification

A classification task with exactly two output classes (e.g. spam vs ham, positive vs negative).

ML_CS 5 · p55 (image)

Multiclass Classification

A classification task with three or more mutually-exclusive output classes (e.g. Yes/No/Maybe), commonly solved by reducing it to several binary problems via One-vs-All or One-vs-One.

ML_CS 5 · p55 (image)

Early Stopping

A regularization technique that halts training at the epoch of minimum validation-set error, before the model begins to overfit the training data.

ML_CS 34 · p89 (image)

Pseudo-Inverse

A generalized matrix inverse (Python: numpy.linalg.pinv) used to solve the normal equation when XᵀX is singular / not invertible.
