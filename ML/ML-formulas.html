M1 · Introduction to Machine Learning · 5 items

Learning as function approximation

\[ \text{find } h \in H \text{ such that } h(x) \approx f(x) \text{ for all } x \in X \]

where: \(X\) is the instance space, \(f: X \to Y\) the unknown target function, \(H\) the hypothesis space, and the training data \(D = \{\langle x_i, f(x_i) \rangle\}\) is the experience \(E\); the task \(T\) and performance measure \(P\) (e.g. accuracy, MSE) complete Mitchell's \(\langle T, P, E \rangle\).

use: state any ML problem by naming \(T\), \(P\) and \(E\). The inductive learning hypothesis says an \(h\) that fits a large enough \(D\) well will also fit unseen \(x\) well. Classification has \(Y = \{c_1, \dots, c_k\}\), regression has \(Y = \mathbb{R}\), probability estimation has \(Y = [0, 1]\).

Size of the instance and hypothesis spaces

\[ \lvert X \rvert = \prod_{j=1}^{d} \lvert V_j \rvert, \qquad \lvert H_{\text{all}} \rvert = 2^{\lvert X \rvert}, \qquad \lvert H_{\text{conj}} \rvert = \prod_{j=1}^{d} \left( \lvert V_j \rvert + 1 \right) + 1 \]

where: \(d\) attributes, \(\lvert V_j \rvert\) values of attribute \(j\); \(H_{\text{all}}\) = every Boolean labelling of \(X\); \(H_{\text{conj}}\) = conjunctions where each attribute is a value or "?" (any), plus the single empty hypothesis \(\varnothing\) that rejects everything.

use: shows why an unrestricted \(H\) has no inductive bias (it can memorise any \(D\)) while a restricted \(H\) can generalise. The most specific hypothesis keeps a value only where all positives agree; the most general is \(\langle ?, \dots, ? \rangle\) unless negatives rule it out.

1.4.2, 1.4.3 · slides 119–123, 130

Supervised, unsupervised and reinforcement signals

\[ \text{supervised: } \{(x_i, y_i)\}, \qquad \text{unsupervised: } \{x_i\}, \qquad \text{RL: } G = r_1 + \gamma r_2 + \gamma^2 r_3 + \dots \]

where: \(y_i\) is a label; in RL an agent in state \(s_t\) takes action \(a_t\), receives reward \(r_{t+1}\), and \(\gamma \in [0, 1]\) discounts future reward (\(\gamma = 1\) is a plain cumulative reward).

use: decide the learning type from the feedback signal: labels (supervised), none (unsupervised: group by minimising intra-cluster and maximising inter-cluster distance), delayed reward for a sequence of decisions (RL), few labels plus many unlabelled points (semi-supervised).

1.2.1, 1.2.2, 1.2.3, 1.2.4 · slides 20–40

Batch versus online updating

\[ \text{batch: } \theta \leftarrow \theta - \eta \, \frac{1}{n} \sum_{i=1}^{n} \nabla \ell_i(\theta), \qquad \text{online: } \theta \leftarrow \theta - \eta \, \nabla \ell_t(\theta) \]

where: \(\ell_i\) is the loss on example \(i\), \(\eta\) the learning rate, \(\ell_t\) the loss on the single example arriving at time \(t\); mini-batch averages over \(b\) examples (\(1 < b < n\)).

use: batch retrains on all data at once; online learns incrementally from a stream and can track drift, but a large \(\eta\) makes it forget old data quickly.

1.3.1 · slides 48–51

Instance-based versus model-based cost

\[ \text{instance-based: train } O(1), \ \text{query } O(Nd); \qquad \text{model-based: train } O(\text{fit}), \ \text{query } O(\lvert \theta \rvert) \]

where: \(N\) stored examples, \(d\) features, \(\lvert \theta \rvert\) number of model parameters (e.g. \(d + 1\) for a linear model).

use: lazy (instance-based) learners store the data and pay at query time (one distance per stored point); eager (model-based) learners pay once to fit, then discard the data. Total query cost = queries per day \(\times\, N \times d\).

Measurement levels and the operations they allow

Level Allowed operations Allowed transformation Typical statistics
Nominal \(=, \ne\) any one-to-one relabelling mode, entropy, \(\chi^2\)
Ordinal \(=, \ne, <, >\) any order-preserving \(x' = g(x)\) median, percentiles, rank correlation
Interval \(+, -\) as well \(x' = a x + b\), \(a > 0\) mean, standard deviation, Pearson \(r\)
Ratio \(\times, \div\) as well \(x' = a x\), \(a > 0\) geometric mean, coefficient of variation

where: each level inherits every operation of the levels above it; a ratio scale has a true zero.

use: a ratio claim ("twice as hot") is only meaningful on a ratio scale: \(30\,{}^\circ\text{C}/15\,{}^\circ\text{C} = 2\) but \(303.15\,\text{K}/288.15\,\text{K} \approx 1.05\). Ratios of differences, \(\frac{x_1 - x_2}{x_3 - x_4}\), are invariant on an interval scale.

2.1.2, 2.1.3 · slides 63–69

Density, sparsity and storage

\[ \text{density} = \frac{\text{nnz}}{n \times d}, \qquad \text{sparsity} = 1 - \text{density}, \qquad \text{CSR bytes} \approx \text{nnz} \times (b_v + b_i) + (n + 1) \times b_i \]

where: nnz = number of non-zero entries in the \(n \times d\) data matrix; \(b_v, b_i\) bytes per stored value and per index. Dense storage needs \(n \times d \times b_v\) bytes.

use: document-term matrices are extremely sparse, so only non-zeros (with their column index) are stored; dimensionality \(d\), sparsity and resolution decide which algorithms and distance measures are practical.

2.1.4 · slides 70–75

Aggregation reduces variance

\[ \operatorname{Var}(\bar{x}_m) = \frac{\sigma^2}{m}, \qquad \operatorname{SD}(\bar{x}_m) = \frac{\sigma}{\sqrt{m}} \]

where: \(\bar{x}_m\) is the mean of \(m\) aggregated values (e.g. 7 daily sales into one weekly average), \(\sigma^2\) the variance of one value, values assumed independent.

use: aggregation changes scale (days to weeks, cities to states) and gives more stable data, at the cost of detail. The coefficient of variation \(\sigma/\mu\) drops by the factor \(\sqrt{m}\).

2.2.3 · slides 88–90

Handling missing values

\[ \hat{x}_{ij} = \frac{1}{\lvert O_j \rvert} \sum_{i' \in O_j} x_{i'j} \quad \text{(mean)}, \qquad \hat{x}_{ij} = \operatorname{median}_{i' \in O_j} x_{i'j}, \qquad \hat{x}_{ij} = \frac{1}{\lvert O_{j,c} \rvert} \sum_{i' \in O_{j,c}} x_{i'j} \]

where: \(O_j\) are the rows where feature \(j\) is observed; \(O_{j,c}\) those that also belong to the same class \(c\) as row \(i\) (class-conditional imputation).

use: eliminate rows only when few are missing; otherwise impute (median is robust to skew/outliers; mode for categorical). Compute the imputation statistic on the training split only and reuse it on validation and test data, or the test set leaks into training.

2.2.1, 2.2.2 · slides 81–93

IQR outlier fences

\[ \text{IQR} = Q_3 - Q_1, \qquad \text{fences: } \left[ Q_1 - 1.5\,\text{IQR}, \ Q_3 + 1.5\,\text{IQR} \right] \]

where: \(Q_1, Q_3\) are the lower and upper quartiles of the sorted data. The slides use the median-of-halves method: \(Q_1\) = median of the lower half, \(Q_3\) = median of the upper half (for odd \(n\), leave the median out of both halves).

use: points outside the fences are flagged as outliers; robust to skew because quartiles ignore the tails. Other conventions (position \(k(n + 1)/4\), NumPy's interpolation at \(p(n - 1)\)) give slightly different quartiles (slide 96 data gives \(Q_3 = 14.5\) by halves, \(14.75\) by position), so state the method used.

2.3.1 · slides 94–96

The 3σ rule

\[ \left[ \bar{x} - 3\sigma, \ \bar{x} + 3\sigma \right], \qquad P(\lvert Z \rvert > 3) \approx 0.27\%, \qquad P(\lvert Z \rvert \le 1, 2, 3) \approx 68\%, 95\%, 99.7\% \]

where: \(\bar{x}\) is the mean, \(\sigma\) the standard deviation, \(Z \sim N(0, 1)\).

use: only for roughly normal data. On skewed data the mean and \(\sigma\) are themselves inflated by the outliers (masking), so the IQR rule is safer. A single extreme point \(x_1\) among \(n\) can never exceed \(\sqrt{n - 1}\) standard deviations from the mean.

2.3.2 · slides 94, 97

Stratified allocation and data partitioning

\[ n_h = n \cdot \frac{N_h}{N}, \qquad n_{\text{train}} : n_{\text{val}} : n_{\text{test}} \approx 60{:}20{:}20 \ \text{or} \ 70{:}15{:}15 \]

where: \(N\) records in total, \(N_h\) in stratum (class) \(h\), \(n\) the size of the sample or split.

use: stratified sampling keeps each class's proportion the same in every split, which matters for rare classes; simple random sampling can leave a rare class out of a small split entirely. Fit on train, tune on validation, report once on test.

2.4.1, 2.4.2 · slides 98–101

Class imbalance and resampling arithmetic

\[ \text{IR} = \frac{N_{\text{maj}}}{N_{\text{min}}}, \qquad \text{undersample: keep } N_{\text{min}} \text{ of each}, \qquad \text{oversample: add } N_{\text{maj}} - N_{\text{min}} \text{ minority points} \]

where: \(N_{\text{maj}}, N_{\text{min}}\) are the majority and minority class counts; IR is the imbalance ratio.

use: the all-majority classifier already scores accuracy \(N_{\text{maj}}/N\). Undersampling throws data away; oversampling duplicates or synthesises minority points (risk of overfitting). Resample the training split only, after splitting.

2.4.3 · slide 102

SMOTE synthetic point

\[ x_{\text{new}} = x_i + \lambda \left( x_{\text{nn}} - x_i \right), \qquad \lambda \sim U(0, 1) \]

where: \(x_i\) is a minority example, \(x_{\text{nn}}\) one of its \(k\) nearest minority-class neighbours, \(\lambda\) a random fraction.

use: creates a new minority point on the segment between two minority points. It can place points inside majority regions when minority points are scattered or noisy, and must be applied after the train/test split.

2.4.3 · slide 102

Min-max normalisation

\[ x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}} \left( \text{new\_max} - \text{new\_min} \right) + \text{new\_min} \]

where: \(x_{\min}, x_{\max}\) are the training minimum and maximum of the feature; the default target range is \([0, 1]\).

use: for distance- and gradient-based methods (k-NN, k-means, SVM, gradient descent, neural nets). Sensitive to outliers: one extreme value squashes all others. A test value outside the training range maps outside \([0, 1]\) (e.g. \(1.1875\)). Trees do not need scaling; target values are not scaled.

2.5.1, 6.2.5 · slide 105

Z-score, decimal and robust scaling

\[ z = \frac{x - \bar{x}}{\sigma}, \qquad x' = \frac{x}{10^{j}} \ \text{with the smallest } j \text{ such that } \max \lvert x' \rvert < 1, \qquad x' = \frac{x - \text{median}}{\text{IQR}} \]

where: \(\bar{x}, \sigma\) are the training mean and standard deviation (the course uses the population \(\sigma\), dividing by \(N\), unless told otherwise).

use: z-score gives mean 0 and SD 1 and suits roughly normal features; robust scaling resists outliers; decimal scaling just shifts the decimal point. All statistics come from the training split.

2.5.1, 6.2.5 · slide 105

Equal-width and equal-depth binning

\[ W = \frac{x_{\max} - x_{\min}}{k}, \qquad \text{bin } i = \left[ x_{\min} + (i - 1)W, \ x_{\min} + iW \right), \qquad \text{equal-depth: } \frac{N}{k} \text{ values per bin} \]

where: \(k\) is the number of bins and \(N\) the number of values. Smoothing then replaces each value by its bin mean, median or nearest boundary.

use: equal-width is simple but outliers leave most bins empty; equal-depth (equal-frequency) adapts to skew so every bin carries the same number of records.

2.5.3 · slides 112–113

One-hot and label encoding

\[ \text{one-hot: } v \mapsto e_v \in \{0, 1\}^{m}, \qquad \text{label: } v \mapsto \{0, 1, \dots, m - 1\} \]

where: \(m\) is the number of categories and \(e_v\) the indicator vector with a single 1 in position \(v\).

use: label encoding imposes a fake order and fake equal spacing, so a linear model gives category 2 exactly twice the effect of category 1; use it only for ordinal data or tree models. One-hot adds \(m\) columns; with an intercept drop one (\(m - 1\) dummies) to avoid perfect collinearity (the dummy-variable trap).

2.5.4 · slide 114

Curse of dimensionality in the unit cube

\[ e(d) = f^{1/d}, \qquad P(\text{within } \varepsilon \text{ of the boundary}) = 1 - (1 - 2\varepsilon)^{d}, \qquad \text{grid points} = g^{d} \]

where: points uniform in \([0, 1]^d\); \(e(d)\) is the edge of a sub-cube holding fraction \(f\) of the data; \(\varepsilon\) the boundary width; \(g\) points per axis.

use: with \(f = 0.1\), \(e(10) \approx 0.79\), so a "local" neighbourhood spans most of every axis. With \(\varepsilon = 0.05\) the shell fraction is \(1 - 0.9^{d}\), almost 1 for \(d = 50\). Remedies: feature selection and dimensionality reduction (e.g. PCA).

M3 · Linear Models for Regression · 20 items

Linear hypothesis

\[ h_\theta(x) = \theta^\top x = \theta_0 + \theta_1 x_1 + \dots + \theta_d x_d, \qquad \hat{y} = X\theta \]

where: \(x_0 = 1\) is prepended so \(\theta_0\) is the intercept; \(X\) is the \(n \times (d + 1)\) design matrix (first column all ones), \(\theta\) the weight vector.

use: simple regression has \(d = 1\), multiple regression \(d > 1\). \(\theta_j\) is the change in \(\hat{y}\) per unit increase in \(x_j\) with the other features held fixed. "Linear" means linear in \(\theta\), not in \(x\).

3.1.1 · slides 128–135

Squared-error cost function

\[ J(\theta) = \frac{1}{2n} \sum_{i=1}^{n} \left( h_\theta(x_i) - y_i \right)^2 = \frac{1}{2n} \lVert X\theta - y \rVert^2, \qquad \text{SSE} = \sum_i (h_\theta(x_i) - y_i)^2, \qquad \text{MSE} = \frac{\text{SSE}}{n} \]

where: \(n\) training examples \((x_i, y_i)\).

use: the \(\frac{1}{2}\) only cancels the 2 from differentiation; it does not move the minimiser. So \(J = \text{SSE}/(2n)\): with SSE \(= 0.1667\) and \(n = 3\), \(J = 0.0278\). Always check which scaling a question uses.

3.1.2 · slides 135–144

Gradient and Hessian of the cost

\[ \frac{\partial J}{\partial \theta_j} = \frac{1}{n} \sum_{i=1}^{n} \left( h_\theta(x_i) - y_i \right) x_{ij}, \qquad \nabla J = \frac{1}{n} X^\top (X\theta - y), \qquad H = \frac{1}{n} X^\top X \]

where: \(x_{ij}\) is feature \(j\) of example \(i\) (\(x_{i0} = 1\)); \(H\) is the Hessian.

use: \(v^\top H v = \frac{1}{n} \lVert Xv \rVert^2 \ge 0\), so \(H\) is positive semi-definite and \(J\) is convex: every local minimum is global and gradient descent with a small enough \(\eta\) converges to it.

3.1.2, 3.3.5 · slides 156–157, 172–173

Matrix-calculus rules

\[ \nabla_\theta (b^\top \theta) = b, \qquad \nabla_\theta (\theta^\top A \theta) = (A + A^\top)\theta = 2A\theta \ (A \text{ symmetric}), \qquad \nabla_\theta \lVert X\theta - y \rVert^2 = 2X^\top (X\theta - y) \]

where: \(b\) a constant vector, \(A\) a constant square matrix; also \((AB)^\top = B^\top A^\top\) and \((AB)^{-1} = B^{-1}A^{-1}\).

use: expand \(\lVert X\theta - y \rVert^2 = \theta^\top X^\top X \theta - 2y^\top X\theta + y^\top y\), differentiate term by term, set to zero: this is the derivation of the normal equations.

3.2.1, 3.1.2 · slides 149–153

Normal equations

\[ X^\top X \theta = X^\top y \quad \Longrightarrow \quad \theta = (X^\top X)^{-1} X^\top y \]

where: \(X\) is the design matrix with a column of ones, \(y\) the target vector.

use: a one-shot exact solution, no learning rate, no iterations and no feature scaling needed. Needs \(X^\top X\) invertible (at least \(d + 1\) examples, no perfectly collinear features); costs about \(O(d^3)\), so gradient descent is preferred for very many features. At the solution the residual \(r = X\theta - y\) satisfies \(X^\top r = 0\).

3.2.1 · slides 149–153

Simple regression in closed form

\[ \theta_1 = \frac{\sum_i (x_i - \bar{x})(y_i - \bar{y})}{\sum_i (x_i - \bar{x})^2} = \frac{\sum x_i y_i - n\bar{x}\bar{y}}{\sum x_i^2 - n\bar{x}^2}, \qquad \theta_0 = \bar{y} - \theta_1 \bar{x} \]

where: \(\bar{x}, \bar{y}\) are sample means; these solve \(n\theta_0 + \theta_1 \sum x_i = \sum y_i\) and \(\theta_0 \sum x_i + \theta_1 \sum x_i^2 = \sum x_i y_i\).

use: the fastest hand route for one feature. The fitted line always passes through \((\bar{x}, \bar{y})\).

3.2.1 · slides 149–153

Inverse of a 2×2 matrix

\[ \begin{bmatrix} a & b \\ c & d \end{bmatrix}^{-1} = \frac{1}{ad - bc} \begin{bmatrix} d & -b \\ -c & a \end{bmatrix} \]

where: \(ad - bc \ne 0\) is the determinant.

use: for one-feature normal equations, \(X^\top X = \begin{bmatrix} n & \sum x_i \\ \sum x_i & \sum x_i^2 \end{bmatrix}\). For \(3 \times 3\) systems, solve \(X^\top X \theta = X^\top y\) by elimination rather than inverting.

3.2.1 · slides 149–153

Gradient-descent update

\[ \theta_j \leftarrow \theta_j - \eta \, \frac{\partial J}{\partial \theta_j} = \theta_j - \eta \, \frac{1}{n} \sum_{i=1}^{n} \left( h_\theta(x_i) - y_i \right) x_{ij} \]

where: \(\eta\) is the learning rate; all \(\theta_j\) are updated simultaneously from the same old \(\theta\).

use: batch GD uses all \(n\) examples per step. A positive derivative moves \(\theta_j\) down, a negative one moves it up; at the minimum the gradient is 0 and the update stops. Recompute residuals \(h(x_i) - y_i\) after every step.

3.3.1 · slides 155–171

Learning-rate stability

\[ e_{k+1} = (1 - \eta a)\, e_k, \quad e_k = (1 - \eta a)^k e_0, \qquad \text{converges iff } 0 < \eta < \frac{2}{a}; \qquad \text{in general } 0 < \eta < \frac{2}{\lambda_{\max}(H)} \]

where: for a 1-D quadratic cost \(J'(\theta) = a(\theta - \theta^*)\) with \(a = \frac{1}{n}\sum x_i^2\); \(e_k = \theta_k - \theta^*\); \(\lambda_{\max}(H)\) is the largest eigenvalue of the Hessian.

use: \(\eta\) too small: slow, monotone descent; \(\eta a\) between 1 and 2: oscillating but converging; \(\eta > 2/a\): divergence (cost grows). The fastest single-coordinate rate is \(\eta = 1/a\). Diagnose from the cost curve.

3.3.2, 3.3.5 · slides 161–173

Feature scaling and the descent path

\[ e_j \leftarrow (1 - \eta s_j^2)\, e_j, \qquad \kappa = \frac{\lambda_{\max}(H)}{\lambda_{\min}(H)}, \qquad \text{iterations} \propto \kappa \]

where: for uncorrelated features \(H = \operatorname{diag}(s_1^2, \dots, s_d^2)\) with \(s_j^2 = \frac{1}{n}\sum x_{ij}^2\); \(\kappa\) is the condition number.

use: one \(\eta\) must satisfy \(\eta < 2/\max_j s_j^2\), so the small-scale coordinate barely moves: elongated contours, zig-zag path, many iterations (e.g. \(s^2 = 1\) and \(250{,}000\) force \(\eta < 8 \times 10^{-6}\)). Scaling makes \(\kappa \approx 1\) (round contours). The minimiser is the same, only the path changes.

3.3.3, 2.5.1 · slides 175–176

Batch, mini-batch and stochastic gradient descent

\[ \theta \leftarrow \theta - \eta \frac{1}{\lvert B \rvert} \sum_{i \in B} (h_\theta(x_i) - y_i)\, x_i, \qquad B = \{1..n\} \ (\text{batch}), \quad \lvert B \rvert = b \ (\text{mini-batch}), \quad \lvert B \rvert = 1 \ (\text{SGD}) \]

where: \(B\) is the set of examples used for one update; an epoch is one pass over all \(n\) examples.

use: one epoch is 1 update in batch GD, \(n/b\) in mini-batch, \(n\) in SGD (the parameters change after each example, so later examples see updated \(\theta\)). SGD is noisy but cheap per step and can escape shallow regions; use a decaying \(\eta\) for it to settle.

3.3.4, 1.3.1 · slides 145–146, 175, 190

Linear basis-function model

\[ y(x, w) = \sum_{j=0}^{M} w_j \phi_j(x), \quad \phi_0(x) = 1, \qquad w = (\Phi^\top \Phi)^{-1} \Phi^\top y, \qquad \Phi_{ij} = \phi_j(x_i) \]

where: \(\phi_j\) are fixed basis functions; polynomial regression uses \(\phi_j(x) = x^j\), Gaussian bases \(\phi_j(x) = \exp\left(-\frac{(x - \mu_j)^2}{2s^2}\right)\); \(\Phi\) is the design matrix.

use: non-linear in \(x\) but still linear in \(w\), so the normal equations and gradient descent work unchanged. Higher degree \(M\) lowers training error but raises variance (overfitting).

3.4.1 · slides 199–202

Bias–variance decomposition

\[ E\left[ (y - \hat{f}(x))^2 \right] = \sigma^2 + \left( E[\hat{f}(x)] - f(x) \right)^2 + \operatorname{Var}\left( \hat{f}(x) \right) \]

where: \(y = f(x) + \varepsilon\) with noise variance \(\sigma^2\) (irreducible error); the expectation is over training sets; the middle term is \(\text{Bias}^2\).

use: underfitting = high bias (train and test error both high, close together); overfitting = high variance (train error low, test error much higher). For least squares with \(p\) parameters, expected train SSE \(= n\,\text{Bias}^2 + \sigma^2(n - p)\) and expected test SSE \(= n\,\text{Bias}^2 + \sigma^2(n + p)\), so the gap grows with \(p\) and shrinks with \(n\).

3.4.2 · slides 203–213

Ridge (L2) regression

\[ J_{\text{ridge}}(w) = J(w) + \frac{\lambda}{2} \sum_{j=1}^{d} w_j^2, \qquad w_j \leftarrow w_j (1 - \eta\lambda) - \eta \frac{\partial J}{\partial w_j}, \qquad w = (X^\top X + \lambda I)^{-1} X^\top y \]

where: \(\lambda \ge 0\) is the regularisation constant; the intercept \(w_0\) is not penalised (its update has no shrink factor); the closed form is for the unscaled cost \(\lVert Xw - y \rVert^2 + \lambda \lVert w \rVert^2\) on centred data.

use: every step multiplies each weight by \((1 - \eta\lambda)\) before the usual gradient step (slide example: \(0.9\)). Weights shrink smoothly towards 0 but never exactly to 0. \(X^\top X + \lambda I\) is invertible for every \(\lambda > 0\), which also fixes collinearity.

3.5.1, 3.5.4 · slides 219, 223

Lasso (L1) regression

\[ J_{\text{lasso}}(w) = J(w) + \lambda \sum_{j=1}^{d} \lvert w_j \rvert, \qquad w_j \leftarrow w_j - \eta \frac{\partial J}{\partial w_j} - \eta\lambda \operatorname{sign}(w_j) \quad (w_j \ne 0) \]

where: \(\operatorname{sign}(w_j) = \pm 1\); at \(w_j = 0\) the penalty has no derivative, only the subgradient interval \([-\lambda, \lambda]\).

use: subtracts a fixed amount \(\eta\lambda\) towards 0 each step, so it can set weights exactly to 0 (feature selection). \(w_j = 0\) is optimal exactly when \(\left\lvert \frac{\partial J}{\partial w_j} \right\rvert \le \lambda\) there. Erratum: the slide 224 Lasso answer (weights larger than the unregularised ones) is wrong; a correct Lasso step moves each non-zero weight towards 0 relative to the plain step.

3.5.2, 3.5.4 · slides 220, 222–224

Shrinkage versus soft thresholding

\[ w_j^{\text{ridge}} = \frac{z_j}{1 + \lambda}, \qquad w_j^{\text{lasso}} = \operatorname{sign}(z_j) \max\left( \lvert z_j \rvert - \lambda, \ 0 \right) \]

where: orthonormal design \(\frac{1}{n} X^\top X = I\), \(z_j = \frac{1}{n} x_j^\top y\) the OLS coefficient, cost \(J = \frac{1}{2n} \lVert Xw - y \rVert^2\) plus \(\frac{\lambda}{2}\lVert w \rVert^2\) (ridge) or \(\lambda \lVert w \rVert_1\) (lasso).

use: ridge divides every coefficient by the same factor; lasso subtracts \(\lambda\) from every magnitude and zeroes any \(\lvert z_j \rvert \le \lambda\). Example: \(z = 3.0, \lambda = 0.5\): ridge \(2.0\), lasso \(2.5\); \(z = 0.4\): ridge \(0.267\), lasso \(0\).

3.5.1, 3.5.2 · slides 219–222

Elastic Net

\[ J_{\text{EN}}(w) = J(w) + \lambda \left[ r \lVert w \rVert_1 + \frac{1 - r}{2} \lVert w \rVert_2^2 \right], \qquad w_j = \frac{\operatorname{sign}(z_j) \max(\lvert z_j \rvert - \lambda r, 0)}{1 + \lambda(1 - r)} \ \text{(orthonormal)} \]

where: \(r \in [0, 1]\) is the L1 share (sklearn l1_ratio), \(\lambda\) the overall strength (sklearn alpha).

use: \(r = 1\) is Lasso, \(r = 0\) is Ridge (the slide wording swaps these, so always check which penalty \(r\) multiplies). Prefer Elastic Net with groups of highly correlated features: Lasso picks one arbitrarily, the L2 part shares weight across the group. Tune \(\lambda\) (and \(r\)) by cross-validation, never on the test set.

3.5.3 · slides 221–222

Sums of squares and R²

\[ \text{SST} = \sum_i (y_i - \bar{y})^2, \quad \text{SSR} = \sum_i (\hat{y}_i - \bar{y})^2, \quad \text{SSE} = \sum_i (y_i - \hat{y}_i)^2, \qquad R^2 = 1 - \frac{\text{SSE}}{\text{SST}} \]

where: \(\bar{y}\) is the mean of the observed \(y\) (the test-set mean on a test set), \(\hat{y}_i\) the predictions.

use: \(\text{SST} = \text{SSR} + \text{SSE}\) holds only for least squares with an intercept on the training data, giving \(R^2 = \text{SSR}/\text{SST} \in [0, 1]\). On test data or without an intercept the identity fails and \(R^2\) can be negative (worse than predicting \(\bar{y}\)).

3.6.1 · slides 136, 197

Adjusted R²

\[ \bar{R}^2 = 1 - (1 - R^2) \, \frac{n - 1}{n - p - 1} \]

where: \(n\) observations, \(p\) predictors (not counting the intercept).

use: training \(R^2\) never falls when a feature is added, even a random one; \(\bar{R}^2\) penalises extra predictors and can fall. A model is better only if it does better on held-out data.

3.6.1, 3.6.2 · slides 136, 197

Train versus test error

\[ \text{MSE}_{\text{train}} = \frac{1}{n} \sum_{i \in \text{train}} (y_i - \hat{y}_i)^2, \qquad \text{MSE}_{\text{test}} = \frac{1}{m} \sum_{i \in \text{test}} (y_i - \hat{y}_i)^2, \qquad E[\text{MSE}_{\text{test}}] - E[\text{MSE}_{\text{train}}] = \frac{2\sigma^2 p}{n} \]

where: \(n\) training and \(m\) test examples; the last identity is for least squares with \(p\) parameters and noise variance \(\sigma^2\).

use: in-sample MSE is optimistic; generalisation is judged on unseen data. As complexity rises, train MSE falls monotonically while test MSE is U-shaped; pick the complexity (degree, \(\lambda\)) at the validation minimum.

Least squares as a classifier

\[ h(x) = w_0 + w_1 x, \qquad \hat{y} = 1 \iff h(x) \ge 0.5, \qquad x^* = \frac{0.5 - w_0}{w_1} \]

where: \(w_0, w_1\) are fitted by least squares to 0/1 labels; \(x^*\) is the induced decision threshold.

use: shows the two defects: \(h(x)\) is unbounded (values below 0 or above 1 are not probabilities), and one far-away but correctly labelled point drags the least-squares line and moves \(x^*\), misclassifying points that were right before.

4.1.1 · slides 228–235

Sigmoid (logistic) function

\[ \sigma(z) = \frac{1}{1 + e^{-z}}, \qquad \sigma(0) = 0.5, \qquad \sigma(-z) = 1 - \sigma(z), \qquad \sigma'(z) = \sigma(z)\left(1 - \sigma(z)\right) \]

where: \(z = w^\top x = w_0 + w_1 x_1 + \dots + w_d x_d\) is the linear score; \(h_w(x) = \sigma(z) = P(y = 1 \mid x)\).

use: squashes any score into \((0, 1)\). Large positive \(z\) gives \(h \to 1\), large negative \(z\) gives \(h \to 0\). The derivative identity makes the log-loss gradient simple.

4.1.2 · slides 231, 236

Decision boundary

\[ \hat{y} = 1 \iff h_w(x) \ge 0.5 \iff w^\top x \ge 0, \qquad \text{boundary: } w_0 + w_1 x_1 + w_2 x_2 = 0 \]

where: the threshold 0.5 can be changed to \(t\), giving the boundary \(w^\top x = \ln\frac{t}{1 - t}\).

use: the boundary is a hyperplane (a line in 2-D); solve the boundary equation for one feature to get the cut-off, e.g. \(z = -5 + 0.6x_1 + 0.2x_2\) with \(x_2 = 7\) gives \(x_1 \ge 6\).

Cross-entropy (log-loss) cost

\[ \text{Cost}(h, y) = \begin{cases} -\log h & y = 1 \\ -\log(1 - h) & y = 0 \end{cases}, \qquad J(w) = -\frac{1}{m} \sum_{i=1}^{m} \left[ y_i \log h_i + (1 - y_i) \log(1 - h_i) \right] \]

where: \(h_i = \sigma(w^\top x_i)\), \(m\) training examples, \(\log\) is natural.

use: a confident wrong prediction is punished heavily (\(-\ln 0.01 \approx 4.61\)) and a confident right one costs almost nothing. \(J\) is convex in \(w\); squared error with a sigmoid is not convex (flat regions and local minima), which is why it is not used.

Logistic-regression gradient-descent update

\[ \frac{\partial J}{\partial w_j} = \frac{1}{m} \sum_{i=1}^{m} \left( h_w(x_i) - y_i \right) x_{ij}, \qquad w_j \leftarrow w_j - \eta \, \frac{1}{m} \sum_{i=1}^{m} \left( h_w(x_i) - y_i \right) x_{ij} \]

where: \(x_{i0} = 1\); \(h_w(x_i) = \sigma(w^\top x_i)\); updates are simultaneous.

use: the same form as linear regression, only \(h\) changes. Per example \(\frac{\partial \ell}{\partial w_j} = (h - y)x_j\) and \(\frac{\partial^2 \ell}{\partial w_j^2} = \sigma(1 - \sigma)x_j^2 \ge 0\) (convex). There is no closed form, so iterate; on perfectly separable data the weights grow without bound unless regularised.

Odds, log-odds and the odds ratio

\[ \text{odds} = \frac{p}{1 - p}, \qquad \ln\frac{p}{1 - p} = w^\top x, \qquad \frac{\text{odds}(x_j + 1)}{\text{odds}(x_j)} = e^{w_j}, \qquad \frac{\partial p}{\partial x_j} = w_j \, p(1 - p) \]

where: \(p = P(y = 1 \mid x)\); \(w_j\) is the coefficient of feature \(j\), others held fixed.

use: each one-unit increase in \(x_j\) multiplies the odds by \(e^{w_j}\) (slide: odds of a job offer rise by a factor 1.35 per CGPA point); a \(\Delta\)-unit change multiplies them by \(e^{w_j \Delta}\). \(e^{w_j} > 1\) raises the odds, \(< 1\) lowers them. Regularised logistic regression

\[ J(w) = -\frac{1}{m} \sum_i \left[ y_i \log h_i + (1 - y_i)\log(1 - h_i) \right] + \frac{\lambda}{2m} \sum_{j=1}^{d} w_j^2, \qquad w_j \leftarrow w_j \left( 1 - \frac{\eta\lambda}{m} \right) - \eta \frac{1}{m} \sum_i (h_i - y_i) x_{ij} \]

where: \(\lambda\) is the regularisation strength, \(w_0\) is not penalised; sklearn uses \(C = 1/\lambda\) (\(1/\alpha\)).

Confusion-matrix metrics

\[ \text{Acc} = \frac{TP + TN}{TP + TN + FP + FN}, \quad P = \frac{TP}{TP + FP}, \quad R = TPR = \frac{TP}{TP + FN}, \quad F_1 = \frac{2PR}{P + R} \]

where: TP, FP, FN, TN count true/false positives/negatives for the positive class (the class of interest); specificity \(= TNR = \frac{TN}{TN + FP}\), \(FPR = \frac{FP}{FP + TN} = 1 - TNR\).

use: precision answers "of the flagged, how many are real?", recall "of the real, how many were caught?". \(F_1\) is the harmonic mean, so it is dragged towards the smaller of \(P\) and \(R\) (\(P = 1, R = 0.1\) gives \(F_1 \approx 0.18\)). \(F_\beta = \frac{(1 + \beta^2)PR}{\beta^2 P + R}\) weights recall \(\beta\) times as much.

Accuracy paradox baseline

\[ \text{Acc}_{\text{baseline}} = \frac{N_{\text{maj}}}{N}, \qquad \text{balanced accuracy} = \frac{TPR + TNR}{2} \]

where: \(N_{\text{maj}}\) is the majority-class count among \(N\) cases.

use: a model that always predicts the majority class gets high accuracy (e.g. 98%) with recall 0 on the rare class. Compare any model with this baseline and report recall, precision, \(F_1\), balanced accuracy or ROC-AUC under imbalance.

4.4.2, 4.4.4 · slides 274–275

ROC curve and AUC

\[ \text{ROC point at threshold } t: \ \left( FPR(t), \ TPR(t) \right), \qquad \text{AUC} = \frac{\#\{(i, j): s_i > s_j\} + \tfrac{1}{2}\#\{(i, j): s_i = s_j\}}{n_+ \, n_-} \]

where: \(i\) ranges over the \(n_+\) positives, \(j\) over the \(n_-\) negatives, \(s\) is the classifier score.

use: sort by score descending and lower the threshold one case at a time: each positive steps up by \(1/n_+\), each negative steps right by \(1/n_-\), and a tie of mixed labels is one diagonal step. AUC is the area under this staircase (trapezoid rule), equal to the probability that a random positive outscores a random negative. 0.5 = random, 1 = perfect; \((0, 0)\) predicts all negative, \((1, 1)\) all positive, \((0, 1)\) is perfect.

4.4.3 · slides 265–272

Choosing a threshold by expected cost

\[ \text{Cost}(t) = c_{FN} \cdot FN(t) + c_{FP} \cdot FP(t), \qquad t^* = \arg\min_t \text{Cost}(t) \]

where: \(c_{FN}, c_{FP}\) are the costs of a missed positive and a false alarm; \(FN(t), FP(t)\) are the counts at threshold \(t\).

use: when misses are expensive (disease, fraud) lower the threshold to raise recall. With probabilities that are calibrated, predict positive when \(p \ge \frac{c_{FP}}{c_{FP} + c_{FN}}\).

One-vs-All and One-vs-One

\[ \text{OvA: } K \text{ classifiers}, \ \hat{y} = \arg\max_k f_k(x); \qquad \text{OvO: } \frac{K(K - 1)}{2} \text{ classifiers}, \ \hat{y} = \text{majority vote} \]

where: \(K\) classes; \(f_k\) is the score of "class \(k\) vs the rest"; each OvO model is trained only on the two classes it separates (about \(2n\) examples when each class has \(n\)).

use: OvA trains few models on all \(Kn\) examples (imbalanced, rest-heavy); OvO trains many small models, total training examples \((K - 1)n\). For a learner with cost \(\propto N^2\) (e.g. kernel SVM), OvO is cheaper: OvA \(K^3 n^2\) vs OvO \(2K(K - 1)n^2\). Break OvO vote ties by summed scores.

Entropy

\[ \text{Entropy}(S) = -\sum_{i=1}^{k} p_i \log_2 p_i, \qquad 0 \le \text{Entropy}(S) \le \log_2 k \]

where: \(p_i\) is the fraction of records in node \(S\) belonging to class \(i\), \(k\) classes, \(0 \log_2 0 = 0\); units are bits.

use: 0 for a pure node, maximum \(\log_2 k\) for a uniform one (1 bit for two classes). For two classes with fraction \(p\): \(H(p) = -p\log_2 p - (1 - p)\log_2(1 - p)\), concave with maximum at \(p = 0.5\). Use \(\log_2 x = \ln x / \ln 2\).

Information gain

\[ \text{Gain}(S, A) = \text{Entropy}(S) - \sum_{v \in \text{Values}(A)} \frac{\lvert S_v \rvert}{\lvert S \rvert} \, \text{Entropy}(S_v) \]

where: \(S_v\) is the subset of \(S\) with \(A = v\); the sum is the weighted average child entropy.

use: ID3 splits on the attribute with the largest gain and recurses on each child with the remaining attributes. Gain is never negative. It is biased towards many-valued attributes: an ID attribute makes every child pure, so its gain equals \(\text{Entropy}(S)\).

5.2.1, 5.1.2 · slides 317–321

Gini index and Gini gain

\[ \text{Gini}(S) = 1 - \sum_{i=1}^{k} p_i^2, \qquad \text{Gini}_{\text{split}} = \sum_{v} \frac{\lvert S_v \rvert}{\lvert S \rvert} \text{Gini}(S_v), \qquad \Delta\text{Gini} = \text{Gini}(S) - \text{Gini}_{\text{split}} \]

where: \(p_i\) class fractions in the node; \(0 \le \text{Gini} \le 1 - \frac{1}{k}\) (at most 0.5 for two classes).

use: CART chooses the split with the smallest weighted Gini (largest \(\Delta\)Gini). Cheaper than entropy (no logs) and usually picks the same split, though they can disagree.

Binary splits of a nominal attribute

\[ \text{number of binary partitions of } k \text{ values} = 2^{k - 1} - 1 \]

where: \(k\) distinct values of the attribute; each partition sends a subset of values left and the rest right.

use: CART considers only binary splits: a 3-valued attribute has 3 candidate groupings ({A} vs {B, C}, {B} vs {A, C}, {C} vs {A, B}). Evaluate the weighted Gini of each and keep the best.

5.2.2, 5.4 · slides 327–328

Classification error as impurity

\[ \text{Error}(S) = 1 - \max_i p_i, \qquad 0 \le \text{Error}(S) \le 1 - \frac{1}{k} \]

where: \(p_i\) class fractions; \(\max_i p_i\) is the majority-class share.

use: the least sensitive impurity: if the majority class is the same in every child, the weighted child error equals the parent error and the error gain is exactly 0, even when entropy and Gini show a real improvement. Fine for pruning, poor for growing.

Pre-pruning (stopping) rules

\[ \text{stop splitting node } S \text{ if } \ \text{Gain}(S, A^*) \le \tau \ \text{ or } \ \lvert S \rvert < n_{\min} \ \text{ or } \ \text{depth}(S) \ge D_{\max} \]

5.3.2, 5.3.1 · slides 353–356

Reduced-error post-pruning

\[ \text{prune subtree } T_v \text{ into a leaf if } \ \text{Err}_{\text{val}}(\text{leaf}) \le \text{Err}_{\text{val}}(T_v), \qquad \text{Err} = \frac{\#\text{misclassified}}{\#\text{records}} \]

where: \(\text{Err}_{\text{val}}\) is measured on a separate prune (validation) set; the new leaf predicts the training-majority class of the records reaching \(v\).

use: grow the tree fully, then scan bottom-up and prune any node whose removal does not increase validation error. Training error rises a little; test error usually falls. Overfitting shows as training error falling while validation error rises with tree size.

Minimum description length

\[ h_{\text{MDL}} = \arg\min_h \left[ L_{C_1}(h) + L_{C_2}(D \mid h) \right], \qquad L(\text{event}) = -\log_2 p \ \text{bits}, \qquad h_{\text{MAP}} = \arg\min_h \left[ -\log_2 P(h) - \log_2 P(D \mid h) \right] \]

6.3.1 · slides 392–398

Choosing k

\[ k \approx \sqrt{N}, \qquad k^* = \arg\min_k \ \text{CV error}(k) \]

where: \(N\) training examples; CV error is the validation or cross-validated error for each candidate \(k\).

Distance-weighted k-NN

\[ w_i = \frac{1}{d(x_q, x_i)^2}, \qquad \hat{f}(x_q) = \arg\max_c \sum_{i=1}^{k} w_i \mathbf{1}[f(x_i) = c], \qquad \hat{f}(x_q) = \frac{\sum_{i=1}^{k} w_i f(x_i)}{\sum_{i=1}^{k} w_i} \]

Locally weighted regression: error criterion

\[ E(x_q) = \frac{1}{2} \sum_{x \in k\text{NN}(x_q)} K\left( d(x_q, x) \right) \left( f(x) - \hat{f}(x) \right)^2, \qquad \hat{f}(x) = w_0 + w_1 a_1(x) + \dots + w_n a_n(x) \]

where: \(K\) is a kernel that decreases with distance from the query \(x_q\); \(a_j(x)\) is feature \(j\) of \(x\), \(a_0(x) = 1\).

use: a fresh local linear model is fitted for each query and discarded after predicting \(\hat{f}(x_q)\). Mitchell also lists weighting all training points, or using the \(k\) nearest without a kernel.

Locally weighted regression: gradient update

\[ w_j \leftarrow w_j + \eta \sum_{x \in k\text{NN}(x_q)} K\left( d(x_q, x) \right) \left( f(x) - \hat{f}(x) \right) a_j(x) \]

where: \(\eta\) is the learning rate; note the sign: \(f(x) - \hat{f}(x)\) (target minus prediction) with a plus.

use: the same as the linear-regression delta rule with every residual multiplied by its kernel weight. With a constant model \(\hat{f} = w_0\) the minimiser is the kernel-weighted mean \(w_0 = \frac{\sum K_x f(x)}{\sum K_x}\); with \(K \equiv 1\) it is ordinary least squares on the neighbours.

k-fold and leave-one-out cross-validation

\[ \text{CV}_{(k)} = \frac{1}{k} \sum_{i=1}^{k} \text{Err}_i, \qquad \text{fold size} = \frac{n}{k}, \qquad \text{training size per fold} = \frac{(k - 1)n}{k}, \qquad \text{LOOCV: } k = n \]

where: \(\text{Err}_i\) is the error (MSE or misclassification rate) on fold \(i\) when the model is trained on the other \(k - 1\) folds; stratified k-fold keeps class proportions in every fold.

use: estimates generalisation error for tuning hyper-parameters (\(k\), \(\lambda\), \(C\), depth). It costs \(k\) fits per candidate; for a lazy learner LOOCV is cheap (just drop each point from its own neighbour list). The test set is held out of all of this and used once.

Linear classifier

\[ f(x) = \operatorname{sign}\left( w^\top x + b \right), \qquad g(x) = w^\top x + b \]

where: \(w\) is the normal vector of the hyperplane \(g(x) = 0\), \(b\) the offset, labels \(y_i \in \{-1, +1\}\); \(g(x)\) is the raw score.

use: many hyperplanes separate separable data; the SVM picks the one with the largest margin. A point is correctly classified iff \(y_i\, g(x_i) > 0\).

7.1.1 · slides 431–438

Distance from a point to the hyperplane

\[ \text{dist}(x_0) = \frac{\lvert w^\top x_0 + b \rvert}{\lVert w \rVert}, \qquad \text{functional margin} = y_i\, g(x_i), \qquad \text{geometric margin} = \frac{y_i\, g(x_i)}{\lVert w \rVert} \]

where: \(\lVert w \rVert = \sqrt{w^\top w}\).

use: the geometric margin is the signed distance (positive on the correct side) and does not change if \(w, b\) are rescaled; the functional margin does. Canonical form rescales so the closest points have \(y_i\, g(x_i) = 1\).

7.1.2, 7.2.1 · slides 436–438

Margin width

\[ \text{width} = \frac{2}{\lVert w \rVert}, \qquad \text{margin hyperplanes: } w^\top x + b = \pm 1 \]

where: \(w, b\) in canonical form.

use: maximising the width is the same as minimising \(\lVert w \rVert\). Support vectors lie exactly on \(w^\top x + b = \pm 1\). Example: \(w = (1, 1)\) gives width \(2/\sqrt{2} = \sqrt{2}\).

7.1.2 · slides 436–438

Hard-margin primal problem

\[ \min_{w, b} \ \frac{1}{2} \lVert w \rVert^2 \quad \text{subject to} \quad y_i (w^\top x_i + b) \ge 1, \quad i = 1, \dots, N \]

where: \(N\) training points \((x_i, y_i)\).

use: a convex quadratic program with a unique solution when the data are linearly separable; it has no solution otherwise (use the soft margin). To check a proposed \((w, b)\): every constraint must hold, and no feasible hyperplane may have smaller \(\lVert w \rVert\).

7.2.1 · slides 438–443

Lagrangian and stationarity conditions

\[ L(w, b, \alpha) = \frac{1}{2} \lVert w \rVert^2 - \sum_i \alpha_i \left[ y_i (w^\top x_i + b) - 1 \right], \qquad \frac{\partial L}{\partial w} = 0 \Rightarrow w = \sum_i \alpha_i y_i x_i, \qquad \frac{\partial L}{\partial b} = 0 \Rightarrow \sum_i \alpha_i y_i = 0 \]

where: \(\alpha_i \ge 0\) is the Lagrange multiplier of constraint \(i\).

use: \(w\) is a weighted sum of training points, and only points with \(\alpha_i > 0\) (the support vectors) contribute. Any valid solution must satisfy \(\alpha_i \ge 0\) and \(\sum_i \alpha_i y_i = 0\).

7.2.2 · slides 443–444

Dual problem

\[ \max_{\alpha} \ W(\alpha) = \sum_i \alpha_i - \frac{1}{2} \sum_i \sum_j \alpha_i \alpha_j y_i y_j \, x_i^\top x_j \quad \text{subject to} \quad \alpha_i \ge 0, \ \ \sum_i \alpha_i y_i = 0 \]

where: obtained by substituting the stationarity conditions back into \(L\); the data enter only through inner products \(x_i^\top x_j\).

use: solve for \(\alpha\), then recover \(w\) and \(b\). Because only inner products appear, any kernel \(K(x_i, x_j)\) can replace \(x_i^\top x_j\).

7.2.2 · slides 443–451

KKT conditions and recovering b

\[ \alpha_i \left[ y_i (w^\top x_i + b) - 1 \right] = 0, \qquad b = y_s - w^\top x_s \ \text{ for any support vector } x_s \ (\alpha_s > 0) \]

where: complementary slackness: either \(\alpha_i = 0\) (point beyond the margin) or the point lies exactly on its margin hyperplane.

use: average \(b\) over all support vectors for numerical stability. Erratum (slides 447–452): solving "\(w \cdot x_i + b = y_i\)" through guessed support vectors as a plain linear system can give a negative \(\alpha_i\) (the slide's \(\alpha_1 = -3.5\), with \(\sum \alpha_i y_i = 5 \ne 0\)); that is not a valid dual solution. Check \(\alpha_i \ge 0\), \(\sum \alpha_i y_i = 0\) and all margin constraints before accepting an answer.

Two-point SVM in closed form

\[ \alpha = \frac{2}{\lVert x_+ - x_- \rVert^2}, \qquad w = \alpha (x_+ - x_-) = \frac{2(x_+ - x_-)}{\lVert x_+ - x_- \rVert^2}, \qquad b = 1 - w^\top x_+ \]

where: one positive point \(x_+\) and one negative point \(x_-\), both support vectors with equal \(\alpha\).

use: the boundary is the perpendicular bisector of the segment, with width \(\lVert x_+ - x_- \rVert\). A quick check for small hand problems (e.g. \(x_+ = (3, 3)\), \(x_- = (1, 1)\) gives \(\alpha = 0.25\), \(w = (0.5, 0.5)\), \(b = -2\)).

7.2.2, 7.1.2 · slides 443–451

SVM decision function in dual form

\[ f(x) = \operatorname{sign}\left( \sum_{i \in SV} \alpha_i y_i \, K(x_i, x) + b \right) \]

where: the sum runs over support vectors only; \(K(x_i, x) = x_i^\top x\) for a linear SVM.

use: prediction costs one kernel evaluation per support vector, so a sparse solution (few support vectors) is fast. Removing a non-support vector from the training set leaves the solution unchanged.

7.2.2, 7.4.1 · slides 464–475

Soft-margin primal with slack variables

\[ \min_{w, b, \xi} \ \frac{1}{2} \lVert w \rVert^2 + C \sum_i \xi_i \quad \text{subject to} \quad y_i (w^\top x_i + b) \ge 1 - \xi_i, \quad \xi_i \ge 0 \]

where: \(\xi_i\) is the slack of point \(i\); \(C > 0\) the penalty on margin violations.

use: large \(C\): violations are expensive, narrow margin, fits training data hard (low bias, high variance, approaches the hard margin); small \(C\): wide, tolerant margin (more bias, less variance). Compare candidate hyperplanes by evaluating this objective for the given \(C\). Tune \(C\) by cross-validation.

7.3.1, 7.3.2 · slides 456–459, 466

Slack values and hinge loss

\[ \xi_i = \max\left( 0, \ 1 - y_i (w^\top x_i + b) \right), \qquad \min_{w, b} \ \frac{1}{2} \lVert w \rVert^2 + C \sum_i \max\left( 0, 1 - y_i f(x_i) \right) \]

where: \(f(x_i) = w^\top x_i + b\); \(\max(0, 1 - yf)\) is the hinge loss.

use: \(\xi_i = 0\): on or outside the correct margin; \(0 < \xi_i \le 1\): inside the margin but correctly classified; \(\xi_i > 1\): misclassified. \(\sum_i \xi_i\) bounds the number of training errors. Dividing by \(C\) gives hinge loss plus \(\lambda \lVert w \rVert^2\) with \(\lambda = \frac{1}{2C}\), a regularised loss like ridge.

7.3.1 · slides 456–459

Soft-margin dual and the multiplier cases

\[ \max_\alpha \ \sum_i \alpha_i - \frac{1}{2} \sum_{i, j} \alpha_i \alpha_j y_i y_j K(x_i, x_j) \quad \text{s.t.} \quad 0 \le \alpha_i \le C, \ \ \sum_i \alpha_i y_i = 0 \]

where: the only change from the hard-margin dual is the upper bound \(C\) (box constraint).

use: read a solution through its multipliers: \(\alpha_i = 0 \Rightarrow y_i g(x_i) \ge 1\) (not a support vector); \(0 < \alpha_i < C \Rightarrow y_i g(x_i) = 1\) (on the margin, use these to compute \(b\)); \(\alpha_i = C \Rightarrow y_i g(x_i) \le 1\) (inside the margin or misclassified).

The kernel trick

\[ K(x, z) = \phi(x)^\top \phi(z), \qquad \text{degree 2: } (1 + x^\top z)^2 = \phi(x)^\top \phi(z), \ \ \phi(x) = \left( 1, \sqrt{2}x_1, \sqrt{2}x_2, x_1^2, x_2^2, \sqrt{2}x_1 x_2 \right) \]

where: \(\phi\) maps the input to a higher-dimensional feature space; \(x, z \in \mathbb{R}^2\) in the example.

use: compute inner products in feature space without building \(\phi(x)\): data that are not linearly separable in input space (e.g. 1-D classes inside/outside an interval, separable after \(\phi(x) = (x, x^2)\)) become separable. A valid kernel must give a symmetric positive semi-definite Gram matrix (Mercer).

7.4.1 · slides 465–475

Common kernels

\[ K_{\text{lin}} = x^\top z, \qquad K_{\text{poly}} = (1 + x^\top z)^{p}, \qquad K_{\text{RBF}} = \exp\left( -\gamma \lVert x - z \rVert^2 \right) = \exp\left( -\frac{\lVert x - z \rVert^2}{2\sigma^2} \right), \qquad K_{\text{sig}} = \tanh\left( \beta_0 x^\top z + \beta_1 \right) \]

where: \(p\) the degree, \(\gamma = \frac{1}{2\sigma^2} > 0\) the RBF width parameter, \(\beta_0, \beta_1\) sigmoid parameters.

use: RBF values lie in \((0, 1]\) and equal 1 only at \(x = z\); large \(\gamma\) (small \(\sigma\)) makes very local, wiggly boundaries (overfitting risk), small \(\gamma\) smooth ones. RBF corresponds to an infinite-dimensional \(\phi\). The sigmoid kernel is not PSD for all parameters.

7.4.2 · slides 476–480

Size of the polynomial feature space

\[ \dim \phi = \binom{d + p}{p} \quad \text{for } K(x, z) = (1 + x^\top z)^p \]

where: \(d\) input features, \(p\) the polynomial degree (counts all monomials of degree \(\le p\)).

use: \(d = 100\): \(\binom{102}{2} = 5{,}151\), \(\binom{105}{5} \approx 9.7 \times 10^7\), yet the kernel costs only \(O(d)\) per evaluation. The trick saves feature-space cost, not the \(O(N^2)\) Gram-matrix cost in the number of training points.

Likelihood and the MLE recipe

\[ L(\theta) = \prod_{i=1}^{n} f(x_i \mid \theta), \qquad LL(\theta) = \sum_{i=1}^{n} \log f(x_i \mid \theta), \qquad \hat{\theta}_{\text{MLE}} = \arg\max_\theta LL(\theta) \]

where: \(f(x \mid \theta)\) is the PMF or PDF, data i.i.d., \(\log\) natural.

use: write \(L\), take logs (products become sums), differentiate with respect to each parameter, set to 0, solve, and check it is a maximum. Constants not involving \(\theta\) can be dropped. A likelihood ratio \(L(\theta_1)/L(\theta_2) = e^{LL_1 - LL_2}\).

8.1.1 · slides 487–497

Bernoulli and binomial MLE

\[ L(p) = p^{k} (1 - p)^{n - k}, \qquad \frac{dLL}{dp} = \frac{k}{p} - \frac{n - k}{1 - p} = 0 \ \Rightarrow \ \hat{p} = \frac{k}{n} \]

where: \(k\) successes in \(n\) independent trials.

use: the MLE is the observed proportion (3 heads in 10 tosses gives 0.3). With \(k = 0\) it gives \(\hat{p} = 0\), the zero-frequency problem that smoothing fixes.

Poisson and exponential MLE

\[ P(X = x) = \frac{e^{-\lambda} \lambda^{x}}{x!} \Rightarrow \hat{\lambda} = \bar{x}, \qquad f(t) = \lambda e^{-\lambda t} \Rightarrow \hat{\lambda} = \frac{n}{\sum t_i} = \frac{1}{\bar{t}} \]

where: \(x_i\) counts per interval (Poisson), \(t_i \ge 0\) lifetimes (exponential); \(LL_{\text{Pois}} = (\sum x_i)\log\lambda - n\lambda - \sum \log x_i!\).

use: the same recipe for any distribution, including a home-made PMF such as \(P(0) = \theta/2, P(1) = 1/2, P(2) = (1 - \theta)/2\) (count each outcome, then maximise). Plug \(\hat{\lambda}\) back in for probabilities, e.g. \(P(X \le 1) = e^{-\lambda}(1 + \lambda)\).

Gaussian density and its MLE

\[ \mathcal{N}(x; \mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(x - \mu)^2}{2\sigma^2} \right), \qquad \hat{\mu} = \bar{x}, \qquad \hat{\sigma}^2_{\text{MLE}} = \frac{1}{n} \sum_{i=1}^{n} (x_i - \bar{x})^2 \]

where: \(LL(\mu, \sigma^2) = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum (x_i - \mu)^2\).

use: the MLE variance divides by \(n\) and is biased low; the unbiased sample variance divides by \(n - 1\). A density value can exceed 1 when \(\sigma\) is small; only areas are probabilities.

Least squares is the Gaussian-noise MLE

\[ y^{(i)} = \theta^\top x^{(i)} + \varepsilon_i, \ \varepsilon_i \sim N(0, \sigma^2) \ \Rightarrow \ LL(\theta) = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2} \sum_i \left( y^{(i)} - \theta^\top x^{(i)} \right)^2 \]

where: noise i.i.d. Gaussian with constant variance.

use: maximising \(LL\) over \(\theta\) is exactly minimising the sum of squared errors, so \(\hat{\theta}_{\text{MLE}}\) solves the normal equations, and \(\hat{\sigma}^2 = \frac{1}{n}\sum (y^{(i)} - \hat{\theta}^\top x^{(i)})^2\). Logistic-regression log-likelihood

\[ LL(\theta) = \sum_{i} \left[ y_i \log \sigma_i + (1 - y_i) \log(1 - \sigma_i) \right], \qquad \frac{\partial LL}{\partial \theta_j} = \sum_i (y_i - \sigma_i)\, x_{ij}, \qquad \theta_j \leftarrow \theta_j + \eta \sum_i (y_i - \sigma_i)\, x_{ij} \]

MAP estimation

\[ \hat{\theta}_{\text{MAP}} = \arg\max_\theta P(D \mid \theta)\, P(\theta), \qquad \text{Beta}(a, b) \text{ prior on a coin: } \hat{p}_{\text{MAP}} = \frac{k + a - 1}{n + a + b - 2} \]

where: \(P(\theta)\) is the prior; Beta prior \(f(p) \propto p^{a - 1}(1 - p)^{b - 1}\); \(k\) heads in \(n\) tosses.

use: the prior acts like \(a - 1\) extra heads and \(b - 1\) extra tails. With a uniform prior (\(a = b = 1\)) MAP equals MLE exactly; as \(n\) grows the data dominate and MAP tends to the MLE.

8.1.4 · slides 502–504

Bayes' theorem

\[ P(h \mid D) = \frac{P(D \mid h)\, P(h)}{P(D)}, \qquad P(D) = \sum_{h'} P(D \mid h')\, P(h') \]

where: \(P(h)\) prior, \(P(D \mid h)\) likelihood, \(P(h \mid D)\) posterior, \(P(D)\) evidence (law of total probability).

use: \(P(\text{class} \mid \text{evidence}) \ne P(\text{evidence} \mid \text{class})\); with a rare class the posterior stays small even for a sensitive test (prior 0.002, detection 0.95, false alarm 0.03 gives \(P(\text{fraud} \mid A) \approx 0.06\)). For a second independent alarm, reuse the posterior as the new prior.

8.2.1 · slides 490–492, 502

Bayes optimal classifier

\[ v^* = \arg\max_{v \in V} \sum_{h \in H} P(v \mid h)\, P(h \mid D), \qquad h_{\text{MAP}} = \arg\max_h P(h \mid D) \]

where: \(V\) is the set of class labels, \(P(v \mid h)\) the probability hypothesis \(h\) assigns to label \(v\).

use: votes over all hypotheses weighted by their posterior; no other classifier using the same \(H\) and prior does better on average. It can disagree with \(h_{\text{MAP}}\) when several less probable hypotheses together outweigh the MAP one.

8.2.2 · slides 505–507

Gibbs classifier

\[ h \sim P(h \mid D), \quad \hat{v} = h(x); \qquad E[\text{error}_{\text{Gibbs}}] \le 2 \, E[\text{error}_{\text{Bayes optimal}}] \]

where: one hypothesis is drawn at random from the posterior and used alone.

use: much cheaper than the Bayes optimal vote. For two classes with posterior \(q\) for the true class, Gibbs errs with probability \(2q(1 - q) \le 2\min(q, 1 - q)\), which is at most twice the Bayes-optimal error.

Naïve Bayes classifier

\[ P(X_1, \dots, X_n \mid Y) = \prod_{i=1}^{n} P(X_i \mid Y), \qquad \hat{y} = \arg\max_{y} \ P(Y = y) \prod_{i=1}^{n} P(X_i = x_i \mid Y = y) \]

where: \(X_i\) are features assumed conditionally independent given the class \(Y\); priors and likelihoods are relative frequencies from the training table.

use: compute a score per class, pick the largest; the posterior is a score divided by the sum of scores. The independence assumption is often violated, yet the \(\arg\max\) is often still right. Correlated (duplicated) features count the same evidence twice and push probabilities to extremes.

\[ P(\text{ensemble correct}) = A_n = \sum_{k = (n+1)/2}^{n} \binom{n}{k} p^{k} (1 - p)^{n - k} \]

Bagging aggregation

\[ \hat{y}_{\text{reg}} = \frac{1}{B} \sum_{b=1}^{B} \hat{f}_b(x), \qquad \hat{y}_{\text{hard}} = \text{mode}\{\hat{f}_b(x)\}, \qquad \hat{y}_{\text{soft}} = \arg\max_c \frac{1}{B} \sum_{b=1}^{B} \hat{p}_b(c \mid x) \]

where: \(B\) base models trained in parallel on \(B\) bootstrap samples; \(\hat{p}_b(c \mid x)\) the class probability from model \(b\).

use: averaging reduces variance, so bagging suits high-variance, low-bias learners (deep trees); it cannot fix a high-bias learner. Hard and soft votes can disagree: soft voting uses how confident each model is (three weak "yes" at 0.55 can lose to two strong "no").

Out-of-bag error

\[ \text{OOB error} = \frac{1}{n} \sum_{i=1}^{n} \mathbf{1}\left[ \hat{y}_{\text{OOB}}(x_i) \ne y_i \right], \qquad \hat{y}_{\text{OOB}}(x_i) = \text{vote of the models whose bootstrap sample excludes } i \]

where: each record is predicted only by the trees that did not see it in training.

use: a free validation estimate of generalisation error, with no separate hold-out set. Records that appear in every bag have no OOB prediction and are skipped.

9.2.1, 9.2.2 · slides 603, 613

Variance of an average of correlated learners

\[ \operatorname{Var}(\bar{f}) = \rho\sigma^2 + \frac{1 - \rho}{B}\sigma^2 \]

where: \(B\) learners each with variance \(\sigma^2\) and pairwise correlation \(\rho\).

use: as \(B \to \infty\) the variance falls only to \(\rho\sigma^2\), so correlation sets the floor. Random Forest's random feature subsets lower \(\rho\) between trees, which is why it beats plain bagging (\(\rho = 0.2\), \(\sigma^2 = 4.5\), \(B = 100\): \(0.936\)).

Random-forest feature subsampling

\[ m = \lfloor \sqrt{p} \rfloor \ \text{(classification)}, \quad m = \lfloor p/3 \rfloor \ \text{(regression)}, \qquad P(\text{given feature is a candidate}) = \frac{m}{p}, \qquad P(\text{none of } s \text{ chosen}) = \frac{\binom{p - s}{m}}{\binom{p}{m}} \]

where: \(p\) features in total, \(m\) drawn without replacement at every split, \(s\) particular (e.g. strong) features.

use: a dominant feature is unavailable at a split with probability \(1 - m/p\), so other features get used and the trees decorrelate. \(m = p\) is plain bagging of trees.

AdaBoost weighted error

\[ w_i^{(1)} = \frac{1}{n}, \qquad \varepsilon_t = \sum_{i:\ h_t(x_i) \ne y_i} w_i^{(t)} \]

where: \(n\) training records, labels \(y_i \in \{-1, +1\}\), weights summing to 1, \(h_t\) the weak learner (usually a stump) of round \(t\).

use: the total error is the sum of the weights of the misclassified records (not the count). Each round picks the stump with the lowest weighted error.

9.3.1, 9.3.2 · slides 618–622

AdaBoost stump performance

\[ \alpha_t = \frac{1}{2} \ln\frac{1 - \varepsilon_t}{\varepsilon_t} \]

where: \(\varepsilon_t\) is the weighted error of \(h_t\); \(\ln\) natural.

use: \(\alpha = 0\) at \(\varepsilon = 0.5\) (a coin flip gets no say), large for small \(\varepsilon\), negative for \(\varepsilon > 0.5\) (the vote is flipped, \(\alpha' h' = \alpha h\)). Keep \(\varepsilon\) exact: \(\varepsilon = 2/7\) gives \(\alpha = \frac{1}{2}\ln 2.5 = 0.458\); rounding \(\varepsilon\) to 0.28 first gives 0.472.

9.3.2 · slides 622–626

AdaBoost weight update

\[ w_i \leftarrow \frac{w_i \, e^{-\alpha_t y_i h_t(x_i)}}{Z_t}, \qquad Z_t = \sum_i w_i \, e^{-\alpha_t y_i h_t(x_i)} = 2\sqrt{\varepsilon_t (1 - \varepsilon_t)} \]

where: \(y_i h_t(x_i) = +1\) if correct (weight multiplied by \(e^{-\alpha_t}\)), \(-1\) if wrong (multiplied by \(e^{\alpha_t}\)); \(Z_t\) renormalises the weights to sum to 1.

use: after renormalising, the misclassified records always hold exactly half the total weight, so the next stump must focus on them. A record misclassified by every stump has its weight grow geometrically, which is why boosting overfits noisy labels.

9.3.2 · slides 626–629

AdaBoost final classifier

\[ H(x) = \operatorname{sign}\left( \sum_{t=1}^{T} \alpha_t h_t(x) \right) \]

where: \(T\) rounds, \(\alpha_t\) the performance of stump \(t\).

use: a weighted vote: one confident stump can outvote two weak ones. Boosting trains sequentially and reduces bias, so it suits high-bias, low-variance base learners (stumps); the training error is bounded by \(\prod_t Z_t\), which shrinks every round with \(\varepsilon_t < 0.5\).

9.3.2 · slides 626–629

Gradient boosting for regression

\[ F_0(x) = \bar{y}, \qquad r_i^{(m)} = y_i - F_{m-1}(x_i), \qquad F_m(x) = F_{m-1}(x) + \eta \, h_m(x) \]

where: \(h_m\) is a small regression tree fitted to the residuals \(r_i^{(m)}\) (each leaf predicts the mean residual of its records), \(\eta \in (0, 1]\) the learning rate (shrinkage).

use: the residual is the negative gradient of the squared loss, \(-\frac{\partial}{\partial F}\frac{1}{2}(y - F)^2 = y - F\), so each tree is a step of functional gradient descent. A small \(\eta\) needs more trees but generalises better; MSE on the training set falls every round.

XGBoost regularised objective

\[ \text{Obj} = \sum_{i} \ell\left( y_i, \hat{y}_i \right) + \sum_{k} \Omega(f_k), \qquad \Omega(f) = \gamma T + \frac{1}{2} \lambda \sum_{j=1}^{T} w_j^2 \]

where: \(f_k\) the \(k\)-th tree, \(T\) its number of leaves, \(w_j\) its leaf values, \(\gamma\) the cost per leaf, \(\lambda\) the L2 penalty on leaf values.

use: regularisation is part of the tree-growing objective itself. Other XGBoost features: shrinkage \(\eta\), column subsampling, level-wise growth then pruning of negative-gain splits, sparsity-aware handling of missing values, cache-aware parallel computation.

XGBoost leaf value and split gain

\[ w^* = -\frac{G}{H + \lambda}, \qquad \text{Gain} = \frac{1}{2} \left[ \frac{G_L^2}{H_L + \lambda} + \frac{G_R^2}{H_R + \lambda} - \frac{(G_L + G_R)^2}{H_L + H_R + \lambda} \right] - \gamma \]

where: \(g_i = \frac{\partial \ell}{\partial F}\), \(h_i = \frac{\partial^2 \ell}{\partial F^2}\) at the current prediction; \(G = \sum g_i\), \(H = \sum h_i\) over a leaf. For squared loss \(\ell = \frac{1}{2}(y - F)^2\): \(g_i = F - y_i\) (minus the residual), \(h_i = 1\).

Stacking

Cohesion and separation

\[ \text{SSE} = \text{WSS} = \sum_{i=1}^{K} \sum_{x \in C_i} \lVert x - m_i \rVert^2, \qquad \text{BSS} = \sum_{i=1}^{K} \lvert C_i \rvert \, \lVert m_i - m \rVert^2, \qquad \text{TSS} = \text{WSS} + \text{BSS} \]

where: \(C_i\) cluster \(i\) with centroid \(m_i\), \(m\) the overall mean, \(\lvert C_i \rvert\) the cluster size.

use: a good clustering has small WSS (cohesion, intra-cluster) and large BSS (separation, inter-cluster). TSS is fixed by the data, so lowering WSS raises BSS. SSE always falls as \(K\) grows, so it cannot choose \(K\) alone.

K-means objective

\[ J(r, \mu) = \sum_{n=1}^{N} \sum_{k=1}^{K} r_{nk} \lVert x_n - \mu_k \rVert^2, \qquad r_{nk} \in \{0, 1\}, \quad \sum_k r_{nk} = 1 \]

where: \(r_{nk} = 1\) if point \(x_n\) is assigned to cluster \(k\) (1-of-\(K\) coding, hard assignment), \(\mu_k\) the centroid of cluster \(k\).

use: \(J\) is the SSE of the clustering. K-means minimises it by coordinate descent over \(r\) and \(\mu\).

10.2.2 · slides 657, 660, 663

K-means E-step and M-step

\[ \text{E-step: } r_{nk} = \begin{cases} 1 & k = \arg\min_j \lVert x_n - \mu_j \rVert^2 \\ 0 & \text{otherwise} \end{cases}, \qquad \text{M-step: } \mu_k = \frac{\sum_n r_{nk} \, x_n}{\sum_n r_{nk}} \]

where: the M-step centroid is the mean of the points currently assigned to cluster \(k\).

use: alternate assign and recompute until no assignment changes. Recompute all distances with the new centroids each iteration. Scale features first, since Euclidean distance is scale-dependent.

10.2.1 · slides 655–663, 705–706

K-means convergence

\[ J\left( r^{(t)}, \mu^{(t)} \right) \ge J\left( r^{(t+1)}, \mu^{(t)} \right) \ge J\left( r^{(t+1)}, \mu^{(t+1)} \right) \]

where: the first inequality is the E-step (each point moves to its nearest centroid), the second the M-step (the mean minimises squared distance).

use: \(J\) never increases and there are finitely many assignments, so K-means always converges, but only to a local minimum that depends on the initial centroids. Run several initialisations (or k-means++) and keep the lowest \(J\).

The mean minimises squared distance

\[ \sum_{i=1}^{n} \lVert x_i - c \rVert^2 = \sum_{i=1}^{n} \lVert x_i - \bar{x} \rVert^2 + n \lVert c - \bar{x} \rVert^2 \]

where: \(c\) is any candidate centre, \(\bar{x}\) the mean of the points.

use: the centroid is the best centre for SSE; any other point (including the medoid) costs an extra \(n\lVert c - \bar{x} \rVert^2\). For the sum of absolute (\(L_1\)) distances the median is optimal instead, which is why medoids resist outliers.

Elbow method for K

\[ \Delta \text{SSE}(K) = \text{SSE}(K - 1) - \text{SSE}(K), \qquad \hat{K} = \text{the } K \text{ after which } \Delta \text{SSE} \text{ drops sharply} \]

where: \(\text{SSE}(K)\) is the best SSE found with \(K\) clusters.

use: SSE falls with every extra cluster (to 0 at \(K = N\)); pick the bend where adding clusters stops paying. If the decreases shrink smoothly there is no clear elbow: use the silhouette or BIC as well.

K-medoids cost and swap

\[ \text{Cost} = \sum_{k=1}^{K} \sum_{x \in C_k} d(x, m_k), \quad m_k \in C_k, \qquad \text{swap } (m, o) \text{ if } \text{Cost}_{\text{new}} - \text{Cost}_{\text{old}} < 0 \]

where: \(m_k\) is the medoid (an actual data point) of cluster \(k\), \(d\) any dissimilarity (often Manhattan or Euclidean, not squared).

use: PAM tries replacing a medoid \(m\) by a non-medoid \(o\), reassigns every point to its nearest medoid, and keeps the swap if total cost falls. An outlier drags a centroid far away (\((1,1),(2,1),(1,2),(2,3),(9,8)\): centroid \((3, 3)\)) but cannot pull a medoid off the data. Costs \(O(K(N - K)^2)\) per iteration.

Silhouette coefficient

\[ s(i) = \frac{b(i) - a(i)}{\max\{a(i), b(i)\}} = \begin{cases} 1 - \dfrac{a(i)}{b(i)} & a(i) < b(i) \\ \dfrac{b(i)}{a(i)} - 1 & a(i) \ge b(i) \end{cases}, \qquad \bar{s} = \frac{1}{N} \sum_i s(i) \]

where: \(a(i)\) = average distance from \(i\) to the other points of its own cluster (cohesion); \(b(i)\) = the minimum over other clusters of the average distance from \(i\) to that cluster's points (separation).

use: \(s \in [-1, 1]\): near 1 well placed, near 0 on a border, negative probably in the wrong cluster. Compare clusterings (or values of \(K\)) by the mean \(\bar{s}\). A singleton cluster is conventionally given \(s = 0\).

Entropy and purity against known labels

\[ e_j = -\sum_{i} p_{ij} \log_2 p_{ij}, \qquad e = \sum_{j} \frac{n_j}{n} \, e_j, \qquad \text{purity} = \sum_j \frac{n_j}{n} \max_i p_{ij} = \frac{1}{n} \sum_j \max_i n_{ij} \]

where: \(p_{ij} = n_{ij}/n_j\) is the fraction of cluster \(j\) that belongs to class \(i\); \(n_j\) the size of cluster \(j\), \(n\) the total.

Multivariate Gaussian density

\[ \mathcal{N}(x \mid \mu, \Sigma) = \frac{1}{(2\pi)^{d/2} \lvert \Sigma \rvert^{1/2}} \exp\left( -\frac{1}{2} (x - \mu)^\top \Sigma^{-1} (x - \mu) \right) \]

GMM log-likelihood

\[ \ln L = \sum_{n=1}^{N} \ln \left( \sum_{k=1}^{K} \pi_k \, \mathcal{N}(x_n \mid \mu_k, \Sigma_k) \right) \]

where: the inner sum is the mixture density \(p(x_n)\) at each data point.

use: EM never decreases \(\ln L\) (check after each iteration), but converges only to a local maximum that depends on initialisation. \(\ln L\) is unbounded: a component collapsing onto one point with \(\sigma \to 0\) sends it to \(\infty\) (singularity), so floor the variances or restart.

Regression metrics

\[ \text{MSE} = \frac{1}{n} \sum_i (y_i - \hat{y}_i)^2, \quad \text{RMSE} = \sqrt{\text{MSE}}, \quad \text{MAD} = \text{MAE} = \frac{1}{n} \sum_i \lvert y_i - \hat{y}_i \rvert, \quad \text{MAPE} = \frac{100\%}{n} \sum_i \frac{\lvert y_i - \hat{y}_i \rvert}{\lvert y_i \rvert}, \quad R^2 = 1 - \frac{\text{SSE}}{\text{SST}} \]

where: \(y_i\) actual, \(\hat{y}_i\) predicted, \(n\) test cases; the slides call MAE "MAD" (mean absolute deviation).

use: MSE/RMSE punish large errors most (sensitive to outliers); MAE treats all errors linearly; MAPE is scale-free but undefined at \(y_i = 0\) and inflated by small \(y_i\); \(R^2\) compares with predicting the mean and is negative on test data for a model worse than that. Different metrics can rank models differently, so pick the one that matches the business cost.

Cross-validation mean and its standard error

\[ \bar{a} = \frac{1}{k} \sum_{i=1}^{k} a_i, \qquad s = \sqrt{\frac{1}{k - 1} \sum_{i=1}^{k} (a_i - \bar{a})^2}, \qquad \text{SE} = \frac{s}{\sqrt{k}} \]

where: \(a_i\) is the score on fold \(i\) of \(k\).

use: report \(\bar{a} \pm \text{SE}\) to show how stable the estimate is (folds overlap in training data, so this SE is only approximate). Picking the best of many settings on one test set inflates the score: the expected maximum of 20 equal models is about \(1.867\) SEs above the truth.

Standard error of an accuracy

\[ \operatorname{Var}(\hat{p}) = \frac{1}{n^2} \sum_{i=1}^{n} \operatorname{Var}(X_i) = \frac{p(1 - p)}{n}, \qquad \text{SE}(\hat{p}) = \sqrt{\frac{\hat{p}(1 - \hat{p})}{n}} \]

where: \(X_i \in \{0, 1\}\) indicates a correct prediction on test case \(i\) (Bernoulli), \(\hat{p}\) the test accuracy, \(n\) test cases.

use: test accuracy is a sample mean, so its uncertainty shrinks like \(1/\sqrt{n}\). The same formula gives the SE of a TPR or FPR, with \(n\) the number of positives or negatives, which is why per-group rates on small groups are noisy.

Confidence interval for an accuracy

\[ \hat{p} \pm z_{\alpha/2} \sqrt{\frac{\hat{p}(1 - \hat{p})}{n}}, \qquad n \ge \frac{z_{\alpha/2}^2 \, \hat{p}(1 - \hat{p})}{E^2} \]

where: \(z_{0.025} = 1.96\) (95%), \(z_{0.005} = 2.576\) (99%); \(E\) the desired half-width (margin of error).

use: the normal (Wald) interval, fine when \(n\hat{p}\) and \(n(1 - \hat{p})\) are both at least about 10. Example: \(0.85\) on 1000 cases gives \([0.828, 0.872]\). For the sample size, use \(\hat{p} = 0.5\) if nothing is known (worst case), and round \(n\) up.

\[ z = \frac{\hat{p}_A - \hat{p}_B}{\sqrt{\bar{p}(1 - \bar{p}) \left( \frac{1}{n_A} + \frac{1}{n_B} \right)}}, \quad \bar{p} = \frac{x_A + x_B}{n_A + n_B}; \qquad (\hat{p}_A - \hat{p}_B) \pm z_{\alpha/2} \sqrt{\frac{\hat{p}_A(1 - \hat{p}_A)}{n_A} + \frac{\hat{p}_B(1 - \hat{p}_B)}{n_B}} \]

McNemar's test on a shared test set

\[ \chi^2 = \frac{(b - c)^2}{b + c}, \qquad \chi^2_{\text{cc}} = \frac{(\lvert b - c \rvert - 1)^2}{b + c}, \qquad \text{df} = 1 \]

where: \(b\) = cases A gets right and B wrong, \(c\) = cases A gets wrong and B right (the discordant counts); cases where both agree are ignored.

use: compare with \(\chi^2_1 = 3.841\) at 5%. Group fairness: demographic parity

\[ \text{SR}_g = P(\hat{Y} = 1 \mid G = g) = \frac{TP_g + FP_g}{n_g}, \qquad \Delta_{DP} = \lvert \text{SR}_A - \text{SR}_B \rvert, \qquad \text{DI} = \frac{\min(\text{SR}_A, \text{SR}_B)}{\max(\text{SR}_A, \text{SR}_B)} \]

where: \(\text{SR}_g\) is the selection rate of group \(g\) (fraction predicted positive), DI the disparate-impact ratio.

use: the "four-fifths rule" flags disparate impact when \(\text{DI} < 0.8\) (\(0.34/0.56 = 0.607\)). Parity ignores differing base rates \(P(Y = 1 \mid G)\), so it is not a full verdict on its own. Dropping the protected attribute ("fairness through unawareness") does not remove a gap when proxies encode it.

Group fairness: equal opportunity, equalized odds, predictive parity

\[ \Delta_{EO} = \lvert TPR_A - TPR_B \rvert, \qquad \text{equalized odds: } TPR_A = TPR_B \text{ and } FPR_A = FPR_B, \qquad \text{predictive parity: } PPV_A = PPV_B \]

where: \(TPR_g = \frac{TP_g}{TP_g + FN_g}\), \(FPR_g = \frac{FP_g}{FP_g + TN_g}\), \(PPV_g = \frac{TP_g}{TP_g + FP_g}\) computed within group \(g\).

use: equal opportunity asks that qualified people in each group are accepted equally often; equalized odds adds equal false-alarm rates; predictive parity (calibration) asks that a positive prediction means the same in each group. If the labels themselves carry historical bias (negative legacy), every metric computed against them inherits it.

Precision depends on the base rate

\[ PPV = \frac{TPR \cdot \pi}{TPR \cdot \pi + FPR \cdot (1 - \pi)} = \frac{1}{1 + \frac{FPR}{TPR} \cdot \frac{1 - \pi}{\pi}} \]

where: \(\pi = P(Y = 1 \mid G = g)\) is the group's base rate.

use: with equal TPR and FPR across groups (equalized odds), groups with different base rates must have different precision, and vice versa: equalized odds and predictive parity cannot both hold unless base rates are equal or the classifier is perfect (the COMPAS dispute). Solve the equation for the FPR one group would need to match another's PPV.

Phi coefficient for proxy strength

\[ \phi = \frac{ad - bc}{\sqrt{(a + b)(c + d)(a + c)(b + d)}} \]

where: \(a, b\) (first row) and \(c, d\) (second row) are the cells of the \(2 \times 2\) table of a binary feature \(Z\) against the protected attribute \(G\).

use: the Pearson correlation of two binary variables, in \([-1, 1]\); a large \(\lvert \phi \rvert\) means \(Z\) is a proxy (redundant encoding) for \(G\), so a model that never sees \(G\) can still discriminate through \(Z\).

11.3.2 · slides 739–742

Explaining a linear or logistic prediction

\[ z = w_0 + \sum_j w_j x_j, \qquad \text{contribution}_j = w_j x_j, \qquad \Delta x_j = \frac{\Delta z}{w_j}, \qquad P = \sigma(z) \]

where: \(w_j x_j\) is feature \(j\)'s additive push on the score (on \(\hat{y}\) for linear regression, on the log-odds for logistic regression); \(\Delta z\) the score change needed to reach the decision threshold (\(z = 0\) for \(P = 0.5\)).

use: gives per-decision explanations and counterfactuals ("raise \(x_1\) by 4.33 to be approved"). Coefficients are comparable across features only when the features are on comparable scales. Trees explain by their rule path and k-NN by its neighbours; black boxes (forests, boosting, deep nets) trade this transparency for accuracy and need post-hoc tools (feature importance), which show magnitude but not direction.
